## デザイン原則

### 没入感最大化

- ユーザーはSCP記事を読むことに集中したい
- UI要素は最小限に抑え、コンテンツを最大化
- 操作は直感的に、説明不要で

### 2026年UIトレンド準拠

- Glassmorphism（すりガラス効果）
- フローティングUI
- ミニマルナビゲーション

### 一貫性

- 全画面で同じドロワーメニューを使用
- 戻るボタンは使わない（メニューで統一）
- カラーとスペーシングは統一されたトークンを使用


## インタラクション

### お気に入りボタン

```
タップ → ハートが赤に → scale(1.3) → scale(1)
         ↑ 0.3秒アニメーション
```

```css
@keyframes heartPop {
  0% {
    transform: scale(1);
  }
  50% {
    transform: scale(1.3);
  }
  100% {
    transform: scale(1);
  }
}
```

### ドロワー開閉

```
開く: translateX(-100%) → translateX(0)
閉じる: translateX(0) → translateX(-100%)
時間: 0.3s ease
```

### カードタップ

```
タップ → scale(0.98) + シャドウ軽減
リリース → 元に戻る
時間: 0.2s ease
```

## 実装時の注意

1. **design-tokens.css をインポート**して使用
2. Tailwind CSS と併用する場合は `tailwind.config.js` に統合
3. コンポーネントは **React + TypeScript** で実装
4. アニメーションは **Framer Motion** 推奨
5. SCP記事コンテンツは **iframe または API取得** で表示

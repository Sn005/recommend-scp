# Subtask 011-03-02: 生成CLIコマンド実装

## 概要

`pnpm gen:testcases` コマンドでAIテストケース生成を実行できるCLIを実装する。

## ユーザーストーリー

**ペルソナ**: 開発者
**目的**: コマンド一発でテストケースを生成する
**価値**: テストケース作成の自動化が実現する
**理由**: 手動でプロンプトをコピペする手間を省きたい

## 受け入れ条件（EARS記法）

- [x] WHEN `pnpm gen:testcases` を実行する際
      GIVEN EPIC/Story IDが指定された場合
      THEN 対応する仕様書を読み込んでテストケースを生成する

- [x] WHEN テストケースを生成する際
      GIVEN 出力先CSVファイルが存在しない場合
      THEN 新規ファイルとして作成される

- [x] WHEN テストケースを生成する際
      GIVEN 出力先CSVファイルが存在する場合
      THEN 差分のみを追記・更新する（既存テストケースは保持）

- [x] WHEN 生成が完了した際
      GIVEN 正常終了した場合
      THEN 生成されたテストケース数が表示される

### 差分更新ロジック

```typescript
function mergeCsv(existingCsv: string, newCsv: string): string {
  const existingCases = parseCsv(existingCsv);
  const newCases = parseCsv(newCsv);

  // 既存IDは保持、新規IDは追加
  const merged = new Map<string, TestCase>();
  for (const tc of existingCases) {
    merged.set(tc.id, tc);
  }
  for (const tc of newCases) {
    if (!merged.has(tc.id)) {
      merged.set(tc.id, tc);
    }
  }

  return toCsv(Array.from(merged.values()));
}
```

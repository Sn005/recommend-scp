# Story 011-03: AIテストケース生成

## 概要

EPIC/Story仕様からAIがテストケースを自動生成する機能を実装する。

## ユーザーストーリー

**ペルソナ**: 開発者
**目的**: 仕様書からテストケースを自動生成する
**価値**: テストケース作成の工数を大幅に削減できる
**理由**: 手動でのテストケース作成は時間がかかり、抜け漏れも発生しやすい

## 受け入れ条件（Storyレベル）

- [x] 仕様書からテストケースを生成するプロンプトが設計されている
- [x] `pnpm gen:testcases` でテストケースCSVが生成される
- [x] 既存テストケースがある場合は差分更新される

## 関連Subtask

- [011-03-01: 生成プロンプト設計](./011-03-01-prompt-design.md)
- [011-03-02: 生成CLIコマンド実装](./011-03-02-gen-cli.md)

## 技術メモ

- Claude API を使用してテストケースを生成
- 仕様書のAC（EARS記法）を入力として使用
- シナリオベース（ユーザーフロー単位）で出力

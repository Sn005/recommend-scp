# Story 011-04: 画面別テストケース

## 概要

オンボーディング、推薦、お気に入りの各画面に対する正常系E2Eテストケースを作成・実行する。

## ユーザーストーリー

**ペルソナ**: 開発者
**目的**: 全画面の正常系フローをE2Eテストで検証する
**価値**: ユーザーフローのリグレッションを自動検知できる
**理由**: 手動テストでは見逃しやすいフロー全体の整合性を担保したい

## 受け入れ条件（Storyレベル）

- [ ] オンボーディング画面の正常系テストが実行できる
- [ ] 推薦画面の正常系テストが実行できる

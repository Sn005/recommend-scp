# Story 017-02: OGP画像・メタデータ設定

## 概要

SNS共有時に表示されるOGP（Open Graph Protocol）専用画像を制作し、Next.jsのメタデータ設定を整備する。Twitter Card対応も含む。

**status**: completed

## ユーザーストーリー

> SCPicksユーザーとして、アプリのURLをSNSに共有した際にアプリの魅力が伝わるOGP画像が表示されてほしい。なぜならテキストだけのリンクでは興味を引けないから。

## Acceptance Criteria

### AC-1: OGP画像制作

- [x] 1200x630pxの専用OGP画像が制作されている
      AND アプリ名「SCPicks」が含まれている
      AND キャッチコピー「あなた好みのSCPを発見」が含まれている
      AND ブランドカラー（#3B82F6 / #FFFFFF）を使用している

### AC-2: OGPメタデータ設定

- [x] WHEN クローラーがSCPicksのページを取得した際
      THEN `og:title` が設定されている
      AND `og:description` が設定されている
      AND `og:image` がOGP画像を指している
      AND `og:type` が `website` に設定されている
      AND `og:url` が正しいURLを指している

### AC-3: Twitter Card対応

- [x] WHEN TwitterでSCPicksのURLを共有した際
      THEN `twitter:card` が `summary_large_image` に設定されている
      AND `twitter:image` がOGP画像を指している
      AND 大きなプレビュー画像が表示される

### AC-4: 各ページのOGP

- [x] ルートレイアウト（`layout.tsx`）にデフォルトOGPが設定されている
      AND 必要に応じてページ固有のOGPをオーバーライドできる構造になっている

## 技術メモ

### OGP画像の生成方式

Next.js の `opengraph-image.tsx` 規約ファイルによる動的生成方式を採用。

```
apps/web/src/app/
  opengraph-image.tsx   # ImageResponse APIでOGP画像を動的生成（1200x630）
  twitter-image.tsx     # opengraph-image.tsx を再エクスポート
```

### Next.js Metadata API

```typescript
// app/layout.tsx（OGP画像は opengraph-image.tsx が自動設定）
export const metadata: Metadata = {
  openGraph: {
    type: "website",
    siteName: siteConfig.name,
    title: `${siteConfig.name} - あなた好みのSCPを発見`,
    description: siteConfig.description,
    locale: siteConfig.locale,
  },
  twitter: {
    card: "summary_large_image",
    title: `${siteConfig.name} - あなた好みのSCPを発見`,
    description: siteConfig.description,
  },
};
```

# Story 017-02: OGP画像・メタデータ設定

## 概要

SNS共有時に表示されるOGP（Open Graph Protocol）専用画像を制作し、Next.jsのメタデータ設定を整備する。Twitter Card対応も含む。

**status**: pending

## ユーザーストーリー

> SCPicksユーザーとして、アプリのURLをSNSに共有した際にアプリの魅力が伝わるOGP画像が表示されてほしい。なぜならテキストだけのリンクでは興味を引けないから。

## Acceptance Criteria

### AC-1: OGP画像制作

- [ ] 1200x630pxの専用OGP画像が制作されている
      AND アプリ名「SCPicks」が含まれている
      AND キャッチコピー「あなた好みのSCPを発見」が含まれている
      AND ブランドカラー（#3B82F6 / #FFFFFF）を使用している

### AC-2: OGPメタデータ設定

- [ ] WHEN クローラーがSCPicksのページを取得した際
      THEN `og:title` が設定されている
      AND `og:description` が設定されている
      AND `og:image` がOGP画像を指している
      AND `og:type` が `website` に設定されている
      AND `og:url` が正しいURLを指している

### AC-3: Twitter Card対応

- [ ] WHEN TwitterでSCPicksのURLを共有した際
      THEN `twitter:card` が `summary_large_image` に設定されている
      AND `twitter:image` がOGP画像を指している
      AND 大きなプレビュー画像が表示される

### AC-4: 各ページのOGP

- [ ] ルートレイアウト（`layout.tsx`）にデフォルトOGPが設定されている
      AND 必要に応じてページ固有のOGPをオーバーライドできる構造になっている

## 技術メモ

### OGP画像の配置

```
apps/web/public/
  og-image.png          # 1200x630 デフォルトOGP画像
```

### Next.js Metadata API

```typescript
// app/layout.tsx
export const metadata: Metadata = {
  openGraph: {
    title: "SCPicks - あなた好みのSCPを発見",
    description: "AIがあなたの好みを学習し、おすすめのSCP記事を推薦",
    images: [{ url: "/og-image.png", width: 1200, height: 630 }],
    type: "website",
  },
  twitter: {
    card: "summary_large_image",
    title: "SCPicks - あなた好みのSCPを発見",
    description: "AIがあなたの好みを学習し、おすすめのSCP記事を推薦",
    images: ["/og-image.png"],
  },
};
```

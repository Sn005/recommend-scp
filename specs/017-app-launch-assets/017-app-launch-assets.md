# EPIC-017: アプリ起動アセット

## 概要

SCPicksの本番公開に向けて、アプリアイコン・favicon・OGP画像・スプラッシュスクリーンなどのビジュアルアセットを制作・配置する。EPIC-015（PWA対応）で配置したプレースホルダーアセットを本番品質に差し替え、SNS共有時やPWA起動時のブランド体験を向上させる。

**status**: pending

## ユーザーストーリー

**ペルソナ**: SCPicksを利用・共有するユーザー
**目的**: アプリアイコン・OGP・スプラッシュスクリーンが本番品質であること
**価値**: SNS共有時の視認性向上、PWA起動時のブランド体験、プロダクトとしての信頼感
**理由**: プレースホルダーアセットのままではプロダクトとしての完成度が低く、共有時に魅力が伝わらない

> SCPicksユーザーとして、アプリアイコンやSNS共有時のOGP画像が本番品質であってほしい。なぜならプロダクトの信頼感とブランド認知に直結するから。

## 背景

### 現状のアセット

| アセット                 | 現状                           | 課題               |
| ------------------------ | ------------------------------ | ------------------ |
| `favicon.ico`            | 121バイト（プレースホルダー）  | 本番品質に差し替え |
| `apple-touch-icon.png`   | 495バイト（プレースホルダー）  | 本番品質に差し替え |
| `icons/icon-192x192.png` | PWA用アイコン                  | デザイン精査が必要 |
| `icons/icon-512x512.png` | PWA用アイコン                  | デザイン精査が必要 |
| OGP画像                  | なし（icon-512x512.pngを流用） | 専用画像が必要     |
| スプラッシュスクリーン   | なし                           | PWA起動体験に必要  |

### ブランディング（EPIC-015で決定済み）

| アプリ名（長） | `SCPicks - あなた好みのSCPを発見` |
| テーマカラー   | `#3B82F6`（青）/ `#FFFFFF`（白）  |

## EPIC-level Acceptance Criteria

### AC-1: アプリアイコン本番化

- [ ] WHEN ユーザーがPWAをホーム画面に追加した際
      THEN 本番品質のアプリアイコンが表示される
      AND 192x192、512x512、apple-touch-icon（180x180）が全て統一デザインである

### AC-2: favicon本番化

- [ ] WHEN ユーザーがブラウザタブでSCPicksを開いた際
      THEN 本番品質のfaviconが表示される
      AND ブランドカラー・デザインと統一されている

### AC-3: OGP画像

- [ ] WHEN ユーザーがSCPicksのURLをSNS（Twitter/X、LINE等）に共有した際
      THEN 1200x630の専用OGP画像が表示される
      AND アプリ名・キャッチコピー・ブランドカラーが含まれている

### AC-4: OGPメタデータ

- [ ] WHEN クローラーがSCPicksのページを取得した際
      THEN og:title、og:description、og:image、og:type が正しく設定されている
      AND Twitter Card（twitter:card、twitter:image）も設定されている

### AC-5: スプラッシュスクリーン

- [ ] WHEN ユーザーがPWAをホーム画面から起動した際
      THEN スプラッシュスクリーンが表示される
      AND アプリ名・アイコン・背景色がブランドと統一されている

### スプラッシュスクリーン対応

iOSのPWAスプラッシュスクリーンは `apple-touch-startup-image` メタタグで制御。
デバイスごとのサイズ対応が必要（iPhone/iPad各解像度）。

# Story 002-02: コミットフック設定

## 概要

lefthookとcommitlintを導入し、コミット時の自動lint/formatとConventional Commits形式の強制を実現する。

## ユーザーストーリー

**As a** 開発者（AI/人間）
**I want** コミット時に自動的にlint/formatが実行され、コミットメッセージ形式が検証される
**So that** 品質の低いコードやフォーマットの統一されていないコミットがリポジトリに入ることを防げる

## Acceptance Criteria（Storyレベル）

- [ ] `git commit` 時にlefthookがpre-commitフックを実行する
- [ ] ステージングされたファイルのみがlint/formatされる
- [ ] lint/formatで自動修正されたファイルが再ステージングされる
- [ ] Conventional Commits形式でないコミットメッセージがブロックされる
- [ ] CLAUDE.mdにConventional Commitsルールが記載されている

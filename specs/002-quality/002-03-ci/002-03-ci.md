# Story 002-03: GitHub Actions CI設定

## 概要

GitHub ActionsでCI環境を構築し、PR時に自動でテスト・型チェック・Lintを実行する。

## ユーザーストーリー

**As a** 開発者（AI/人間）
**I want** PRを作成した際に自動的に品質チェックが実行される
**So that** 品質の低いコードがmainブランチにマージされることを防げる

## Acceptance Criteria（Storyレベル）

- [ ] PRに対してCIワークフローが自動実行される
- [ ] 型チェック、Lint、テストが実行される
- [ ] テストカバレッジレポートが生成される
- [ ] pnpm依存関係がキャッシュされる
- [ ] すべてのチェックが成功した場合のみマージ可能になる

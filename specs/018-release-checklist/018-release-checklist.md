# EPIC-018: リリース前最終確認

## ステータス

- **status**: pending
- **created**: 2026-03-09
- **epic-id**: 018

## ユーザーストーリー

**ペルソナ**: 開発者
**目的**: scpicks.appを一般公開・告知する前に、ライセンス準拠・品質・パフォーマンス・SNS表示・文言を最終確認する
**価値**: 公開後の法的問題・品質問題・パフォーマンス劣化・ブランディング不整合を防止する
**理由**: 公開後に問題が発覚すると、ユーザー体験とプロジェクトの信頼性を損なうから

## 背景

全17 EPICの実装が完了し、残るは検証・確認タスクのみ。
本EPICでは、一般公開前に必要な最終確認を体系的に実施する。

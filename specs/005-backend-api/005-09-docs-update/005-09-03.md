## API実装パターン（Hono）

### ドメイン別Colocation

各ドメインは以下のファイル構成で実装する:

\`\`\`
apps/api-server/src/domains/[domain]/
├── routes.ts # エンドポイント定義
├── service.ts # ビジネスロジック
├── repository.ts # DB操作
├── schema.ts # Zodバリデーション
├── types.ts # 型定義（必要に応じて）
└── **dev**/
├── routes.test.ts
├── service.test.ts
└── repository.test.ts
\`\`\`

### 各ファイルの責務

| ファイル      | 責務                               | 依存先             |
| ------------- | ---------------------------------- | ------------------ |
| routes.ts     | HTTPリクエスト/レスポンス処理      | service, schema    |
| service.ts    | ビジネスロジック、トランザクション | repository, shared |
| repository.ts | DB操作（CRUD）、snake_case変換     | Supabase           |
| schema.ts     | 入力バリデーション（Zod）          | -                  |

### ルート定義パターン

\`\`\`typescript
// routes.ts
import { Hono } from "hono";
import { zValidator } from "@hono/zod-validator";
import { mySchema } from "./schema";
import { MyService } from "./service";

export const createMyRoutes = (supabase: SupabaseClient) => {
const routes = new Hono();
const service = new MyService(supabase);

routes.post(
"/",
zValidator("json", mySchema),
async (c) => {
const input = c.req.valid("json");
const result = await service.doSomething(input);
return c.json(result, 200);
}
);

return routes;
};
\`\`\`

### エラーハンドリング

RFC 7807 Problem Details形式を使用:

\`\`\`typescript
// lib/errors.ts
export class AppError extends Error {
constructor(
public type: string,
public title: string,
public status: number,
public detail?: string
) {
super(title);
}
}

export class NotFoundError extends AppError {
constructor(resource: string, id: string) {
super(
"not-found",
"Not Found",
404,
\`\${resource} with id '\${id}' not found\`
);
}
}

export class ValidationError extends AppError {
constructor(detail: string) {
super("validation-error", "Validation Error", 400, detail);
}
}

export class OnboardingRequiredError extends AppError {
constructor(visitorId: string) {
super(
"onboarding-required",
"Onboarding Required",
400,
\`Onboarding not completed for visitor \${visitorId}\`
);
}
}
\`\`\`

### Repository層のパターン

snake_case ↔ camelCase変換はRepository層で行う:

\`\`\`typescript
// repository.ts
export class MyRepository {
constructor(private supabase: SupabaseClient) {}

async findById(id: string): Promise<MyEntity | null> {
const { data, error } = await this.supabase
.from("my_table")
.select("\*")
.eq("id", id)
.single();

    if (error) return null;

    // snake_case → camelCase変換
    return {
      id: data.id,
      visitorId: data.visitor_id,
      createdAt: data.created_at,
    };

}
}
\`\`\`

### 004-recommend.md に追加

```markdown
## アーキテクチャ変更履歴

### 2024-XX: サーバー主導アーキテクチャへの移行（EPIC-005）

EPIC-005でバックエンドAPIを実装するにあたり、ストレージ戦略を変更した。

| 項目                  | EPIC-004（当初）          | EPIC-005（変更後）        |
| --------------------- | ------------------------- | ------------------------- |
| ストレージ            | IndexedDB（クライアント） | Supabase（サーバー）      |
| 推薦計算              | クライアント側            | サーバー側                |
| データ永続化          | ブラウザローカル          | PostgreSQL                |
| PreferenceStorage実装 | IndexedDBStorage          | SupabasePreferenceStorage |

**変更理由:**

1. 複数端末でのデータ共有
2. 将来のSupabase Auth連携
3. サーバー側での行動データ分析

**互換性:**

- EPIC-004で定義した `PreferenceStorage` インターフェースはそのまま使用
- `RecommendationEngine` 等のロジックは変更なし（ストレージ実装を差し替えるだけ）
- IndexedDB実装はPWAオフラインモード用として保持

詳細は [EPIC-005: バックエンドAPI](../005-backend-api/005-backend-api.md) を参照。
```

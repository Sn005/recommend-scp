# Subtask 005-10-02: GET/DELETE /favorites エンドポイント

## 親 Story

[005-10: favorites API](./005-10.md)

## 概要

お気に入り API のエンドポイント（GET /favorites, DELETE /favorites/:articleId）を実装し、Hono ルーターに登録する。

## ステータス

- **status**: completed

## Acceptance Criteria

### GET /favorites

- [x] AC-1: お気に入り一覧取得エンドポイントを実装する
  - WHEN GET /favorites?visitorId={visitorId} をリクエストした際
  - THEN 200 OK でお気に入り一覧を返す
  - AND レスポンス形式は `{ favorites: FavoriteWithArticle[], total: number }`

- [x] AC-2: visitorId のバリデーションを行う
  - WHEN visitorId クエリパラメータが欠落した際
  - THEN 400 Bad Request を返す
  - AND RFC 7807 Problem Details 形式のエラーレスポンス

- [x] AC-3: 存在しない visitorId に対して 404 を返す
  - WHEN 未登録の visitorId でリクエストした際
  - THEN 404 Not Found を返す
  - AND RFC 7807 Problem Details 形式のエラーレスポンス

### DELETE /favorites/:articleId

- [x] AC-4: お気に入り削除エンドポイントを実装する
  - WHEN DELETE /favorites/:articleId をリクエストした際
  - THEN お気に入りを削除して 204 No Content を返す
  - AND レスポンスボディは空

- [x] AC-5: リクエストボディに visitorId を必須とする
  - WHEN リクエストボディが空または visitorId が欠落した際
  - THEN 400 Bad Request を返す

- [x] AC-6: 存在しないお気に入りに対して 404 を返す
  - WHEN お気に入りに登録されていない articleId を指定した際
  - THEN 404 Not Found を返す

### ルーティング

- [x] AC-7: app.ts に favorites ルートを登録する
  - WHEN API サーバーを起動した際
  - THEN /favorites エンドポイントが利用可能になる

## 技術仕様

### レスポンス形式

```typescript
// GET /favorites レスポンス
interface GetFavoritesResponse {
  favorites: FavoriteWithArticle[];
  total: number;
}

interface FavoriteWithArticle {
  id: string;
  articleId: string;
  title: string;
  objectClass: string | null;
  rating: number | null;
  favoritedAt: string;
}
```

### Zod スキーマ

```typescript
// GET /favorites クエリ
const getFavoritesQuerySchema = z.object({
  visitorId: z.string().uuid(),
});

// DELETE /favorites/:articleId ボディ
const deleteFavoriteBodySchema = z.object({
  visitorId: z.string().uuid(),
});
```

### ルート定義

```typescript
// routes.ts
export const createFavoritesRoutes = (supabase: SupabaseClient) => {
  return new Hono()
    .get("/", zValidator("query", getFavoritesQuerySchema), async (c) => {
      // GET /favorites
    })
    .delete("/:articleId", zValidator("json", deleteFavoriteBodySchema), async (c) => {
      // DELETE /favorites/:articleId
    });
};
```

### app.ts への登録

```typescript
// app.ts
import { createFavoritesRoutes } from "./domains/favorites/routes";

export const createRoutes = (supabase: SupabaseClient) => {
  return (
    new Hono()
      // ... 既存ルート
      .route("/favorites", createFavoritesRoutes(supabase))
  );
};
```

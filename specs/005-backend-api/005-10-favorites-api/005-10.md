# Story 005-10: favorites API

## 概要

お気に入り一覧取得（GET /favorites）と削除（DELETE /favorites/:articleId）エンドポイントを実装する。EPIC-006（フロントエンド）の Story 006-03「お気に入り管理」が本 API に依存している。

## ステータス

- **status**: completed

## ユーザーストーリー

**As a** ユーザー
**I want** お気に入りに保存した記事の一覧を取得・追加・削除できる
**So that** 気に入った記事にいつでもアクセスでき、推薦精度が向上し、不要になった記事を整理できる

## Acceptance Criteria（Story レベル）

- [x] AC-1: GET /favorites でお気に入り一覧を取得できる
- [x] AC-2: レスポンスに記事情報（タイトル、オブジェクトクラス、評価）が含まれる
- [x] AC-3: DELETE /favorites/:articleId でお気に入りを解除できる
- [x] AC-4: POST /favorites/:articleId でお気に入りを追加できる
- [x] AC-5: 存在しない visitorId に対して 404 エラーを返す
- [x] AC-6: エラーレスポンスは RFC 7807 Problem Details 形式

## 技術設計

### エンドポイント設計

#### GET /favorites

```
GET /favorites?visitorId={visitorId}

Response 200:
{
  "favorites": [
    {
      "id": "uuid",
      "articleId": "SCP-173",
      "title": "彫刻 - オリジナル",
      "objectClass": "Euclid",
      "rating": 1024,
      "favoritedAt": "2024-01-01T00:00:00Z"
    }
  ],
  "total": 10
}

Response 404 (visitorId未登録):
RFC 7807 Problem Details形式
```

#### POST /favorites/:articleId

```
POST /favorites/:articleId
Content-Type: application/json

Body:
{
  "visitorId": "visitor-uuid"
}

Response 201: { "articleId": "SCP-173", "favoritedAt": "2024-01-01T00:00:00Z" }
Response 200: 既にお気に入り済み（冪等）
Response 404: visitorId未登録
```

#### DELETE /favorites/:articleId

```
DELETE /favorites/:articleId
Content-Type: application/json

Body:
{
  "visitorId": "visitor-uuid"
}

Response 204: No Content
Response 404: visitorIdまたはお気に入りが見つからない
```

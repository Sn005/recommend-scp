[005-10: favorites API](./005-10.md)

## 概要

お気に入り API のデータアクセス層（Repository）とビジネスロジック層（Service）を実装する。
feedback ドメインと同じ 3 層アーキテクチャを採用する。

## ステータス

- **status**: planned

## Acceptance Criteria

### Repository 層

- [ ] AC-1: FavoritesRepository クラスを実装する
  - WHEN `getByVisitorId(visitorId)` を呼び出した際
  - THEN favorites テーブルから visitorId に紐づく一覧を取得する
  - AND scp_articles テーブルと JOIN して記事情報を含める
  - AND 結果を FavoriteWithArticle[] 型で返す

- [ ] AC-2: getByVisitorId は記事情報を含める
  - WHEN お気に入り一覧を取得した際
  - THEN 各レコードに articleId, title, objectClass, rating, favoritedAt が含まれる
  - AND objectClass は tags カラムから抽出する（safe, euclid, keter 等）

- [ ] AC-3: お気に入り削除メソッドを実装する
  - WHEN `remove(visitorId, articleId)` を呼び出した際
  - THEN favorites テーブルから該当行を削除する
  - AND 削除成功で true、該当なしで false を返す

### Service 層

- [ ] AC-4: FavoritesService クラスを実装する
  - WHEN `getFavorites(visitorId)` を呼び出した際
  - THEN visitorId の存在を確認する
  - AND 存在しない場合は NotFoundError をスローする
  - AND 存在する場合は Repository 経由でお気に入り一覧を返す

- [ ] AC-5: お気に入り削除サービスを実装する
  - WHEN `removeFavorite(visitorId, articleId)` を呼び出した際
  - THEN visitorId の存在を確認する
  - AND 存在しない場合は NotFoundError（Visitor）をスローする
  - AND お気に入りが見つからない場合は NotFoundError（Favorite）をスローする

## 技術仕様

### 型定義

```typescript
/** お気に入り（記事情報付き） */
interface FavoriteWithArticle {
  id: string; // お気に入りID（UUID）
  articleId: string; // 記事ID（SCP-173等）
  title: string; // 記事タイトル
  objectClass: string | null; // オブジェクトクラス
  rating: number | null; // 評価スコア
  favoritedAt: string; // 追加日時（ISO 8601）
}
```

### ObjectClass 抽出ロジック

```typescript
/**
 * tags配列からオブジェクトクラスを抽出
 * tags例: ["safe", "horror", "科学"]
 */
const OBJECT_CLASSES = ["safe", "euclid", "keter", "thaumiel", "neutralized", "apollyon", "archon"];

function extractObjectClass(tags: string[] | null): string | null {
  if (!tags) return null;
  const found = tags.find((tag) => OBJECT_CLASSES.includes(tag.toLowerCase()));
  return found ?? null;
}
```

### DB クエリ（Repository）

```sql
-- お気に入り一覧取得（記事情報JOIN）
SELECT
  f.id,
  f.article_id,
  f.added_at,
  a.title,
  a.rating,
  a.tags
FROM favorites f
LEFT JOIN scp_articles a ON f.article_id = a.id
WHERE f.visitor_id = $1
ORDER BY f.added_at DESC;
```

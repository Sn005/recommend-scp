# Subtask 005-03-02: POST /visitors

## 概要

visitorId登録エンドポイント（POST /visitors）を実装する。

## ステータス

- **status**: completed

## ユーザーストーリー

**As a** フロントエンドアプリケーション
**I want** POST /visitors でvisitorIdを登録できる
**So that** サーバー側でユーザーを識別できる

## Acceptance Criteria（EARS記法）

- [x] WHEN POST /visitors に有効なvisitorIdを送信した際
      GIVEN visitorIdが未登録の場合
      THEN 201 Created を返す
      AND isNew: true を含むレスポンスを返す

- [x] WHEN POST /visitors に有効なvisitorIdを送信した際
      GIVEN visitorIdが登録済みの場合
      THEN 200 OK を返す
      AND isNew: false を含むレスポンスを返す

- [x] WHEN POST /visitors に無効なvisitorIdを送信した際
      THEN 400 Bad Request を返す
      AND RFC 7807形式のエラーを返す

- [x] WHEN POST /visitors にvisitorIdなしでリクエストした際
      THEN 400 Bad Request を返す

## 技術設計

### schema.ts

```typescript
import { z } from "zod";

export const registerVisitorSchema = z.object({
  visitorId: z.string().uuid("visitorId must be a valid UUID"),
});

export type RegisterVisitorInput = z.infer<typeof registerVisitorSchema>;
```

### routes.ts

```typescript
import { Hono } from "hono";
import { zValidator } from "@hono/zod-validator";
import { registerVisitorSchema } from "./schema";
import { VisitorsService } from "./service";
import { VisitorsRepository } from "./repository";

export const createVisitorsRoutes = (supabase: SupabaseClient) => {
  const visitors = new Hono();
  const repository = new VisitorsRepository(supabase);
  const service = new VisitorsService(repository);

  visitors.post("/", zValidator("json", registerVisitorSchema), async (c) => {
    const { visitorId } = c.req.valid("json");
    const result = await service.registerVisitor(visitorId);

    const status = result.isNew ? 201 : 200;
    return c.json(result, status);
  });

  return visitors;
};
```

### app.tsへの統合

```typescript
import { createVisitorsRoutes } from "./domains/visitors/routes";

// ...
app.route("/visitors", createVisitorsRoutes(supabase));
```

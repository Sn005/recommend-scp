# Subtask 005-01-03: pinoロガー設定

## 概要

pinoを使用した構造化ロギングを設定し、リクエストログを記録する。

## ステータス

- **status**: planned

## ユーザーストーリー

**As a** 運用担当者
**I want** 構造化されたリクエストログを取得する
**So that** 問題調査やパフォーマンス分析ができる

## Acceptance Criteria（EARS記法）

- [ ] WHILE リクエストを処理する際
      THE SYSTEM SHALL 以下の情報をログに記録する: - リクエストメソッド - リクエストパス - レスポンスステータス - レスポンス時間（ms）- visitorId（ヘッダーから取得可能な場合）

- [ ] WHERE ログ出力
      THE SYSTEM SHALL pinoを使用する
      AND console.logは使用しない（ESLintエラー）

- [ ] WHEN 開発環境で実行する際
      THEN pino-prettyで整形されたログを出力する

- [ ] WHEN 本番環境で実行する際
      THEN JSON形式でログを出力する

- [ ] WHILE エラーが発生した際
      THE SYSTEM SHALL エラー詳細をログに記録する
      AND スタックトレースを含める

### lib/logger.ts

```typescript
import { pino } from "pino";
import { env } from "@recommend-scp/shared";

const isDevelopment = env.NODE_ENV !== "production";

export const logger = pino({
  level: env.LOG_LEVEL ?? "info",
  transport: isDevelopment
    ? {
        target: "pino-pretty",
        options: {
          colorize: true,
          translateTime: "SYS:standard",
        },
      }
    : undefined,
});

export const createChildLogger = (bindings: Record<string, unknown>) => logger.child(bindings);
```

### middleware/request-logger.ts

```typescript
import type { MiddlewareHandler } from "hono";
import { logger } from "../lib/logger";

export const requestLogger: MiddlewareHandler = async (c, next) => {
  const start = Date.now();
  const method = c.req.method;
  const path = c.req.path;
  const visitorId = c.req.header("X-Visitor-Id");

  await next();

  const duration = Date.now() - start;
  const status = c.res.status;

  logger.info(
    {
      method,
      path,
      status,
      duration,
      visitorId,
    },
    `${method} ${path} ${status} ${duration}ms`
  );
};
```

# Subtask 005-01-01: Honoサーバー初期化

## 概要

`apps/api-server` パッケージを作成し、Honoサーバーの基本構成を実装する。

## ステータス

- **status**: completed

## ユーザーストーリー

**As a** 開発者
**I want** Honoベースのサーバーパッケージを持つ
**So that** APIエンドポイントを実装する基盤ができる

## Acceptance Criteria（EARS記法）

- [x] WHEN `pnpm dev` を実行した際
      GIVEN apps/api-server が存在する場合
      THEN Honoサーバーが起動する
      AND 指定ポート（デフォルト: 3001）でリクエストを受け付ける

- [x] WHERE パッケージ構成
      THE SYSTEM SHALL 以下のファイルを持つ: - src/index.ts（エントリーポイント）- src/app.ts（Honoアプリ定義）- package.json - tsconfig.json（ルート設定を継承）- vitest.config.ts

- [x] WHEN TypeScriptビルドを実行した際
      THEN エラーなくコンパイルが完了する
      AND ルートのESLint設定が適用される

- [x] WHEN `pnpm test` を実行した際
      THEN apps/api-server のテストが実行される

### src/index.ts

```typescript
import { serve } from "@hono/node-server";
import { app } from "./app";
import { env } from "@recommend-scp/shared";

const port = env.API_PORT ?? 3001;

serve({
  fetch: app.fetch,
  port,
});
```

### src/app.ts

```typescript
import { Hono } from "hono";

export const app = new Hono();

// ミドルウェアは後続Subtaskで追加

export type AppType = typeof app;
```

# Story 005-01: API基盤構築

## 概要

Honoサーバーの初期化、共通ミドルウェア、エラーハンドリング基盤を構築する。

## ステータス

- **status**: completed

## ユーザーストーリー

**As a** 開発者
**I want** 堅牢なAPI基盤を持つ
**So that** 各ドメインのエンドポイントを安全かつ効率的に実装できる

## Acceptance Criteria（Story レベル）

- [x] WHEN APIサーバーが起動した際
      THEN Honoサーバーが指定ポートでリクエストを受け付ける

- [x] WHERE APIエラーが発生した際
      THE SYSTEM SHALL RFC 7807 Problem Details形式でレスポンスを返す

- [x] WHILE リクエストを処理する際
      THE SYSTEM SHALL pinoでリクエストログを記録する

- [x] WHILE リクエストを受け付ける際
      THE SYSTEM SHALL CORSを適切に設定する

- [x] WHEN GET /health にアクセスした際
      THEN 200 OK とサーバー状態を返す

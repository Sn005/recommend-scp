# Subtask 005-01-05: ヘルスチェックエンドポイント

## 概要

サーバーの稼働状態を確認するヘルスチェックエンドポイントを実装する。

## ステータス

- **status**: planned

## ユーザーストーリー

**As a** 運用担当者
**I want** サーバーの稼働状態を確認できる
**So that** 監視ツールやロードバランサーでヘルスチェックできる

## Acceptance Criteria（EARS記法）

- [ ] WHEN GET /health にアクセスした際
      GIVEN サーバーが正常に稼働している場合
      THEN 200 OK を返す
      AND 以下の情報を含むJSONを返す: - status: "ok" - timestamp: ISO 8601形式 - version: パッケージバージョン

- [ ] WHEN GET /health にアクセスした際
      GIVEN DBへの接続に問題がある場合
      THEN 503 Service Unavailable を返す
      AND status: "degraded" を返す

- [ ] WHILE ヘルスチェックを実行する際
      THE SYSTEM SHALL 認証なしでアクセス可能である

- [ ] WHILE ヘルスチェックを実行する際
      THE SYSTEM SHALL 100ms以内にレスポンスを返す

## 技術設計

### エンドポイント定義

```typescript
// apps/api-server/src/routes/health.ts
import { Hono } from "hono";
import { supabase } from "../lib/supabase";

const health = new Hono();

interface HealthResponse {
  status: "ok" | "degraded";
  timestamp: string;
  version: string;
  checks?: {
    database?: "ok" | "error";
  };
}

health.get("/", async (c) => {
  const response: HealthResponse = {
    status: "ok",
    timestamp: new Date().toISOString(),
    version: "0.0.1", // package.jsonから読み取り
  };

  // DB接続チェック（オプション）
  try {
    const { error } = await supabase.from("scp_articles").select("id").limit(1);
    if (error) throw error;
    response.checks = { database: "ok" };
  } catch {
    response.status = "degraded";
    response.checks = { database: "error" };
    return c.json(response, 503);
  }

  return c.json(response, 200);
});

export { health };
```

### app.tsへの統合

```typescript
import { Hono } from "hono";
import { health } from "./routes/health";

export const app = new Hono();

// ヘルスチェックは認証・ログ不要
app.route("/health", health);

// 他のルートは後続Subtaskで追加
```

## テストケース

- [ ] GET /health が200を返す
- [ ] レスポンスにstatus, timestamp, versionが含まれる
- [ ] DB接続エラー時に503を返す
- [ ] 100ms以内にレスポンスを返す
- [ ] 認証なしでアクセス可能

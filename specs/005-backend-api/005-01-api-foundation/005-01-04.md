# Subtask 005-01-04: CORSミドルウェア

## 概要

クロスオリジンリクエストを許可するCORS設定を実装する。

## ステータス

- **status**: completed

## ユーザーストーリー

**As a** フロントエンド開発者
**I want** 異なるオリジンからAPIを呼び出せる
**So that** Vercelでホストされたフロントエンドからアクセスできる

## Acceptance Criteria（EARS記法）

- [x] WHEN 許可されたオリジンからリクエストがあった際
      THEN Access-Control-Allow-Origin ヘッダーを設定する

- [x] WHEN プリフライトリクエスト（OPTIONS）があった際
      THEN 204 No Content を返す
      AND 必要なCORSヘッダーを設定する

- [x] WHERE CORS設定
      THE SYSTEM SHALL 以下を許可する: - Methods: GET, POST, PUT, DELETE, OPTIONS - Headers: Content-Type, X-Visitor-Id, Authorization - Credentials: true（将来のAuth対応）

- [x] WHEN 環境変数 ALLOWED_ORIGINS が設定されている際
      THEN 指定されたオリジンのみを許可する

- [x] WHEN 開発環境で ALLOWED_ORIGINS が未設定の際
      THEN localhost:3000 を許可する

## 技術設計

### ファイル構成

```
apps/api-server/src/middleware/
└── cors.ts
```

### middleware/cors.ts

```typescript
import { cors } from "hono/cors";
import { env } from "@recommend-scp/shared";

const getAllowedOrigins = (): string[] => {
  if (env.ALLOWED_ORIGINS) {
    return env.ALLOWED_ORIGINS.split(",").map((o) => o.trim());
  }
  // 開発環境のデフォルト
  return ["http://localhost:3000"];
};

export const corsMiddleware = cors({
  origin: getAllowedOrigins(),
  allowMethods: ["GET", "POST", "PUT", "DELETE", "OPTIONS"],
  allowHeaders: ["Content-Type", "X-Visitor-Id", "Authorization"],
  credentials: true,
  maxAge: 86400, // 24時間
});
```

### 環境変数

```bash
# .env
ALLOWED_ORIGINS=https://scpicks.vercel.app,http://localhost:3000
```

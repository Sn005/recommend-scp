# Subtask 005-01-02: RFC 7807エラーハンドリング

## 概要

RFC 7807 Problem Details形式のエラーレスポンスを実装する。

## ステータス

- **status**: completed

## ユーザーストーリー

**As a** APIクライアント開発者
**I want** 標準化されたエラーレスポンスを受け取る
**So that** エラーハンドリングを統一的に実装できる

## Acceptance Criteria（EARS記法）

- [x] WHERE APIエラーが発生した際
      THE SYSTEM SHALL 以下のフィールドを含むJSONを返す: - type: エラータイプURI - title: 人間可読なタイトル - status: HTTPステータスコード - detail: 詳細説明（オプション）- instance: 問題発生箇所（オプション）

- [x] WHEN Zodバリデーションエラーが発生した際
      THEN 400 Bad Request を返す
      AND type は "validation-error" を含む
      AND detail にバリデーションエラーの詳細を含む

- [x] WHEN リソースが見つからない際
      THEN 404 Not Found を返す
      AND type は "not-found" を含む

- [x] WHEN 予期しないエラーが発生した際
      THEN 500 Internal Server Error を返す
      AND スタックトレースはレスポンスに含めない
      AND エラー詳細はログに記録する

- [x] WHILE エラーレスポンスを返す際
      THE SYSTEM SHALL Content-Type: application/problem+json を設定する

### lib/problem-details.ts

```typescript
export interface ProblemDetails {
  type: string;
  title: string;
  status: number;
  detail?: string;
  instance?: string;
}

const BASE_URI = "https://recommend-scp.dev/errors";

export const ErrorTypes = {
  VALIDATION_ERROR: "validation-error",
  NOT_FOUND: "not-found",
  ONBOARDING_REQUIRED: "onboarding-required",
  INTERNAL_ERROR: "internal-error",
} as const;

export const createProblemDetails = (
  type: keyof typeof ErrorTypes,
  title: string,
  status: number,
  detail?: string,
  instance?: string
): ProblemDetails => ({
  type: `${BASE_URI}/${ErrorTypes[type]}`,
  title,
  status,
  detail,
  instance,
});
```

### middleware/error-handler.ts

```typescript
import type { ErrorHandler } from "hono";
import { HTTPException } from "hono/http-exception";
import { ZodError } from "zod";
import { createProblemDetails } from "../lib/problem-details";
import { logger } from "../lib/logger";

// Hono の app.onError() で使用するエラーハンドラー
export const createErrorHandler = (customLogger = logger): ErrorHandler => {
  return (error, c) => {
    if (error instanceof ZodError) {
      const detail = error.errors.map((e) => `${e.path.join(".")}: ${e.message}`).join(", ");
      return c.json(
        createProblemDetails("VALIDATION_ERROR", "Validation Error", 400, detail, c.req.path),
        400,
        { "Content-Type": "application/problem+json" }
      );
    }

    if (error instanceof HTTPException) {
      const status = error.status;
      const errorType = status === 404 ? "NOT_FOUND" : "INTERNAL_ERROR";
      return c.json(
        createProblemDetails(errorType, error.message, status, undefined, c.req.path),
        status,
        { "Content-Type": "application/problem+json" }
      );
    }

    // 予期しないエラー
    customLogger.error({ err: error, path: c.req.path }, "Unexpected error");
    return c.json(
      createProblemDetails("INTERNAL_ERROR", "Internal Server Error", 500, undefined, c.req.path),
      500,
      { "Content-Type": "application/problem+json" }
    );
  };
};

export const errorHandler = createErrorHandler();
```

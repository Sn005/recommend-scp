# Story 005-04: articles API

## 概要

ベクトル検索エンドポイント（GET /articles/search）を実装する。

## ステータス

- **status**: planned

## ユーザーストーリー

**As a** ユーザー
**I want** テキストクエリで記事を検索できる
**So that** 興味のあるSCP記事を見つけられる

## Acceptance Criteria（Story レベル）

- [ ] WHEN ユーザーが検索クエリを送信した際
      GIVEN 有効なクエリ文字列の場合
      THEN システムはクエリをEmbedding変換する
      AND ベクトル検索で類似記事を取得する
      AND 200ms以内にレスポンスを返す

- [ ] WHEN ユーザーが検索クエリを送信した際
      GIVEN limitパラメータを指定した場合
      THEN システムは指定件数以内の結果を返す

- [ ] WHEN ユーザーが検索クエリを送信した際
      GIVEN クエリが空または1文字未満の場合
      THEN システムはRFC 7807形式のエラーを返す

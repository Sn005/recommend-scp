# Subtask 005-04-02: GET /articles/search

## 概要

ベクトル検索エンドポイント（GET /articles/search）を実装する。

## ステータス

- **status**: completed

## ユーザーストーリー

**As a** ユーザー
**I want** GET /articles/search でテキスト検索できる
**So that** 興味のあるSCP記事を見つけられる

## Acceptance Criteria（EARS記法）

- [x] WHEN GET /articles/search?q=xxx に有効なクエリを送信した際
      THEN 200 OK を返す
      AND 類似度降順でソートされた記事リストを返す

- [x] WHEN GET /articles/search?q=xxx&limit=5 を送信した際
      THEN 最大5件の結果を返す

- [x] WHEN GET /articles/search にクエリなしでアクセスした際
      THEN 400 Bad Request を返す

- [x] WHEN GET /articles/search?q=a（1文字）を送信した際
      THEN 400 Bad Request を返す

- [x] WHILE 検索を実行する際
      THE SYSTEM SHALL 200ms以内にレスポンスを返す

## 技術設計

### schema.ts

```typescript
import { z } from "zod";

export const searchArticlesSchema = z.object({
  q: z.string().min(2, "Query must be at least 2 characters"),
  limit: z.coerce.number().min(1).max(50).optional().default(10),
});

export type SearchArticlesInput = z.infer<typeof searchArticlesSchema>;
```

### routes.ts

```typescript
import { Hono } from "hono";
import { zValidator } from "@hono/zod-validator";
import { searchArticlesSchema } from "./schema";
import { ArticlesService } from "./service";
import { ArticlesRepository } from "./repository";

export const createArticlesRoutes = (supabase: SupabaseClient) => {
  const articles = new Hono();
  const repository = new ArticlesRepository(supabase);
  const service = new ArticlesService(repository);

  articles.get("/search", zValidator("query", searchArticlesSchema), async (c) => {
    const { q, limit } = c.req.valid("query");
    const result = await service.searchArticles(q, { limit });
    return c.json(result, 200);
  });

  return articles;
};
```

# Subtask 005-08-01: api-typesパッケージ作成

## 概要

packages/api-typesパッケージを初期化する。

## ステータス

- **status**: completed

## ユーザーストーリー

**As a** モノレポ開発者
**I want** api-typesパッケージを持つ
**So that** API型定義を独立したパッケージとして管理できる

## Acceptance Criteria（EARS記法）

- [x] WHEN packages/api-typesディレクトリを作成した際
      THEN package.jsonが存在する
      AND name: "@recommend-scp/api-types"である

- [x] WHEN tsconfig.jsonを設定した際
      THEN 型定義のみをビルドする設定である
      AND declarationがtrueである

- [x] WHEN pnpm installを実行した際
      THEN @recommend-scp/api-typesがワークスペースで解決される

## 技術設計

### package.json

```json
{
  "name": "@recommend-scp/api-types",
  "version": "0.0.1",
  "private": true,
  "type": "module",
  "main": "./dist/index.js",
  "types": "./dist/index.d.ts",
  "exports": {
    ".": {
      "types": "./dist/index.d.ts",
      "import": "./dist/index.js"
    }
  },
  "scripts": {
    "build": "tsc",
    "type-check": "tsc --noEmit"
  },
  "dependencies": {
    "hono": "^4.0.0"
  },
  "devDependencies": {
    "typescript": "^5.0.0"
  }
}
```

### tsconfig.json

```json
{
  "extends": "../../tsconfig.base.json",
  "compilerOptions": {
    "outDir": "./dist",
    "rootDir": "./src",
    "declaration": true,
    "declarationMap": true,
    "emitDeclarationOnly": false
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "dist"]
}
```

# Story 005-02: サーバー側ストレージ

## 概要

EPIC-004で定義した `PreferenceStorage` / `VectorSearchClient` インターフェースの
Supabase実装を作成し、推薦ロジックをサーバー側で動作させる基盤を構築する。

## ステータス

- **status**: planned

## ユーザーストーリー

**As a** API開発者
**I want** 推薦ロジック（RecommendationEngine等）をサーバー側で使用できる
**So that** クライアントに依存せずに推薦計算を実行できる

## Acceptance Criteria（Story レベル）

- [ ] WHERE PreferenceStorageインターフェース

- [ ] WHERE VectorSearchClientインターフェース

      GIVEN サーバー側ストレージを注入する場合
      THEN 正常に推薦計算が動作する

- [ ] WHERE DBスキーマ

### インターフェース実装

```typescript
// PreferenceStorage実装
export class SupabasePreferenceStorage implements PreferenceStorage {
  constructor(private supabase: SupabaseClient) {}

  async getProfile(visitorId: string): Promise<PreferenceProfile | null> {
    const { data } = await this.supabase
      .from("visitors")
      .select("*")
      .eq("visitor_id", visitorId)
      .single();
    return data ? this.toProfile(data) : null;
  }
  // ...
}

// VectorSearchClient実装
export class SupabaseVectorSearch implements VectorSearchClient {
  constructor(private supabase: SupabaseClient) {}

  async searchByEmbedding(params: VectorSearchParams): Promise<VectorSearchResult[]> {
    const { data } = await this.supabase.rpc("search_articles_by_embedding", {
      query_vector: params.queryVector,
      exclude_ids: params.excludeIds ?? [],
      match_count: params.limit,
    });
    return data ?? [];
  }
  // ...
}
```

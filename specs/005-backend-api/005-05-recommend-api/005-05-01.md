# Subtask 005-05-01: recommend service

## 概要

RecommendationEngineと連携するサービス層を実装する。

## ステータス

- **status**: planned

## ユーザーストーリー

**As a** API開発者
**I want** RecommendationEngineをラップするサービス層を持つ
**So that** ルート層から簡潔に推薦ロジックを呼び出せる

## Acceptance Criteria（EARS記法）

- [ ] WHEN RecommendServiceをインスタンス化した際
      THEN SupabasePreferenceStorageとSupabaseVectorSearchを注入する
      AND RecommendationEngineを初期化する

- [ ] WHEN getRecommendationsを呼び出した際
      GIVEN 有効なvisitorIdとlimitの場合
      THEN RecommendationEngine.getRecommendationsを呼び出す
      AND 推薦記事リストを返す

- [ ] WHEN getRecommendationsを呼び出した際
      GIVEN オンボーディング未完了の場合
      THEN OnboardingRequiredErrorをスローする

- [ ] WHEN getRecommendationsを呼び出した際
      GIVEN visitorIdが未登録の場合
      THEN NotFoundErrorをスローする

## 技術設計

### service.ts

```typescript
import { RecommendationEngine, type RecommendedArticle } from "@recommend-scp/shared";
import { SupabasePreferenceStorage } from "../../lib/storage/supabase-preference-storage";
import { SupabaseVectorSearch } from "../../lib/search/supabase-vector-search";
import { VisitorsRepository } from "../visitors/repository";
import { OnboardingRequiredError, NotFoundError } from "../../lib/errors";

export class RecommendService {
  private engine: RecommendationEngine;
  private visitorsRepo: VisitorsRepository;

  constructor(supabase: SupabaseClient) {
    const storage = new SupabasePreferenceStorage(supabase);
    const vectorSearch = new SupabaseVectorSearch(supabase);
    this.engine = new RecommendationEngine(storage, vectorSearch);
    this.visitorsRepo = new VisitorsRepository(supabase);
  }

  async getRecommendations(visitorId: string, limit: number = 10): Promise<RecommendedArticle[]> {
    // visitorIdの存在確認
    const visitor = await this.visitorsRepo.findByVisitorId(visitorId);
    if (!visitor) {
      throw new NotFoundError("Visitor", visitorId);
    }

    // オンボーディング完了確認
    if (!visitor.onboardingCompletedAt) {
      throw new OnboardingRequiredError(visitorId);
    }

    return this.engine.getRecommendations(visitorId, limit);
  }

  async recordRecommendation(
    visitorId: string,
    articleId: string,
    source: "preference" | "serendipity"
  ): Promise<void> {
    await this.engine.recordRecommendation(visitorId, articleId, source);
  }
}
```

# Subtask 005-05-02: POST /recommend

## 概要

推薦取得エンドポイント（POST /recommend）を実装する。

## ステータス

- **status**: completed

## ユーザーストーリー

**As a** フロントエンドアプリケーション
**I want** POST /recommend で推薦記事を取得できる
**So that** ユーザーに推薦記事を表示できる

## Acceptance Criteria（EARS記法）

- [x] WHEN POST /recommend に有効なリクエストを送信した際
      GIVEN visitorIdが登録済みでオンボーディング完了の場合
      THEN 200 OK を返す
      AND 推薦記事リストを返す

- [x] WHEN POST /recommend を送信した際
      GIVEN visitorIdが未登録の場合
      THEN 404 Not Found を返す

- [x] WHEN POST /recommend を送信した際
      GIVEN オンボーディング未完了の場合
      THEN 400 Bad Request を返す
      AND エラータイプ onboarding-required を返す

- [x] WHILE 推薦を返す際
      THE SYSTEM SHALL 各記事にsource（preference/serendipity）を含める
      AND similarityScoreを含める

- [x] WHILE 推薦を処理する際
      THE SYSTEM SHALL 200ms以内にレスポンスを返す

## 技術設計

### schema.ts

```typescript
import { z } from "zod";

export const getRecommendationsSchema = z.object({
  visitorId: z.string().uuid(),
  limit: z.number().min(1).max(50).optional().default(10),
});

export type GetRecommendationsInput = z.infer<typeof getRecommendationsSchema>;
```

### routes.ts

```typescript
import { Hono } from "hono";
import { zValidator } from "@hono/zod-validator";
import { getRecommendationsSchema } from "./schema";
import { RecommendService } from "./service";
import { OnboardingRequiredError, NotFoundError } from "../../lib/errors";

export const createRecommendRoutes = (supabase: SupabaseClient) => {
  const recommend = new Hono();
  const service = new RecommendService(supabase);

  recommend.post("/", zValidator("json", getRecommendationsSchema), async (c) => {
    const { visitorId, limit } = c.req.valid("json");

    try {
      const recommendations = await service.getRecommendations(visitorId, limit);
      return c.json(
        {
          recommendations,
          count: recommendations.length,
        },
        200
      );
    } catch (error) {
      if (error instanceof NotFoundError) {
        throw error; // エラーハンドラーで処理
      }
      if (error instanceof OnboardingRequiredError) {
        throw error;
      }
      throw error;
    }
  });

  return recommend;
};
```

# Subtask 005-07-02: GET/POST onboarding

## 概要

オンボーディングエンドポイント（GET /onboarding/packs, POST /onboarding/select）を実装する。

## ステータス

- **status**: completed

## ユーザーストーリー

**As a** フロントエンドアプリケーション
**I want** オンボーディングAPIを呼び出せる
**So that** ユーザーに初期設定画面を提供できる

## Acceptance Criteria（EARS記法）

- [x] WHEN GET /onboarding/packs にアクセスした際
      THEN 200 OK を返す
      AND 5種類のスターターパック情報を返す

- [x] WHEN POST /onboarding/select でパック選択した際
      GIVEN 有効なvisitorIdとpackTypeの場合
      THEN 200 OK を返す
      AND プロファイルが初期化される

- [x] WHEN POST /onboarding/select/custom でカスタム選択した際
      GIVEN 有効なvisitorIdと3件以上のarticleIdsの場合
      THEN 200 OK を返す
      AND プロファイルが初期化される

- [x] WHEN POST /onboarding/select/custom でカスタム選択した際
      GIVEN 3件未満のarticleIdsの場合
      THEN 400 Bad Request を返す

- [x] WHILE パック一覧を返す際
      THE SYSTEM SHALL CDNキャッシュ可能なレスポンスヘッダーを設定する

## 技術設計

### schema.ts

```typescript
import { z } from "zod";

export const selectPackSchema = z.object({
  visitorId: z.string().uuid(),
  packType: z.enum(["horror", "surreal", "scientific", "heartwarming", "mystery"]),
});

export const selectCustomSchema = z.object({
  visitorId: z.string().uuid(),
  articleIds: z.array(z.string()).min(3, "At least 3 articles must be selected"),
});

export type SelectPackInput = z.infer<typeof selectPackSchema>;
export type SelectCustomInput = z.infer<typeof selectCustomSchema>;
```

### routes.ts

```typescript
import { Hono } from "hono";
import { zValidator } from "@hono/zod-validator";
import { selectPackSchema, selectCustomSchema } from "./schema";
import { OnboardingApiService } from "./service";

export const createOnboardingRoutes = (supabase: SupabaseClient) => {
  const onboarding = new Hono();
  const service = new OnboardingApiService(supabase);

  // スターターパック一覧
  onboarding.get("/packs", async (c) => {
    const packs = service.getStarterPacks();

    // CDNキャッシュ可能に設定
    c.header("Cache-Control", "public, max-age=3600");

    return c.json({ packs }, 200);
  });

  // パック選択
  onboarding.post("/select", zValidator("json", selectPackSchema), async (c) => {
    const { visitorId, packType } = c.req.valid("json");
    await service.selectPack(visitorId, packType);

    return c.json(
      {
        success: true,
        visitorId,
        packType,
      },
      200
    );
  });

  // カスタム選択
  onboarding.post("/select/custom", zValidator("json", selectCustomSchema), async (c) => {
    const { visitorId, articleIds } = c.req.valid("json");
    await service.selectCustom(visitorId, articleIds);

    return c.json(
      {
        success: true,
        visitorId,
        articleCount: articleIds.length,
      },
      200
    );
  });

  return onboarding;
};
```

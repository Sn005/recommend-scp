# Subtask 005-07-01: onboarding service

## 概要

OnboardingServiceと連携するサービス層を実装する。

## ステータス

- **status**: planned

## ユーザーストーリー

**As a** API開発者
**I want** OnboardingServiceをラップするサービス層を持つ
**So that** ルート層から簡潔にオンボーディングロジックを呼び出せる

## Acceptance Criteria（EARS記法）

- [ ] WHEN getStarterPacksを呼び出した際
      THEN 5種類のスターターパック情報を返す
      AND 各パックにtype, displayName, description, primaryTagsを含める

- [ ] WHEN selectPackを呼び出した際
      GIVEN 有効なvisitorIdとpackTypeの場合
      THEN OnboardingService.initializeProfileを呼び出す
      AND visitorsテーブルのpreference_vectorを更新する
      AND onboarding_completed_atを設定する

- [ ] WHEN selectCustomを呼び出した際
      GIVEN 有効なvisitorIdと3件以上のarticleIdsの場合
      THEN 選択記事のEmbedding平均から初期プロファイルを生成する
      AND onboarding_completed_atを設定する

- [ ] WHEN selectCustomを呼び出した際
      GIVEN 3件未満のarticleIdsの場合
      THEN ValidationErrorをスローする

## 技術設計

### service.ts

```typescript
import {
  OnboardingService as SharedOnboardingService,
  StarterPacks,
  type StarterPackType,
} from "@recommend-scp/shared";
import { SupabasePreferenceStorage } from "../../lib/storage/supabase-preference-storage";
import { SupabaseVectorSearch } from "../../lib/search/supabase-vector-search";
import { VisitorsRepository } from "../visitors/repository";
import { NotFoundError, ValidationError } from "../../lib/errors";

export interface StarterPackInfo {
  type: StarterPackType;
  displayName: string;
  description: string;
  primaryTags: string[];
}

export class OnboardingApiService {
  private sharedService: SharedOnboardingService;
  private visitorsRepo: VisitorsRepository;

  constructor(supabase: SupabaseClient) {
    const storage = new SupabasePreferenceStorage(supabase);
    const vectorSearch = new SupabaseVectorSearch(supabase);
    this.sharedService = new SharedOnboardingService(storage, vectorSearch);
    this.visitorsRepo = new VisitorsRepository(supabase);
  }

  getStarterPacks(): StarterPackInfo[] {
    return StarterPacks.map((pack) => ({
      type: pack.type,
      displayName: pack.displayName,
      description: pack.description,
      primaryTags: pack.primaryTags,
    }));
  }

  async selectPack(visitorId: string, packType: StarterPackType): Promise<void> {
    const visitor = await this.visitorsRepo.findByVisitorId(visitorId);
    if (!visitor) {
      throw new NotFoundError("Visitor", visitorId);
    }

    await this.sharedService.initializeProfile(visitorId, packType);
  }

  async selectCustom(visitorId: string, articleIds: string[]): Promise<void> {
    if (articleIds.length < 3) {
      throw new ValidationError("At least 3 articles must be selected");
    }

    const visitor = await this.visitorsRepo.findByVisitorId(visitorId);
    if (!visitor) {
      throw new NotFoundError("Visitor", visitorId);
    }

    await this.sharedService.initializeProfileFromArticles(visitorId, articleIds);
  }
}
```

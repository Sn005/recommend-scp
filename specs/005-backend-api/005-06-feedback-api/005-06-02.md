# Subtask 005-06-02: POST /feedback

## 概要

フィードバック記録エンドポイント（POST /feedback）を実装する。

## ステータス

- **status**: completed

## ユーザーストーリー

**As a** フロントエンドアプリケーション
**I want** POST /feedback でLike/Dislikeを記録できる
**So that** ユーザーの嗜好を収集できる

## Acceptance Criteria（EARS記法）

- [x] WHEN POST /feedback に有効なリクエストを送信した際
      THEN 200 OK を返す
      AND フィードバックが記録される

- [x] WHEN POST /feedback を送信した際
      GIVEN visitorIdが未登録の場合
      THEN 404 Not Found を返す

- [x] WHEN POST /feedback を送信した際
      GIVEN typeがlike/dislike以外の場合
      THEN 400 Bad Request を返す

- [x] WHEN 同じvisitorId+articleIdで再度フィードバックした際
      THEN 既存のフィードバックを上書きする
      AND 200 OK を返す

## 技術設計

### schema.ts

```typescript
import { z } from "zod";

export const recordFeedbackSchema = z.object({
  visitorId: z.string().uuid(),
  articleId: z.string().min(1),
  type: z.enum(["like", "dislike"]),
});

export type RecordFeedbackInput = z.infer<typeof recordFeedbackSchema>;
```

### routes.ts

```typescript
import { Hono } from "hono";
import { zValidator } from "@hono/zod-validator";
import { recordFeedbackSchema } from "./schema";
import { FeedbackService } from "./service";
import { FeedbackRepository } from "./repository";
import { VisitorsRepository } from "../visitors/repository";

export const createFeedbackRoutes = (supabase: SupabaseClient) => {
  const feedback = new Hono();
  const feedbackRepo = new FeedbackRepository(supabase);
  const visitorsRepo = new VisitorsRepository(supabase);
  const service = new FeedbackService(feedbackRepo, visitorsRepo);

  feedback.post("/", zValidator("json", recordFeedbackSchema), async (c) => {
    const { visitorId, articleId, type } = c.req.valid("json");
    await service.recordFeedback(visitorId, articleId, type);

    return c.json(
      {
        success: true,
        visitorId,
        articleId,
        type,
      },
      200
    );
  });

  return feedback;
};
```

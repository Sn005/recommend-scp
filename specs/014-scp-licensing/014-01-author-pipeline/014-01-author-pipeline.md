# Story: 著者情報データパイプライン対応

## 親EPIC

[014: SCPライセンス・帰属表示](../014-scp-licensing.md)

## ユーザーストーリー

**ペルソナ**: 開発者
**目的**: SCP記事の著者情報をDBに保存し、帰属表示に利用できるようにする
**価値**: CC BY-SA 3.0の帰属要件を満たすデータ基盤を構築する
**理由**: 著者名表示にはデータパイプラインでの取得・保存が前提となるから

> 開発者として、SCP記事の著者情報をDBに保存し帰属表示に利用できるようにしたい。なぜなら著者名表示にはデータパイプラインでの取得・保存が前提となるから。

## Acceptance Criteria

- [ ] `scp_articles` テーブルに `author` TEXT カラムが追加されていること
- [ ] クローラーがSCP Data APIの `creator` フィールドを `author` にマッピングして保存すること
- [ ] 既存データに対してバックフィルスクリプトで著者情報が補完されること

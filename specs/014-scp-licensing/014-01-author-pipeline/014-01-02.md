# Subtask: クローラー型定義・マッピング修正

## 親Story

[014-01: 著者情報データパイプライン対応](./014-01-author-pipeline.md)

## ユーザーストーリー

**ペルソナ**: 開発者
**目的**: クローラーがSCP Data APIの `creator` フィールドを取得し、DBに保存するようにする
**価値**: 新規クロール時に著者情報が自動的に取得・保存される
**理由**: 手動での著者情報登録は非現実的であり、自動化が必要であるから

> 開発者として、クローラーがSCP Data APIの `creator` フィールドを取得しDBに保存するようにして、新規クロール時に著者情報が自動取得されるようにしたい。なぜなら手動での著者情報登録は非現実的であり自動化が必要であるから。

## Acceptance Criteria

- [x] WHEN クローラーがSCP Data APIから記事を取得した際
      GIVEN APIレスポンスに `creator` フィールドが存在する場合
      THEN `ArticleContent.author` に値がマッピングされる

- [x] WHEN クローラーが記事をDBに保存する際
      GIVEN `ArticleContent.author` に値がある場合
      THEN `scp_articles.author` カラムに保存される

- [x] WHEN クローラーが記事をDBに保存する際
      GIVEN `ArticleContent.author` が undefined の場合
      THEN `scp_articles.author` カラムは NULL で保存される

## 設計

### 変更対象ファイル

1. **`packages/pipeline/src/crawler/types.ts`**
   - `ArticleContent` インターフェースに `author?: string` を追加
   - `ArticleForDb` インターフェースに `author?: string` を追加

2. **`packages/pipeline/src/crawler/english-crawler.ts`**
   - `fetchArticleContent()` で `creator` → `author` のマッピングを追加

3. **`packages/pipeline/src/crawler/utils/db-saver.ts`**
   - `ArticleForDb` に `author` フィールドを含めて保存

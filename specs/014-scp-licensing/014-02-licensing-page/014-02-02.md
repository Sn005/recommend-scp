# Subtask: ドロワーメニューにライセンス項目追加

## 親Story

[014-02: ライセンスページ・ナビゲーション](./014-02-licensing-page.md)

## ユーザーストーリー

**ペルソナ**: SCP記事を閲覧するゲストユーザー
**目的**: ドロワーメニューからライセンスページにアクセスする
**価値**: アプリ内のどの画面からでもライセンス情報にアクセスできる
**理由**: ライセンス情報へのアクセス導線がなければユーザーが見つけられないから

> ゲストユーザーとして、ドロワーメニューからライセンスページにアクセスして、どの画面からでもライセンス情報を確認したい。なぜならライセンス情報へのアクセス導線がなければユーザーが見つけられないから。

## Acceptance Criteria

- [x] WHEN ユーザーがドロワーメニューを開いた際
      THEN 「ライセンス」項目が区切り線の下、リセットボタンの上に表示される
      AND `file-text` アイコンが使用されている

- [x] WHEN ユーザーが「ライセンス」項目をタップした際
      THEN `/licensing` ページに遷移する
      AND ドロワーが閉じる

- [x] WHEN ユーザーが `/licensing` ページにいる際
      THEN ドロワーメニューの「ライセンス」項目がアクティブ状態で表示される

```

お気に入り一覧 (/favorites)
閲覧履歴 (/history)
──────────────  ← 既存の区切り線
ライセンス (/licensing)  ← 追加
```

- アクティブ状態のスタイリングは既存パターンに準拠（`usePathname()` で判定）

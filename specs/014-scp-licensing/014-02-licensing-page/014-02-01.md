# Subtask: ライセンスページUI実装

## 親Story

[014-02: ライセンスページ・ナビゲーション](./014-02-licensing-page.md)

## ユーザーストーリー

**ペルソナ**: SCP記事を閲覧するゲストユーザー
**目的**: ライセンス情報を一覧できるページを閲覧する
**価値**: アプリのコードとSCPコンテンツのライセンスを明確に理解できる
**理由**: ライセンスの透明性はユーザーの信頼と法的要件の両方を満たすから

> ゲストユーザーとして、ライセンス情報を一覧できるページを閲覧して、アプリのコードとSCPコンテンツのライセンスを明確に理解したい。なぜならライセンスの透明性はユーザーの信頼と法的要件の両方を満たすから。

## Acceptance Criteria

- [x] WHEN ユーザーが `/licensing` にアクセスした際
      THEN 以下のセクションが表示される: 1. アプリコードのライセンス情報（GPLv3）2. SCPコンテンツのライセンス情報（CC BY-SA 3.0）3. SCP Foundation / SCP Data API へのクレジット 4. 各ライセンス全文への外部リンク

- [x] WHEN ユーザーがライセンス全文リンクをタップした際
      THEN 外部ブラウザでライセンス全文ページが開く

- [x] WHEN ユーザーがライセンスページを表示した際
      THEN MenuButtonが画面上に表示される
      AND ドロワーメニューが開閉できる（(main)レイアウト適用済み）

## 設計

### ファイル配置

```
apps/web/src/app/(main)/licensing/page.tsx
```

### 表示内容

| セクション     | 内容                                                                                      |
| -------------- | ----------------------------------------------------------------------------------------- |
| アプリコード   | 「このアプリケーションは GPLv3 ライセンスの下で提供されています」+ GitHubリポジトリリンク |
| SCPコンテンツ  | 「SCP Foundationのコンテンツは CC BY-SA 3.0 ライセンスの下で提供されています」            |
| SCP Data API   | 「記事データは tedivm/scp-data を通じて取得しています」                                   |
| ライセンス全文 | CC BY-SA 3.0 / GPLv3 の外部リンク                                                         |

### 外部リンク

- CC BY-SA 3.0: `https://creativecommons.org/licenses/by-sa/3.0/`
- GPLv3: `https://www.gnu.org/licenses/gpl-3.0.html`
- SCP Foundation: `https://scp-wiki.wikidot.com/`
- SCP Data API: `https://github.com/tedivm/scp-data`

### 技術的考慮事項

- 静的ページ（API呼び出し不要）
- `(main)` ルートグループ配置でドロワー・OnboardingGuard対応
- 外部リンクは `target="_blank" rel="noopener noreferrer"` で開く

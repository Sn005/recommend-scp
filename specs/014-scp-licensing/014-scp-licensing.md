# EPIC: SCPライセンス・帰属表示

## ユーザーストーリー

**ペルソナ**: SCP記事を閲覧するゲストユーザー
**目的**: SCP Foundationコンテンツのライセンス情報と著者帰属を確認する
**価値**: ライセンス準拠を果たし、原著者への正当なクレジットを提供する
**理由**: SCPコンテンツはCC BY-SA 3.0の継承義務があり、帰属表示は法的要件であるから

> ゲストユーザーとして、SCP Foundationコンテンツのライセンス情報と著者帰属を確認して、ライセンス準拠を果たし原著者への正当なクレジットを得たい。なぜならSCPコンテンツはCC BY-SA 3.0の継承義務があり帰属表示は法的要件であるから。

## Acceptance Criteria

- [ ] ライセンスページでアプリコード（GPLv3）とSCPコンテンツ（CC BY-SA 3.0）のライセンス情報が表示されること
- [ ] ドロワーメニューからライセンスページにアクセスできること
- [ ] 記事閲覧時に帰属表示（ライセンス・原文リンク・著者名）が表示されること
- [ ] 著者情報がデータパイプラインで取得・保存されていること

## 備考

- SCP Foundationコンテンツは CC BY-SA 3.0 ライセンスで提供されている
- SCP Data API（tedivm/scp-data）の `creator` フィールドを著者情報として利用
- アプリコード自体は GPLv3 ライセンス
- 著者情報が取得できない記事では著者名を省略して表示する

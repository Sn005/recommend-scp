# Story: 運用Runbook整備

## 親EPIC

[008: 運用・監視](../008-observability.md)

## ユーザーストーリー

**ペルソナ**: 開発者・運用者
**目的**: 障害発生時に参照できるトラブルシューティングチェックリストを整備する
**価値**: 障害対応を迅速かつ漏れなく実施できる
**理由**: 障害時にパニックにならず、手順に沿って対応するためのガイドが必要

> 開発者・運用者として、障害発生時に参照できるトラブルシューティングチェックリストを整備したい。なぜなら障害時に手順に沿って迅速かつ漏れなく対応するためのガイドが必要だから。

## Acceptance Criteria

- [x] トラブルシューティングチェックリストが `docs/operations/runbook.md` に存在する
- [x] 「APIがダウンしたとき」の確認手順が記載されている
- [x] 「パイプラインが失敗したとき」の確認手順が記載されている
- [x] 「DBが応答しないとき」の確認手順が記載されている

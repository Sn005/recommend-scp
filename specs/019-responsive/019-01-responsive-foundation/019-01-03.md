# Subtask 019-01-03: MainLayoutレスポンシブ対応

## 概要

`(main)/layout.tsx` にGlobalHeaderを統合し、既存のMenuButton・Drawerをmd:hiddenにする。PC版ではヘッダー分のpadding-topを適用する。

## ステータス

- **status**: pending

## 親Story

[019-01: 共通レスポンシブ基盤](./019-01.md)

## ユーザーストーリー

**ペルソナ**: PCブラウザでSCPicksを利用するユーザー
**目的**: PC版ではグローバルヘッダーでナビゲーションし、モバイル版では従来通りドロワーを使う
**価値**: デバイスに応じた最適なナビゲーション体験を得られる
**理由**: PCとモバイルでは最適なナビゲーションパターンが異なるから

> PCブラウザのユーザーとして、PC版ではグローバルヘッダーでナビゲーションしたい。なぜならPCではヘッダーナビが標準的なパターンだから。

## Acceptance Criteria（EARS記法）

### AC-1: GlobalHeader統合

- [ ] WHEN MainLayoutを描画する際
      THEN GlobalHeaderコンポーネントをレイアウトに含める
      AND GlobalHeaderは `hidden md:flex` で768px以上のみ表示される

### AC-2: MenuButton非表示（PC版）

- [ ] WHEN 画面幅が768px以上の場合
      THEN MenuButtonに `md:hidden` を適用して非表示にする
      AND 768px未満では従来通り表示する

### AC-3: Drawer非表示（PC版）

- [ ] WHEN 画面幅が768px以上の場合
      THEN Drawerのオーバーレイとナビゲーションパネルに `md:hidden` を適用する
      AND 768px未満では従来通り動作する

### AC-4: メインコンテンツpadding

- [ ] WHEN 画面幅が768px以上の場合
      THEN メインコンテンツ領域にpadding-top: 56px（`md:pt-14`）を適用する
      AND 768px未満ではpadding-topを追加しない

### AC-5: 既存機能の非破壊

- [ ] WHERE MainLayoutの変更後
      THE SYSTEM SHALL モバイル版の全ページ（推薦・お気に入り・履歴）が既存通り動作する
      AND ドロワーの開閉・メニューボタンのドラッグが768px未満で正常動作する

### MainLayout変更イメージ

```typescript
// (main)/layout.tsx
import { GlobalHeader } from "@/shared/components/ui/GlobalHeader";

export default function MainLayout({ children }: { children: React.ReactNode }) {
  return (
    <DrawerProvider>
      <OnboardingGuard>
        <GlobalHeader />
        <MenuButton /> {/* 内部で md:hidden 適用 */}
        <Drawer />     {/* 内部で md:hidden 適用 */}
        <main className="md:pt-14">
          {children}
        </main>
      </OnboardingGuard>
    </DrawerProvider>
  );
}
```

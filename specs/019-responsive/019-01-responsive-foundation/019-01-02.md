# Subtask 019-01-02: DropdownMenuコンポーネント

## 概要

GlobalHeader右端の3点メニューから開くドロップダウンメニューを新規作成する。ライセンス表示と推薦リセットの2項目を含む。

## ステータス

- **status**: completed

## 親Story

[019-01: 共通レスポンシブ基盤](./019-01.md)

## ユーザーストーリー

**ペルソナ**: PCブラウザでSCPicksを利用するユーザー
**目的**: ヘッダーの3点メニューからライセンス確認や推薦リセットを行う
**価値**: メインナビに含めない補助機能に簡単にアクセスできる
**理由**: ライセンスやリセットは頻繁に使わないため、3点メニュー内に収めるのが適切だから

> PCブラウザのユーザーとして、ヘッダーの3点メニューからライセンス確認や推薦リセットにアクセスしたい。なぜなら補助的な機能はメインナビから分離して整理されている方が分かりやすいから。

## Acceptance Criteria（EARS記法）

### AC-1: ドロップダウン表示

- [x] WHEN 3点メニューボタンをクリックした場合
      THEN ドロップダウンメニューをボタン直下に表示する
      AND min-width: 200px、border-radius: 12px、shadow: glass（`0 4px 24px rgba(0,0,0,0.12)`）を適用する
      AND 背景白、ボーダー `1px solid #e5e7eb` を適用する

### AC-2: メニュー項目

- [x] WHEN ドロップダウンメニューが表示されている場合
      THEN 「ライセンス」（file-textアイコン）と「推薦をリセット」（refresh-cwアイコン）を表示する
      AND 各項目のpadding: `10px 14px`、border-radius: 8px、font-size: 14pxとする
      AND ホバー時に背景 `#f3f4f6` を適用する
      AND 2項目間にdivider（1px, #e5e7eb）を配置する

### AC-3: ドロップダウン閉じる

- [x] WHEN ドロップダウンメニューが表示されている場合
      GIVEN ユーザーがメニュー外をクリックした場合
      THEN ドロップダウンメニューを閉じる

- [x] WHEN ドロップダウンメニューが表示されている場合
      GIVEN ユーザーがEscキーを押した場合
      THEN ドロップダウンメニューを閉じる

### AC-4: アクセシビリティ（WAI-ARIA）

- [x] WHEN 3点メニューボタンが描画される際
      THEN `aria-haspopup="true"` と `aria-expanded` 属性をボタンに付与する
      AND ドロップダウンが開いている場合は `aria-expanded="true"`、閉じている場合は `aria-expanded="false"` とする

- [x] WHEN ドロップダウンメニューが表示されている場合
      THEN メニューコンテナに `role="menu"` を付与する
      AND 各メニュー項目に `role="menuitem"` を付与する
      AND Tabキーでメニュー項目間を移動できる

### AC-5: ライセンスリンク

- [x] WHEN 「ライセンス」をクリックした場合
      THEN `/licensing` ページに遷移する
      AND ドロップダウンメニューを閉じる

### AC-6: 推薦リセット

- [x] WHEN 「推薦をリセット」をクリックした場合
      THEN 既存のResetConfirmDialogを表示する
      AND ドロップダウンメニューを閉じる

### コンポーネント設計

```typescript
// DropdownMenu.tsx
"use client";

import { useState, useRef, useEffect } from "react";

export function DropdownMenu() {
  const [isOpen, setIsOpen] = useState(false);
  const menuRef = useRef<HTMLDivElement>(null);

  // 外部クリック検知
  useEffect(() => {
    if (!isOpen) return;
    const handleClickOutside = (e: MouseEvent) => {
      if (menuRef.current && !menuRef.current.contains(e.target as Node)) {
        setIsOpen(false);
      }
    };
    document.addEventListener("mousedown", handleClickOutside);
    return () => document.removeEventListener("mousedown", handleClickOutside);
  }, [isOpen]);

  // Escキー検知
  useEffect(() => {
    if (!isOpen) return;
    const handleEsc = (e: KeyboardEvent) => {
      if (e.key === "Escape") setIsOpen(false);
    };
    document.addEventListener("keydown", handleEsc);
    return () => document.removeEventListener("keydown", handleEsc);
  }, [isOpen]);
}
```

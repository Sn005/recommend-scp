# Subtask 019-03-01: お気に入りPC版レイアウト

## 概要

お気に入り画面のPC版（≥768px）レイアウトとして、カードリストのmax-width中央寄せ、カードのホバーエフェクト（浮き上がり + shadow強化）、padding調整を実装する。

## ステータス

- **status**: completed

## 親Story

[019-03: お気に入り画面レスポンシブ対応](./019-03.md)

## ユーザーストーリー

**ペルソナ**: PCブラウザでSCPicksを利用するユーザー
**目的**: お気に入り記事一覧をPC画面で見やすく操作しやすいレイアウトで閲覧する
**価値**: ホバーでカードの反応があり、適切な余白で一覧性が高い
**理由**: PCではマウスポインタを使うため、ホバーフィードバックが操作の確信を与えるから

> PCブラウザのユーザーとして、お気に入り一覧をPC最適化されたレイアウトで閲覧し、カードホバーで視覚的フィードバックを得たい。なぜならPCではホバーエフェクトが操作性を向上させるから。

## Acceptance Criteria（EARS記法）

### AC-1: コンテンツ中央寄せ

- [x] WHEN お気に入り画面をPC（≥768px）で表示する場合
      THEN お気に入りリスト全体をmax-width: 768pxで中央寄せする（`md:max-w-[768px] md:mx-auto`）

### AC-2: カードホバーエフェクト（PC版≥768pxのみ）

- [x] WHEN PC版（≥768px）でお気に入りカードにマウスホバーした場合
      THEN カードが `translateY(-2px)` で浮き上がる（`md:hover:-translate-y-0.5`）
      AND box-shadowが `0 4px 12px rgba(0,0,0,0.1)` に強化される
      AND transition: `all 0.2s ease` でスムーズに変化する

- [x] WHEN モバイル版（<768px）でカードをタップまたは長押しした場合
      THEN ホバーエフェクト（浮き上がり・shadow強化）は発生しない

### AC-3: カードパディング調整

- [x] WHEN お気に入り画面をPC（≥768px）で表示する場合
      THEN カードのpaddingを20px（`md:p-5`）にする
      AND カード間のgapを12px（`md:gap-3`）にする

### AC-4: ページタイトル調整

- [x] WHEN お気に入り画面をPC（≥768px）で表示する場合
      THEN ページタイトル「お気に入り」のpadding-leftを16pxにする（メニューボタン回避不要）

### AC-5: モバイル非破壊

- [x] WHERE お気に入り画面の変更後
      THE SYSTEM SHALL モバイル版（<768px）の全機能が既存通り動作する
      AND カードの表示・削除アニメーション・ナビゲーションが正常に動作する

# Story 019-02: 推薦画面レスポンシブ対応

## 親EPIC

[019: レスポンシブデザイン対応](../019-responsive.md)

## 概要

推薦画面にPC版レイアウト（サイドパネル付き3カラム、記事中央寄せ、テキストアクションボタン）を追加する。

## ステータス

- **status**: completed

## ユーザーストーリー

> PCブラウザのユーザーとして、推薦記事を768px幅の読みやすいカラムで閲覧し、記事下のボタンでお気に入り/次の記事操作をしたい。なぜならPC画面全幅に広がった記事は読みにくく、フローティングPillNavはPCでは操作性が低いから。

## Acceptance Criteria

### AC-1: サイドパネル付き3カラムレイアウト

- [x] WHEN 推薦画面をPC（≥768px）で表示する場合
      THEN 記事コンテンツをmax-width: 768pxで中央寄せし、左右にグレー背景のサイドパネルを表示する

### AC-2: PCアクションボタン

- [x] WHEN 推薦画面をPC（≥768px）で表示する場合
      THEN PillNav（フローティング下部ナビ）を非表示にし、記事下部にテキストボタンを表示する

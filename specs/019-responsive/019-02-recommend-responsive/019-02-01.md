# Subtask 019-02-01: サイドパネル＆コンテンツ中央寄せ

## 概要

推薦画面のPC版レイアウトとして、記事コンテンツをmax-width: 768pxで中央寄せし、左右にグレー背景（#F3F4F6）+ inset shadowのサイドパネルを配置する3カラム構成を実装する。

## ステータス

- **status**: pending

## 親Story

[019-02: 推薦画面レスポンシブ対応](./019-02.md)

## ユーザーストーリー

**ペルソナ**: PCブラウザでSCPicksを利用するユーザー
**目的**: PC画面で記事を適切な幅で読みやすく表示する
**価値**: 長い行を読む必要がなく、書籍のような快適な読書体験を得られる
**理由**: 全幅の記事は目の移動距離が長くなり読みにくいから

> PCブラウザのユーザーとして、記事コンテンツを768px幅の中央カラムで読みたい。なぜなら全幅表示では行が長すぎて読みにくいから。

## Acceptance Criteria（EARS記法）

### AC-1: 3カラムレイアウト

- [ ] WHEN 推薦画面をPC（≥768px）で表示する場合
      THEN コンテンツを `flex` の3カラム構成にする
      AND 中央カラムのmax-width: 768px、flex-shrink: 0とする
      AND 左右カラムは `flex-1` で残りスペースを均等に埋める

### AC-2: サイドパネルスタイル

- [ ] WHEN 推薦画面をPC（≥768px）で表示する場合
      THEN サイドパネルの背景を `#f3f4f6`（gray-100）にする
      AND 左パネルに `inset -1px 0 3px rgba(0,0,0,0.06)`、右パネルに `inset 1px 0 3px rgba(0,0,0,0.06)` のbox-shadowを適用する

### AC-3: モバイル非表示

- [ ] WHEN 画面幅が768px未満の場合
      THEN サイドパネルを非表示にする（`hidden md:block`）
      AND 記事コンテンツは従来通り全幅表示する

### AC-4: 高さ

- [ ] WHEN 推薦画面をPC（≥768px）で表示する場合
      THEN 3カラムレイアウトの最小高さを `calc(100vh - 56px)` とする（ヘッダー分を除く）

## 技術設計

### 実装箇所

推薦画面の `page.tsx` のレンダリング部分をラッパーで囲む:

```typescript
// recommend/page.tsx 内
<div className="md:flex md:min-h-[calc(100vh-56px)]">
  {/* 左サイドパネル */}
  <div className="hidden md:block flex-1 bg-gray-100"
       style={{ boxShadow: "inset -1px 0 3px rgba(0,0,0,0.06)" }} />

  {/* 中央コンテンツ */}
  <div className="w-full md:max-w-[768px] md:shrink-0">
    {/* 既存の記事表示コンテンツ */}
  </div>

  {/* 右サイドパネル */}
  <div className="hidden md:block flex-1 bg-gray-100"
       style={{ boxShadow: "inset 1px 0 3px rgba(0,0,0,0.06)" }} />
</div>
```

# Subtask 019-02-02: PCアクションボタン

## 概要

推薦画面のPC版（≥768px）で、モバイル向けPillNav（フローティング下部ナビ）の代わりにテキストベースのアクションボタン（お気に入り/次の記事）を記事下部に表示する。

## ステータス

- **status**: pending

## 親Story

[019-02: 推薦画面レスポンシブ対応](./019-02.md)

## ユーザーストーリー

**ペルソナ**: PCブラウザでSCPicksを利用するユーザー
**目的**: 記事を読んだ後にお気に入り登録や次の記事への遷移を行う
**価値**: PCに適したテキストボタンで明確に操作できる
**理由**: フローティングPillNavはモバイルのタッチ操作に最適化されており、PCではテキスト付きボタンの方が操作意図が明確だから

> PCブラウザのユーザーとして、記事下部のテキストボタンでお気に入り/次の記事操作をしたい。なぜならPCではアイコンのみのフローティングボタンよりテキスト付きボタンの方が分かりやすいから。

## Acceptance Criteria（EARS記法）

### AC-1: PillNav非表示（PC版）

- [ ] WHEN 推薦画面をPC（≥768px）で表示する場合
      THEN FloatingUI（PillNav含む）に `md:hidden` を適用して非表示にする
      AND 768px未満では従来通りPillNavを表示する

### AC-2: PCアクションボタン表示

- [ ] WHEN 推薦画面をPC（≥768px）で表示する場合
      THEN 記事下部に「お気に入り」「次の記事へ」のテキストボタンを横並びで表示する（`hidden md:flex`）
      AND ボタン間のgap: 12px、中央寄せ、margin-top: 20px、padding: 0 16pxとする

### AC-3: お気に入りボタンスタイル（PC版≥768pxのみ表示）

- [ ] WHEN PC版でお気に入りボタンが未登録状態の場合
      THEN 背景白、文字色 `#6b7280`、ボーダー `1px solid #e5e7eb` で表示する
      AND マウスホバー時にボーダー `#ef4444`、文字色 `#ef4444`、背景 `#fef2f2` にする（`md:hover:` で適用）

- [ ] WHEN PC版でお気に入りボタンが登録済み状態の場合
      THEN 背景 `#fef2f2`、文字色 `#ef4444`、ボーダー `#ef4444` で表示する
      AND heartアイコンをfilledにする

### AC-4: 次の記事ボタンスタイル

- [ ] WHEN 次の記事ボタンが表示されている場合
      THEN 背景 `#3b82f6`（primary）、文字色白で表示する
      AND ホバー時に背景 `#2563eb`（blue-600）にする

### AC-5: ボタン共通スタイル

- [ ] WHERE PCアクションボタンの両ボタン
      THE SYSTEM SHALL padding: `12px 28px`、border-radius: 12px、font-size: 15px、font-weight: 500を適用する
      AND SVGアイコン（20px）とテキストをgap: 8pxで配置する

### AC-6: ボタン機能

- [ ] WHEN お気に入りボタンをクリックした場合
      THEN 既存の `onFavorite` コールバックを呼び出す

- [ ] WHEN 次の記事ボタンをクリックした場合
      THEN 既存の `onNext` コールバックを呼び出す

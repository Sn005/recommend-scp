# Subtask 015-01-02: Service Worker + 登録コンポーネント

## 概要

最小構成の Service Worker（`sw.js`）を作成し、クライアントコンポーネント `ServiceWorkerRegistrar` で登録する。layout.tsx に配置して全ページで Service Worker を有効化する。

**status**: pending

## ユーザーストーリー

**As a** SCPicksの利用者
**I want** Service Worker が登録されている状態にしたい
**So that** ブラウザのPWAインストール条件を満たし、ホーム画面追加が可能になる

## Acceptance Criteria（EARS記法）

### AC-1: Service Worker ファイル

- [ ] WHEN ブラウザが `/sw.js` にアクセスした際
      THEN 有効なJavaScriptファイルが返される
      AND `install` イベントで `skipWaiting()` が呼ばれる
      AND `activate` イベントで `clients.claim()` が呼ばれる
      AND `fetch` イベントでHTTPスキームのリクエストのみネットワークに転送される（キャッシュなし）
      AND HTTP以外のスキーム（`chrome-extension://` 等）はブラウザデフォルト動作に委ねる

### AC-2: ServiceWorkerRegistrar コンポーネント

- [ ] WHEN アプリが読み込まれた際
      GIVEN ブラウザが Service Worker をサポートしている場合
      THEN `navigator.serviceWorker.register("/sw.js")` が呼び出される

- [ ] WHEN アプリが読み込まれた際
      GIVEN ブラウザが Service Worker をサポートしていない場合
      THEN エラーなく何も実行されない

### AC-3: Service Worker 登録失敗時

- [ ] WHEN アプリが読み込まれた際
      GIVEN Service Worker の登録が失敗した場合
      THEN アプリの通常機能（オンボーディング・推薦・お気に入り）には影響しない

### AC-4: layout.tsx への配置

- [ ] WHEN `layout.tsx` のレンダリング結果を確認した際
      THEN `ServiceWorkerRegistrar` コンポーネントが `<body>` 内に含まれている
      AND コンポーネントはUIを描画しない（`return null`）

## 技術設計

### sw.js（apps/web/public/sw.js）

```javascript
self.addEventListener("install", (event) => {
  self.skipWaiting();
});

self.addEventListener("activate", (event) => {
  event.waitUntil(self.clients.claim());
});

self.addEventListener("fetch", (event) => {
  if (event.request.url.startsWith("http")) {
    event.respondWith(fetch(event.request));
  }
});
```

### ServiceWorkerRegistrar（apps/web/src/shared/components/ServiceWorkerRegistrar.tsx）

```tsx
"use client";
import { useEffect } from "react";

export function ServiceWorkerRegistrar() {
  useEffect(() => {
    if ("serviceWorker" in navigator) {
      navigator.serviceWorker.register("/sw.js");
    }
  }, []);
  return null;
}
```

### layout.tsx 追加箇所

`<body>` 内に `<ServiceWorkerRegistrar />` を配置:

```tsx
import { ServiceWorkerRegistrar } from "@/shared/components/ServiceWorkerRegistrar";

export default function RootLayout({ children }) {
  return (
    <html lang="ja" suppressHydrationWarning>
      <body className="min-h-screen antialiased">
        <ServiceWorkerRegistrar />
        <VisitorProvider>{children}</VisitorProvider>
      </body>
    </html>
  );
}
```

# Subtask 015-01-01: Web App Manifest + メタデータ設定

## 概要

`manifest.json` を作成し、`layout.tsx` にPWA用メタデータ（manifest リンク、appleWebApp設定、タイトル変更）を追加する。

**status**: completed

## ユーザーストーリー

**As a** SCPicksの利用者
**I want** ブラウザがアプリをPWAとして認識してほしい
**So that** 「ホーム画面に追加」の選択肢が表示される

## Acceptance Criteria（EARS記法）

### AC-1: manifest.json の配置

- [x] WHEN ブラウザが `/manifest.json` にアクセスした際
      THEN 以下のフィールドを含む有効なJSONが返される: - `name`: `"SCPicks - あなた好みのSCPを発見"` - `short_name`: `"SCPicks"` - `description`: `"あなたの好みに合ったSCP記事を推薦するWebアプリ"` - `start_url`: `"/"` - `display`: `"standalone"` - `background_color`: `"#FFFFFF"` - `theme_color`: `"#3B82F6"` - `orientation`: `"portrait"` - `lang`: `"ja"` - `icons`: 192x192 と 512x512（通常 + maskable）の配列

### AC-2: layout.tsx メタデータ更新

- [x] WHEN `layout.tsx` の `metadata` エクスポートを確認した際
      THEN `title` が `"SCPicks - あなた好みのSCPを発見"` である
      AND `description` が `"あなたの好みに合ったSCP記事を推薦するWebアプリ"` である
      AND `manifest` が `"/manifest.json"` を指している
      AND `appleWebApp` が `{ capable: true, statusBarStyle: "default", title: "SCPicks" }` で設定されている

### AC-3: HTMLレンダリング確認

- [x] WHEN ページのHTMLソースを確認した際
      THEN `<link rel="manifest" href="/manifest.json">` が含まれている
      AND `<meta name="apple-mobile-web-app-capable" content="yes">` が含まれている
      AND `<meta name="apple-mobile-web-app-status-bar-style" content="default">` が含まれている

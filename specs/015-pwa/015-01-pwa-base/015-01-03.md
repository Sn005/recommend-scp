# Subtask 015-01-03: アプリアイコン配置

## 概要

`docs/pwa-launch-plan.md` のプロンプトで外部AI生成したアイコン画像を、`apps/web/public/` 配下に適切なサイズ・形式で配置する。

**status**: completed

## ユーザーストーリー

**As a** SCPicksの利用者
**I want** ホーム画面に追加したときにアプリアイコンが表示されてほしい
**So that** 他のアプリと同様にSCPicksを識別できる

## Acceptance Criteria（EARS記法）

### AC-1: アイコンファイルの配置

- [x] WHEN `apps/web/public/icons/` ディレクトリを確認した際
      THEN 以下のファイルが存在する: - `icon-192x192.png`（192x192px）- `icon-512x512.png`（512x512px）
      AND `apps/web/public/` 直下に以下が存在する: - `apple-touch-icon.png`（180x180px）- `favicon.ico`（32x32px）

### AC-2: manifest.json との整合性

- [x] WHEN `manifest.json` の `icons` 配列を確認した際
      THEN 各エントリの `src` パスに対応するファイルが実際に存在する
      AND `sizes` と実ファイルのサイズが一致する

### AC-3: maskable アイコン

- [x] WHEN `icon-512x512.png` を https://maskable.app で検証した際
      THEN Safe Zone（中央80%）内にロゴが収まり、Adaptiveアイコンとして適切と判定される

### AC-4: ブラウザ表示

- [x] WHEN ブラウザタブでアプリを表示した際
      THEN `favicon.ico` がタブに表示される

- [x] WHEN iOS Safari で「ホーム画面に追加」を実行した際
      THEN `apple-touch-icon.png` がホーム画面アイコンとして使用される

## アイコン生成手順

1. `docs/pwa-launch-plan.md` の「アイコン生成AIプロンプト」セクションのプロンプトを使用
2. 外部AIツール（Midjourney / DALL-E / Stable Diffusion等）で1024x1024画像を生成
3. 以下のサイズにリサイズ:
   - 512x512 → `icons/icon-512x512.png`
   - 192x192 → `icons/icon-192x192.png`
   - 180x180 → `apple-touch-icon.png`
   - 32x32 → ICO変換 → `favicon.ico`
4. maskable用にセーフゾーン（20%パディング）を確保したバージョンを確認

## テストケース

- [x] 各アイコンファイルが指定パスに存在する
- [x] 各アイコンファイルが有効な画像形式である
- [x] `manifest.json` の `icons[].src` パスが実ファイルと一致する
- [x] ビルドが成功する

# Story 015-01: PWA基盤実装

## 概要

SCPicksをPWAとしてインストール可能にするための基盤を実装する。Web App Manifest、最小Service Worker、メタデータ設定、アプリアイコン配置を行う。

**status**: pending

**I want** アプリをホーム画面に追加してネイティブアプリのように使いたい
**So that** ブラウザを開かずにワンタップでSCP推薦にアクセスできる

## Story-level Acceptance Criteria

- [ ] ブラウザがアプリをインストール可能と判定する（Lighthouse PWA Installable）

- [ ] 既存機能に影響がない

## 技術設計

### データフロー

```mermaid
sequenceDiagram
    participant Browser
    participant HTML as layout.tsx
    participant Manifest as manifest.json
    participant SW as sw.js
    participant Icons as public/icons/

    Browser->>HTML: ページ読み込み
    HTML->>Browser: <link rel="manifest"> 検出
    Browser->>Manifest: manifest.json 取得
    Manifest->>Browser: アプリ情報（name, icons, display等）
    HTML->>Browser: ServiceWorkerRegistrar 実行
    Browser->>SW: navigator.serviceWorker.register("/sw.js")
    SW->>Browser: install → activate → fetch パススルー
    Browser->>Icons: アイコン取得（192, 512, apple-touch-icon）
    Browser->>Browser: インストール可能と判定 → バナー表示
```

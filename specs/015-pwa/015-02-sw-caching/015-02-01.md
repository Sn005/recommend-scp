# Subtask 015-02-01: Workboxキャッシュ実装

## 概要

既存のパススルー専用 Service Worker (`sw.js`) を Workbox ベースのキャッシュ実装に全面書き換えし、ServiceWorkerRegistrar に SW 更新の定期チェックを追加する。

**status**: completed

## ユーザーストーリー

**As a** SCPicksの利用者
**I want** 閲覧した記事がブラウザにキャッシュされ、次回アクセス時に即座に表示されるようにしたい
**So that** 記事表示の待ち時間が減り、オフライン環境でも閲覧済み記事を読める

## Acceptance Criteria（EARS記法）

### AC-1: 記事HTMLキャッシュ（Stale-While-Revalidate）

- [x] WHEN ユーザーが `/api/wiki-proxy/*` パスの記事にアクセスした際
      THEN レスポンスが `scp-articles-v1` キャッシュに保存される
      AND 2回目以降のアクセスではキャッシュから即座にレスポンスが返される
      AND バックグラウンドでネットワークから最新版が取得されキャッシュが更新される

- [x] WHEN ユーザーがオフライン環境でキャッシュ済み記事にアクセスした際
      THEN キャッシュからレスポンスが返され記事が表示される

- [x] WHEN キャッシュ済み記事の最終アクセスから3ヶ月が経過した際
      THEN 該当キャッシュエントリが自動的にパージされる

### AC-2: サブリソースキャッシュ（Cache-first）

- [x] WHEN ユーザーが `/wdfiles-*`, `/wikidot-*`, `/common--*`, `/local--*` パスのリソースにアクセスした際
      THEN レスポンスが `scp-sub-resources-v1` キャッシュに保存される
      AND 2回目以降のアクセスではキャッシュから直接返される（ネットワークリクエストなし）
      AND キャッシュは30日で自動パージされる

### AC-3: ストレージ圧迫時の自動パージ

- [x] WHEN ブラウザのストレージクォータが圧迫された際
      THEN `purgeOnQuotaError: true` によりWorkboxが自動的にLRUパージを実行する
      AND アプリの通常動作に影響しない

### AC-4: キャッシュバージョン管理

- [x] WHEN 新しいバージョンの Service Worker がアクティベートされた際
      THEN `scp-` プレフィックスを持つ旧バージョンのキャッシュが自動削除される
      AND 現行バージョンのキャッシュ（`scp-articles-v1`, `scp-sub-resources-v1`）は保持される

### AC-5: SW更新の定期チェック

- [x] WHEN Service Worker の登録が成功した際
      THEN 60分間隔で `registration.update()` が呼び出される
      AND コンポーネントのアンマウント時にインターバルがクリアされる

### AC-6: エラー耐性

- [x] WHEN Workbox CDN の読み込みが失敗した際
      THEN Service Worker 全体がエラーとなるが、アプリ本体は影響なく動作する
      AND ユーザーは通常のネットワーク経由でコンテンツを閲覧できる

- [x] WHEN Service Worker の登録が失敗した際
      THEN アプリの通常機能に影響しない（既存 AC-3 準拠）

## 技術設計

### sw.js（Workboxベース）

```javascript
// Workbox CDN読み込み
importScripts("https://storage.googleapis.com/workbox-cdn/releases/7.3.0/workbox-sw.js");

// 記事HTML: Stale-While-Revalidate
registerRoute(
  ({ url }) => url.pathname.startsWith("/api/wiki-proxy/"),
  new StaleWhileRevalidate({
    cacheName: "scp-articles-v1",
    plugins: [
      new CacheableResponsePlugin({ statuses: [200] }),
      new ExpirationPlugin({ maxAgeSeconds: 90 * 24 * 60 * 60, purgeOnQuotaError: true }),
    ],
  })
);

// サブリソース: Cache-first
registerRoute(
  ({ url }) => SUB_RESOURCE_PREFIXES.some((p) => url.pathname.startsWith(p)),
  new CacheFirst({
    cacheName: "scp-sub-resources-v1",
    plugins: [
      new CacheableResponsePlugin({ statuses: [0, 200] }),
      new ExpirationPlugin({ maxAgeSeconds: 30 * 24 * 60 * 60, purgeOnQuotaError: true }),
    ],
  })
);
```

### ServiceWorkerRegistrar 更新

```typescript
void navigator.serviceWorker.register("/sw.js").then((registration) => {
  intervalId = setInterval(
    () => {
      void registration.update();
    },
    60 * 60 * 1000
  ); // 60分間隔
});
```

### `?nav=floating` クエリパラメータ

- 推薦画面: `/api/wiki-proxy/scp-173?nav=floating`（帰属表示padding付き）
- 記事詳細画面: `/api/wiki-proxy/scp-173`（パラメータなし）
- WorkboxはフルURL（クエリパラメータ含む）をキャッシュキーにするため、両バリアントが別々にキャッシュされる
- HTML差分は微小（style 1行）でストレージ影響は無視できる

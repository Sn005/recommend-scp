# EPIC-015: PWA対応

## 概要

SCPicksをPWA（Progressive Web App）としてリリースし、ホーム画面追加・スタンドアロン表示を実現する。

**status**: completed

## ユーザーストーリー

**ペルソナ**: SCPicksを継続利用するモバイルユーザー（5-10名）
**目的**: SCPicksをホーム画面に追加し、ネイティブアプリのように利用したい
**価値**: ブラウザのアドレスバーなしのフルスクリーン体験、ワンタップでのアクセス
**理由**: 頻繁に利用するアプリをホーム画面から直接起動したい

## 背景

### ブランディング

| 項目           | 決定                                         |
| -------------- | -------------------------------------------- |
| アプリ名（短） | `SCPicks`                                    |
| アプリ名（長） | `SCPicks - あなた好みのSCPを推薦`            |
| テーマカラー   | `#3B82F6`（既存デザイントークン）/ `#FFFFFF` |
| アイコン       | ミニマル文字ロゴ「SP」                       |

### 機能スコープ

| 機能               | 対応 | 備考                             |
| ------------------ | ---- | -------------------------------- |
| ホーム画面追加     | Yes  | manifest.json + Service Worker   |
| フルスクリーン表示 | Yes  | `display: "standalone"`          |
| オフラインサポート | No   | 常時オンライン前提               |
| プッシュ通知       | No   | 不要                             |
| インストール促進UI | No   | ブラウザネイティブバナーに任せる |
| アプリストア掲載   | No   | Web全面公開のみ                  |

### 技術仕様詳細

`docs/product/pwa-launch-plan.md` に記載。アイコン生成AIプロンプトも同ドキュメントを参照。

## EPIC-level Acceptance Criteria

- [ ] Web App Manifest が正しく配置され、ブラウザがインストール可能と判定する
- [ ] layout.tsx のメタデータに manifest リンク・appleWebApp 設定が含まれる
- [ ] Service Worker が登録され、fetch をパススルーする最小構成で動作する
- [ ] アプリアイコン（192x192, 512x512, 180x180, favicon）が配置されている
- [ ] ホーム画面から起動時にスタンドアロンモードで表示される
- [ ] 既存機能（オンボーディング・推薦・お気に入り・閲覧履歴）に影響がない

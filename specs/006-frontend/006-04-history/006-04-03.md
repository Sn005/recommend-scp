# Subtask: 履歴からの遷移

## 親Story

[006-04: 閲覧履歴](./006-04.md)

## ユーザーストーリー

**ペルソナ**: SCPファン（エンドユーザー）
**目的**: 履歴から選択した記事の詳細を閲覧する
**価値**: タップ一つで読み返したい記事にアクセスできる
**理由**: 履歴を見るだけでなく、そこから直接記事に飛べると便利だから

> SCPファンとして、履歴から選択した記事の詳細を閲覧して、タップ一つで読み返したい記事にアクセスしたい。なぜなら履歴を見るだけでなく、そこから直接記事に飛べると便利だから。

## Acceptance Criteria

### AC-1: カードタップ

- [x] WHEN 履歴カードをタップした際
      THEN 記事詳細画面（/recommend/[scpNumber]）に遷移する

### AC-2: タップフィードバック

- [x] WHEN 履歴カードをタップした際
      THEN タップフィードバック（scale: 0.98）が表示される
      AND リリースで元に戻る

### AC-3: 遷移後の履歴更新

- [x] WHEN 履歴から記事に遷移した際
      THEN その記事が履歴の先頭に移動する
      AND 閲覧日時が更新される
      （Note: 履歴更新は記事詳細画面側で006-02として実装済み）

## 技術設計

### HistoryCard 実装

```typescript
// _components/HistoryCard.tsx
'use client';

import { useRouter } from 'next/navigation';
import { Badge } from '@/shared/components/ui/Badge';
import { formatRelativeTime } from '../_lib/formatDate';
import type { HistoryEntry } from '../_types';

interface HistoryCardProps {
  entry: HistoryEntry;
  onSelect?: (entry: HistoryEntry) => void;
}

export const HistoryCard = ({ entry, onSelect }: HistoryCardProps) => {
  const router = useRouter();

  const handleClick = () => {
    onSelect?.(entry);
    router.push(`/recommend/${encodeURIComponent(entry.scpNumber)}`);
  };

  return (
    <button
      onClick={handleClick}
      className="w-full text-left p-4 bg-white rounded-xl shadow-sm
                 transition-transform active:scale-[0.98]"
    >
      <div className="flex items-center gap-2 mb-1">
        <Badge variant={entry.objectClass} />
        <span className="font-medium">{entry.scpNumber}</span>
      </div>
      <p className="text-gray-700 text-sm mb-1">{entry.title}</p>
      <p className="text-gray-400 text-xs">{formatRelativeTime(entry.viewedAt)}</p>
    </button>
  );
};
```

### HistoryList 実装

```typescript
// _components/HistoryList.tsx
import { HistoryCard } from './HistoryCard';
import type { HistoryEntry } from '../_types';

interface HistoryListProps {
  entries: HistoryEntry[];
  onSelect?: (entry: HistoryEntry) => void;
}

export const HistoryList = ({ entries, onSelect }: HistoryListProps) => {
  if (entries.length === 0) {
    return (
      <div className="text-center text-gray-500 py-8">
        まだ閲覧履歴がありません
      </div>
    );
  }

  return (
    <div className="space-y-3">
      {entries.map((entry) => (
        <HistoryCard
          key={`${entry.scpNumber}-${entry.viewedAt}`}
          entry={entry}
          onSelect={onSelect}
        />
      ))}
    </div>
  );
};
```

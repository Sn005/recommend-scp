# Subtask: 履歴一覧画面

## 親Story

[006-04: 閲覧履歴](./006-04.md)

## ユーザーストーリー

**ペルソナ**: SCPファン（エンドユーザー）
**目的**: 過去に閲覧した記事の一覧を確認する
**価値**: 読み返したい記事を素早く見つけられる
**理由**: 閲覧日時順に並んでいれば、最近読んだ記事がすぐ見つかるから

> SCPファンとして、過去に閲覧した記事の一覧を確認して、読み返したい記事を素早く見つけたい。なぜなら閲覧日時順に並んでいれば、最近読んだ記事がすぐ見つかるから。

## Acceptance Criteria

### AC-1: 画面レイアウト

- [ ] WHEN 履歴画面を開いた際
      THEN 「閲覧履歴」というタイトルが表示される
      AND 履歴件数が表示される

### AC-2: 履歴リスト

- [ ] WHEN 履歴がある場合
      THEN 閲覧日時の新しい順にカードが表示される

- [ ] WHEN 履歴がない場合
      THEN 「まだ閲覧履歴がありません」と表示される

### AC-3: 履歴カード

- [ ] WHEN 履歴カードを表示した際
      THEN SCP番号（例: SCP-173）が表示される
      AND タイトルが表示される
      AND オブジェクトクラスバッジが表示される
      AND 閲覧日時（相対時間）が表示される

### AC-4: 相対時間表示

- [ ] WHEN 閲覧日時を表示する際
      GIVEN 1時間以内の場合
      THEN 「○分前」と表示される

- [ ] WHEN 閲覧日時を表示する際
      GIVEN 1時間以上24時間未満の場合
      THEN 「○時間前」と表示される

- [ ] WHEN 閲覧日時を表示する際
      GIVEN 24時間以上7日未満の場合
      THEN 「○日前」と表示される

- [ ] WHEN 閲覧日時を表示する際
      GIVEN 7日以上前の場合
      THEN 日付（YYYY/MM/DD形式）が表示される

### AC-5: スクロール

- [ ] WHEN 履歴が多い場合
      THEN スクロールで全履歴を確認できる
      AND タイトルはスクロールで消える（固定しない）

### 相対時間フォーマット

```typescript
// _lib/formatDate.ts
export const formatRelativeTime = (dateString: string): string => {
  const date = new Date(dateString);
  const now = new Date();
  const diffMs = now.getTime() - date.getTime();
  const diffMin = Math.floor(diffMs / (1000 * 60));
  const diffHour = Math.floor(diffMs / (1000 * 60 * 60));
  const diffDay = Math.floor(diffMs / (1000 * 60 * 60 * 24));

  if (diffMin < 60) return `${diffMin}分前`;
  if (diffHour < 24) return `${diffHour}時間前`;
  if (diffDay < 7) return `${diffDay}日前`;

  // 7日以上前はYYYY/MM/DD形式
  const year = date.getFullYear();
  const month = String(date.getMonth() + 1).padStart(2, "0");
  const day = String(date.getDate()).padStart(2, "0");
  return `${year}/${month}/${day}`;
};
```

### page.tsx 実装例

```typescript
// page.tsx
'use client';

import { useHistory } from './_hooks/useHistory';
import { HistoryList } from './_components/HistoryList';

export default function HistoryPage() {
  const { entries, isLoading } = useHistory();

  if (isLoading) {
    return <div>読み込み中...</div>;
  }

  return (
    <div className="p-4">
      <header className="mb-4">
        <h1 className="text-xl font-bold">閲覧履歴</h1>
        <p className="text-gray-500">{entries.length}件</p>
      </header>
      <HistoryList entries={entries} />
    </div>
  );
}
```

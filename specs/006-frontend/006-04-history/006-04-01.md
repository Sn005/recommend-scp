# Subtask: 履歴記録機能

## 親Story

[006-04: 閲覧履歴](./006-04.md)

## ユーザーストーリー

**ペルソナ**: SCPファン（エンドユーザー）
**目的**: 閲覧した記事を自動的に記録する
**価値**: 手動で保存しなくても後から参照できる
**理由**: 閲覧した記事を自動で記録してくれれば、読み返すときに便利だから

> SCPファンとして、閲覧した記事を自動的に記録して、手動で保存しなくても後から参照したい。なぜなら閲覧した記事を自動で記録してくれれば、読み返すときに便利だから。

## Acceptance Criteria

### AC-1: 履歴追加

- [x] WHEN 記事を閲覧した際
      THEN その記事が履歴に追加される
      AND SCP番号、タイトル、オブジェクトクラス、閲覧日時が記録される

### AC-2: 重複防止

- [x] WHEN 同じ記事を再度閲覧した際
      THEN 既存のエントリが履歴の先頭に移動する
      AND 重複エントリは作成されない
      AND 閲覧日時が更新される

### AC-3: 上限管理

- [x] WHEN 履歴が100件を超えた際
      THEN 最も古いエントリが削除される
      AND 最新100件が保持される

### AC-4: 永続化

- [x] WHEN 履歴を追加した際
      THEN localStorageに保存される
      AND アプリ再起動後も復元される

### AC-5: useHistory フック

- [x] WHEN useHistory フックを使用した際
      THEN entries（履歴配列）を取得できる
      AND add（追加）関数を使用できる
      AND clear（全削除）関数を使用できる

### ストレージ操作

```typescript
// _lib/historyStorage.ts
const STORAGE_KEY = "scp-recommend-history";
const MAX_ENTRIES = 100;

export const getHistory = (): HistoryEntry[] => {
  if (typeof window === "undefined") return [];
  const stored = localStorage.getItem(STORAGE_KEY);
  return stored ? JSON.parse(stored) : [];
};

export const addHistory = (entry: Omit<HistoryEntry, "viewedAt">): HistoryEntry => {
  const newEntry: HistoryEntry = {
    ...entry,
    viewedAt: new Date().toISOString(),
  };

  const history = getHistory();
  // 重複削除（同じSCP番号）
  const filtered = history.filter((e) => e.scpNumber !== entry.scpNumber);
  // 先頭に追加 & 上限適用
  const updated = [newEntry, ...filtered].slice(0, MAX_ENTRIES);

  localStorage.setItem(STORAGE_KEY, JSON.stringify(updated));
  return newEntry;
};

export const clearHistory = (): void => {
  localStorage.removeItem(STORAGE_KEY);
};
```

### useHistory フック

```typescript
// _hooks/useHistory.ts
import { useState, useEffect } from "react";
import { getHistory, addHistory, clearHistory } from "../_lib/historyStorage";
import type { HistoryEntry } from "../_types";

export const useHistory = () => {
  const [entries, setEntries] = useState<HistoryEntry[]>([]);
  const [isLoading, setIsLoading] = useState(true);

  useEffect(() => {
    setEntries(getHistory());
    setIsLoading(false);
  }, []);

  const add = (entry: Omit<HistoryEntry, "viewedAt">) => {
    const newEntry = addHistory(entry);
    setEntries((prev) => [newEntry, ...prev.filter((e) => e.scpNumber !== entry.scpNumber)]);
  };

  const clear = () => {
    clearHistory();
    setEntries([]);
  };

  return { entries, isLoading, add, clear };
};
```

# Subtask 006-02-01: 記事閲覧ページ実装

## 概要

記事閲覧ページ（/recommend）のメインページコンポーネントを実装する。
推薦API連携、レイアウト構成、推薦切れ・エラー表示を担当。

## ステータス

- **status**: planned

## 親Story

[006-02: 記事閲覧](./006-02.md)

## ユーザーストーリー

**ペルソナ**: SCPファン
**目的**: 推薦された記事を閲覧する画面にアクセスする
**価値**: スムーズに記事閲覧を開始できる
**理由**: 手軽にSCP記事を楽しみたい

> SCPファンとして、推薦された記事を閲覧する画面にアクセスし、スムーズに記事閲覧を開始したい。なぜなら手軽にSCP記事を楽しみたいから。

## Acceptance Criteria（EARS記法）

### AC-1: ページ初期表示

- [ ] WHEN ユーザーが /recommend にアクセスした際
      GIVEN オンボーディング完了後の場合
      THEN 記事閲覧ページが表示される
      AND POST /recommend APIで推薦記事を取得する
      AND ローディング中はスケルトンUIが表示される

### AC-2: 記事表示レイアウト

- [ ] WHEN 推薦記事の取得が完了した際
      THEN ArticleWebViewコンポーネントに記事URLが渡される
      AND 画面下部にPillNavが表示される
      AND 画面下部にProgressBarが表示される

### AC-3: 推薦切れ表示

- [ ] WHEN POST /recommend APIが空配列を返した際
      THEN EmptyStateコンポーネントが表示される
      AND 「すべての推薦を読みました」メッセージが表示される
      AND 「好みを再設定」ボタンが表示される

### AC-4: エラー表示

- [ ] WHEN 記事取得中にエラーが発生した際
      THEN エラーメッセージが表示される
      AND 「再試行」ボタンが表示される

### AC-5: 再試行処理

- [ ] WHEN ユーザーが「再試行」ボタンをタップした際
      THEN POST /recommend APIが再実行される
      AND ローディング状態に戻る

### page.tsx 実装方針

```tsx
// app/(main)/recommend/page.tsx
"use client";

import { useInfiniteArticles } from "./_hooks/useInfiniteArticles";
import { useFeedback } from "./_hooks/useFeedback";
import { useArticleFavorite } from "./_hooks/useArticleFavorite";
import { ArticleWebView } from "./_components/ArticleWebView";
import { FloatingUI } from "./_components/FloatingUI";
import { EmptyState } from "./_components/EmptyState";
import { ErrorState } from "./_components/ErrorState";

export default function RecommendPage() {
  const { articles, currentIndex, isLoading, error, isEmpty, loadMore, goToNext } =
    useInfiniteArticles();

  const { recordLike, recordDislike } = useFeedback();
  const { isFavorited, toggleFavorite } = useArticleFavorite(articles[currentIndex]?.id);

  if (isLoading && articles.length === 0) {
    return <SkeletonLoader />;
  }

  if (error) {
    return <ErrorState error={error} onRetry={() => window.location.reload()} />;
  }

  if (isEmpty) {
    return <EmptyState />;
  }

  const currentArticle = articles[currentIndex];

  return (
    <div className="relative h-screen">
      <ArticleWebView url={currentArticle.url} onScrollEnd={() => recordLike(currentArticle.id)} />
      <FloatingUI
        progress={((currentIndex + 1) / articles.length) * 100}
        isFavorited={isFavorited}
        onFavorite={() => toggleFavorite()}
        onNext={() => {
          recordDislike(currentArticle.id);
          goToNext();
        }}
      />
    </div>
  );
}
```

# Subtask 006-02-02: WebViewコンポーネント

## 概要

記事を全画面で表示するiframeベースのWebViewコンポーネントを実装する。
スクロール位置の検知・通知、ローディング状態管理を担当。

## ユーザーストーリー

**ペルソナ**: SCPファン
**目的**: 元サイトの記事を没入感のある全画面で読む
**価値**: オリジナルの体験を損なわずに記事を楽しめる
**理由**: SCP Wikiの雰囲気をそのまま味わいたい

> SCPファンとして、元サイトの記事を没入感のある全画面で読み、オリジナルの体験を損なわずに記事を楽しみたい。なぜならSCP Wikiの雰囲気をそのまま味わいたいから。

## Acceptance Criteria（EARS記法）

### AC-1: iframe表示

- [x] WHEN ArticleWebViewに記事URLが渡された際
      THEN iframeで元サイトの記事が全画面表示される
      AND iframeの高さは100vh - PillNav領域（約100px）となる

### AC-2: スクロール可能

- [x] WHILE 記事が表示されている間
      THE SYSTEM SHALL iframe内のスクロールを許可する
      AND iframe内リンクのタップを許可する

### AC-3: スクロール位置通知

- [x] WHEN ユーザーがiframe内をスクロールした際
      THEN 親コンポーネントにスクロール位置が通知される
      AND スクロール率（0-100%）が計算される

### AC-4: 記事切り替え

- [x] WHEN 新しい記事URLが渡された際
      THEN iframeのsrcが更新される
      AND スクロール位置が先頭にリセットされる

### AC-5: ローディング状態

- [x] WHILE iframeがコンテンツを読み込んでいる間
      THE SYSTEM SHALL ローディングインジケータを表示する
      AND 読み込み完了後に非表示にする

### AC-6: 読了検知

- [x] WHEN スクロール率が90%に達した際
      THEN onScrollEndコールバックが呼び出される
      AND 同じ記事で複数回呼び出されない

### AC-7: iframe読み込みエラー

- [x] WHEN iframeの読み込みが失敗した際
      GIVEN ネットワークエラー、404、CORS、タイムアウト等の場合
      THEN エラーメッセージが表示される
      AND 「再試行」ボタンが表示される

### useArticleWebView フック

```typescript
// ArticleWebView/useArticleWebView.ts
interface UseArticleWebViewOptions {
  url: string;
  onScrollEnd?: () => void;
  onScrollChange?: (percentage: number) => void;
}

interface UseArticleWebViewReturn {
  iframeRef: RefObject<HTMLIFrameElement | null>;
  isLoading: boolean;
  error: Error | null;
  scrollPercentage: number;
  handleLoad: () => void;
  handleError: () => void;
  retry: () => void;
}

export function useArticleWebView(options: UseArticleWebViewOptions): UseArticleWebViewReturn {
  const [isLoading, setIsLoading] = useState(true);
  const [error, setError] = useState<Error | null>(null);
  const [scrollPercentage, setScrollPercentage] = useState(0);
  const [hasTriggeredEnd, setHasTriggeredEnd] = useState(false);
  const iframeRef = useRef<HTMLIFrameElement | null>(null);

  // コールバックのrefを保持（スクロールハンドラー内でのstale closure防止）
  const callbacksRef = useRef({ onScrollChange, onScrollEnd });
  useEffect(() => {
    callbacksRef.current = { onScrollChange, onScrollEnd };
  }, [onScrollChange, onScrollEnd]);

  const hasTriggeredEndRef = useRef(false);
  useEffect(() => {
    hasTriggeredEndRef.current = hasTriggeredEnd;
  }, [hasTriggeredEnd]);

  // URL変更時にリセット
  useEffect(() => {
    setIsLoading(true);
    setError(null);
    setScrollPercentage(0);
    setHasTriggeredEnd(false);
    hasTriggeredEndRef.current = false;

    // iframe読み込みタイムアウト
    const timeoutId = setTimeout(() => setIsLoading(false), 15_000);
    return () => clearTimeout(timeoutId);
  }, [url]);

  // iframe contentWindowのスクロールを直接検知
  // wiki-proxy経由で同一オリジン配信のため、contentWindowに直接アクセス可能
  // postMessage方式と異なり、iframe側へのスクリプト注入が不要
  useEffect(() => {
    if (isLoading) return;
    const iframe = iframeRef.current;
    if (!iframe) return;
    let iframeWindow: Window | null = null;
    try {
      iframeWindow = iframe.contentWindow;
    } catch {
      return; // Cross-origin access denied（通常はwiki-proxy経由なので発生しない）
    }
    if (!iframeWindow) return;

    let active = true;
    let ticking = false;

    const handleScroll = () => {
      if (ticking || !active) return;
      ticking = true;
      requestAnimationFrame(() => {
        ticking = false;
        if (!active) return;
        try {
          const scrollTop = iframeWindow.scrollY;
          const docHeight = iframeWindow.document.documentElement.scrollHeight;
          const viewHeight = iframeWindow.innerHeight;
          if (docHeight <= viewHeight) return;
          const raw = (scrollTop / (docHeight - viewHeight)) * 100;
          const normalized = normalizePercentage(raw);
          setScrollPercentage(normalized);
          callbacksRef.current.onScrollChange?.(normalized);
          if (!hasTriggeredEndRef.current && normalized >= 90) {
            setHasTriggeredEnd(true);
            hasTriggeredEndRef.current = true;
            callbacksRef.current.onScrollEnd?.();
          }
        } catch {
          // contentWindow access may fail if iframe navigated away
        }
      });
    };

    iframeWindow.addEventListener("scroll", handleScroll, { passive: true });
    return () => {
      active = false;
      try {
        iframeWindow.removeEventListener("scroll", handleScroll);
      } catch {
        // iframe may have navigated away
      }
    };
  }, [isLoading, url]);

  const handleLoad = useCallback(() => {
    setIsLoading(false);
    setError(null);
  }, []);
  const handleError = useCallback(() => {
    setError(new Error("記事の読み込みに失敗しました"));
    setIsLoading(false);
  }, []);
  const retry = useCallback(() => {
    setError(null);
    setIsLoading(true);
    setScrollPercentage(0);
    setHasTriggeredEnd(false);
    hasTriggeredEndRef.current = false;
  }, []);

  return { iframeRef, isLoading, error, scrollPercentage, handleLoad, handleError, retry };
}
```

### ArticleWebView コンポーネント

```tsx
// ArticleWebView/ArticleWebView.tsx
"use client";

import { cn } from "@/shared/lib/utils";
import { useArticleWebView } from "./useArticleWebView";
import type { ArticleWebViewProps } from "./index";

export function ArticleWebView({
  url,
  onScrollEnd,
  onScrollChange,
  className,
}: ArticleWebViewProps) {
  const { iframeRef, isLoading, handleLoad } = useArticleWebView({
    url,
    onScrollEnd,
    onScrollChange,
  });

  return (
    <div className={cn("relative w-full h-[calc(100vh-100px)]", className)}>
      {isLoading && (
        <div className="absolute inset-0 flex items-center justify-center bg-gray-100">
          <div className="animate-spin rounded-full h-8 w-8 border-b-2 border-primary" />
        </div>
      )}
      <iframe
        ref={iframeRef}
        src={url}
        className="w-full h-full border-0"
        onLoad={handleLoad}
        title="SCP記事"
        sandbox="allow-scripts allow-same-origin allow-popups"
      />
    </div>
  );
}
```

### スクロール検知の実装方針

**前提**: wiki-proxy（`/api/wiki-proxy/...`）経由で記事HTMLを同一オリジンで配信しているため、iframeの`contentWindow`に直接アクセス可能。

**採用方式: 直接contentWindowアクセス**

- wiki-proxy経由で同一オリジン配信 → `iframe.contentWindow` に直接アクセス
- `contentWindow.addEventListener("scroll", handler)` でスクロールイベントを監視
- postMessage方式と異なり、iframe側へのスクリプト注入が不要
- `requestAnimationFrame` によるスロットリングでパフォーマンスを確保
- `{ passive: true }` オプションでスクロールパフォーマンスを最適化

**不採用: postMessage方式**

当初はpostMessage方式（iframe内にスクリプトを注入し、`window.parent.postMessage()` でスクロール位置を通知）を検討したが、wiki-proxy経由で同一オリジン配信されるため、より単純な直接アクセス方式を採用した。

## 備考

- wiki-proxy経由で同一オリジン配信されるため、クロスオリジン制約は解消済み
- wiki-proxyはDOM抽出方式を採用（2026-02-16変更）: 通常ページをjsdomでパースし`#main-content`を抽出。記事固有CSS/JSを保持するため、SCP Wikiのテーマ・装飾が忠実に再現される
- 注入CSSの可読性プロパティは `!important` 付きで、記事テーマCSSとの競合を回避
- スクロール検知はcontentWindowへの直接アクセスで実現（postMessage不要）
- sandbox属性で必要最小限の権限のみ付与
- 将来的にService Workerでのキャッシュを検討

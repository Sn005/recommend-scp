# Subtask 006-02-02: WebViewコンポーネント

## 概要

記事を全画面で表示するiframeベースのWebViewコンポーネントを実装する。
スクロール位置の検知・通知、ローディング状態管理を担当。

## ステータス

- **status**: planned

## 親Story

## ユーザーストーリー

**ペルソナ**: SCPファン
**目的**: 元サイトの記事を没入感のある全画面で読む
**価値**: オリジナルの体験を損なわずに記事を楽しめる
**理由**: SCP Wikiの雰囲気をそのまま味わいたい

> SCPファンとして、元サイトの記事を没入感のある全画面で読み、オリジナルの体験を損なわずに記事を楽しみたい。なぜならSCP Wikiの雰囲気をそのまま味わいたいから。

## Acceptance Criteria（EARS記法）

### AC-1: iframe表示

- [ ] WHEN ArticleWebViewに記事URLが渡された際
      THEN iframeで元サイトの記事が全画面表示される
      AND iframeの高さは100vh - PillNav領域（約100px）となる

### AC-2: スクロール可能

- [ ] WHILE 記事が表示されている間
      THE SYSTEM SHALL iframe内のスクロールを許可する
      AND iframe内リンクのタップを許可する

### AC-3: スクロール位置通知

- [ ] WHEN ユーザーがiframe内をスクロールした際
      THEN 親コンポーネントにスクロール位置が通知される
      AND スクロール率（0-100%）が計算される

### AC-4: 記事切り替え

- [ ] WHEN 新しい記事URLが渡された際
      THEN iframeのsrcが更新される
      AND スクロール位置が先頭にリセットされる

### AC-5: ローディング状態

- [ ] WHILE iframeがコンテンツを読み込んでいる間
      THE SYSTEM SHALL ローディングインジケータを表示する
      AND 読み込み完了後に非表示にする

### AC-6: 読了検知

- [ ] WHEN スクロール率が90%に達した際
      THEN onScrollEndコールバックが呼び出される
      AND 同じ記事で複数回呼び出されない

### AC-7: iframe読み込みエラー

- [ ] WHEN iframeの読み込みが失敗した際
      GIVEN ネットワークエラー、404、CORS、タイムアウト等の場合
      THEN エラーメッセージが表示される
      AND 「再試行」ボタンが表示される

### useArticleWebView フック

```typescript
// ArticleWebView/useArticleWebView.ts
interface UseArticleWebViewOptions {
  url: string;
  onScrollEnd?: () => void;
  onScrollChange?: (percentage: number) => void;
}

interface UseArticleWebViewReturn {
  iframeRef: RefObject<HTMLIFrameElement>;
  isLoading: boolean;
  scrollPercentage: number;
  handleLoad: () => void;
}

export function useArticleWebView(options: UseArticleWebViewOptions): UseArticleWebViewReturn {
  const [isLoading, setIsLoading] = useState(true);
  const [scrollPercentage, setScrollPercentage] = useState(0);
  const [hasTriggeredEnd, setHasTriggeredEnd] = useState(false);
  const iframeRef = useRef<HTMLIFrameElement>(null);

  // URL変更時にリセット
  useEffect(() => {
    setIsLoading(true);
    setScrollPercentage(0);
    setHasTriggeredEnd(false);
  }, [options.url]);

  // スクロール検知（postMessage経由）
  useEffect(() => {
    const handleMessage = (event: MessageEvent) => {
      if (event.data.type === "scroll") {
        const percentage = event.data.percentage;
        setScrollPercentage(percentage);
        options.onScrollChange?.(percentage);

        if (percentage >= 90 && !hasTriggeredEnd) {
          setHasTriggeredEnd(true);
          options.onScrollEnd?.();
        }
      }
    };

    window.addEventListener("message", handleMessage);
    return () => window.removeEventListener("message", handleMessage);
  }, [options, hasTriggeredEnd]);

  const handleLoad = () => setIsLoading(false);

  return { iframeRef, isLoading, scrollPercentage, handleLoad };
}
```

### ArticleWebView コンポーネント

```tsx
// ArticleWebView/ArticleWebView.tsx
"use client";

import { cn } from "@/shared/lib/utils";
import { useArticleWebView } from "./useArticleWebView";
import type { ArticleWebViewProps } from "./index";

export function ArticleWebView({
  url,
  onScrollEnd,
  onScrollChange,
  className,
}: ArticleWebViewProps) {
  const { iframeRef, isLoading, handleLoad } = useArticleWebView({
    url,
    onScrollEnd,
    onScrollChange,
  });

  return (
    <div className={cn("relative w-full h-[calc(100vh-100px)]", className)}>
      {isLoading && (
        <div className="absolute inset-0 flex items-center justify-center bg-gray-100">
          <div className="animate-spin rounded-full h-8 w-8 border-b-2 border-primary" />
        </div>
      )}
      <iframe
        ref={iframeRef}
        src={url}
        className="w-full h-full border-0"
        onLoad={handleLoad}
        title="SCP記事"
        sandbox="allow-scripts allow-same-origin allow-popups"
      />
    </div>
  );
}
```

### スクロール検知の実装方針

**課題**: iframeのクロスオリジン制約により、親から直接スクロール位置を取得できない

**解決策**:

1. **プロキシ経由の場合**: サーバーサイドで記事HTMLを取得し、スクロール検知スクリプトを注入
2. **同一オリジンの場合**: 直接iframeのcontentWindowにアクセス

```typescript
// プロキシ経由でスクロール検知スクリプトを注入する場合
const SCROLL_SCRIPT = `
  <script>
    window.addEventListener('scroll', () => {
      const scrollTop = document.documentElement.scrollTop;
      const scrollHeight = document.documentElement.scrollHeight;
      const clientHeight = document.documentElement.clientHeight;
      const percentage = (scrollTop / (scrollHeight - clientHeight)) * 100;
      window.parent.postMessage({ type: 'scroll', percentage }, '*');
    });
  </script>
`;
```

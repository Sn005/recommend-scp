# Subtask 006-02-03: フローティングピルナビ

## 概要

記事閲覧画面の下部に表示するフローティングピル型ナビゲーションを実装する。
お気に入りボタン（♡）と次へボタン（→）の2ボタン構成。

## ステータス

- **status**: planned

## 親Story

[006-02: 記事閲覧](./006-02.md)

## ユーザーストーリー

**ペルソナ**: エンドユーザー
**目的**: 記事閲覧中にお気に入り登録と次の記事への移動を行う
**価値**: 最小限の操作で記事の評価と移動ができる
**理由**: 読書体験を邪魔せず、直感的な操作を提供したい

> エンドユーザーとして、記事閲覧中にフローティングボタンでお気に入り登録と次の記事へ移動したい。なぜなら読書に集中しながら直感的に操作したいから。

## Acceptance Criteria（EARS記法）

### AC-1: フローティングピル表示

- [ ] WHEN 記事閲覧画面を表示した際
      THEN 画面下部中央にフローティングピル型ナビが表示される
      AND Glassmorphism効果（`glass-pill`）が適用されている
      AND z-indexは `--z-bottom-nav: 50` である

### AC-2: ボタン構成

- [ ] WHEN フローティングピルナビを確認した際
      THEN 左側にお気に入りボタン（♡）が表示される
      AND 右側に次へボタン（→）が表示される
      AND ボタン間に区切り線が表示される

### AC-3: お気に入りボタン動作

- [ ] WHEN お気に入りボタンをタップした際
      GIVEN 記事がお気に入り未登録の場合
      THEN ハートアイコンが塗りつぶしに変わる
      AND お気に入り登録APIが呼び出される
      AND 触覚フィードバック（Haptic）が発生する

- [ ] WHEN お気に入りボタンをタップした際
      GIVEN 記事がお気に入り登録済みの場合
      THEN ハートアイコンがアウトラインに変わる
      AND お気に入り解除APIが呼び出される

### AC-4: 次へボタン動作

- [ ] WHEN 次へボタンをタップした際
      THEN 次の推薦記事が読み込まれる
      AND 画面がスムーズに切り替わる
      AND Like/Dislikeフィードバックとして「skip」が記録される

### AC-5: セーフエリア対応

- [ ] WHEN iPhone等のノッチ付き端末で表示した際
      THEN フローティングピルがセーフエリアを考慮した位置に表示される

### AC-6: スクロール連動（オプション）

- [ ] WHEN 下方向にスクロールした際
      THEN フローティングピルナビが非表示になる（オプション実装）

- [ ] WHEN 上方向にスクロールした際
      THEN フローティングピルナビが再表示される

### FloatingPillNav.tsx

```tsx
"use client";

import { FavoriteButton } from "./FavoriteButton";
import { NextButton } from "./NextButton";

interface FloatingPillNavProps {
  articleId: string;
  isFavorite: boolean;
  onFavoriteToggle: () => void;
  onNext: () => void;
}

export function FloatingPillNav({
  articleId,
  isFavorite,
  onFavoriteToggle,
  onNext,
}: FloatingPillNavProps) {
  return (
    <div className="fixed bottom-6 left-1/2 -translate-x-1/2 z-bottom-nav safe-area-inset-bottom">
      <div className="glass-pill flex items-center gap-0 rounded-full px-2 py-2 shadow-lg">
        <FavoriteButton isFavorite={isFavorite} onClick={onFavoriteToggle} />

        {/* 区切り線 */}
        <div className="w-px h-8 bg-white/30 mx-1" />

        <NextButton onClick={onNext} />
      </div>
    </div>
  );
}
```

### FavoriteButton.tsx

```tsx
"use client";

import { HeartIcon } from "lucide-react";

interface FavoriteButtonProps {
  isFavorite: boolean;
  onClick: () => void;
}

export function FavoriteButton({ isFavorite, onClick }: FavoriteButtonProps) {
  const handleClick = () => {
    // 触覚フィードバック（対応端末のみ）
    if (navigator.vibrate) {
      navigator.vibrate(10);
    }
    onClick();
  };

  return (
    <button
      onClick={handleClick}
      className="w-12 h-12 flex items-center justify-center rounded-full transition-colors hover:bg-white/20 active:bg-white/30"
      aria-label={isFavorite ? "お気に入りから削除" : "お気に入りに追加"}
    >
      <HeartIcon
        className={`w-6 h-6 transition-colors ${
          isFavorite ? "fill-red-500 text-red-500" : "text-gray-700"
        }`}
      />
    </button>
  );
}
```

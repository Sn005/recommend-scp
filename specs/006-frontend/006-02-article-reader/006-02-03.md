# Subtask 006-02-03: フローティングUI制御

## 概要

スクロール検知によるPillNav/ProgressBarの表示・非表示制御を実装する。
下スクロール時の非表示、上スクロール・停止時の再表示アニメーションを担当。

## ステータス

- **status**: completed

## 親Story

[006-02: 記事閲覧](./006-02.md)

## ユーザーストーリー

**ペルソナ**: SCPファン
**目的**: 記事閲覧中にUIが邪魔にならない体験を得る
**価値**: 没入感を損なわずに必要な時だけUIにアクセスできる
**理由**: 記事に集中しながらも操作性を維持したい

> SCPファンとして、記事閲覧中にUIが邪魔にならない体験を得て、没入感を損なわずに必要な時だけUIにアクセスしたい。なぜなら記事に集中しながらも操作性を維持したいから。

## Acceptance Criteria（EARS記法）

### AC-1: 通常時表示

- [x] WHEN 記事閲覧ページが表示された際
      THEN PillNavとProgressBarが表示される
      AND 表示位置は画面下部固定

### AC-2: 下スクロール時の非表示

- [x] WHEN ユーザーが下方向にスクロールした際
      GIVEN スクロール量が閾値（50px）を超えた場合
      THEN PillNavがフェードアウトする（300ms）
      AND ProgressBarは常に表示を維持する

### AC-3: 上スクロール時の再表示

- [x] WHEN ユーザーが上方向にスクロールした際
      THEN PillNavがフェードインする（300ms）

### AC-4: スクロール停止時の再表示

- [x] WHEN ユーザーがスクロールを停止した際
      GIVEN 2秒経過した場合
      THEN PillNavがフェードインする

### AC-5: 記事最下部での常時表示

- [x] WHEN 記事最下部（スクロール率90%以上）に到達した際
      THEN PillNavが常時表示される
      AND 非表示アニメーションが無効化される

### useFloatingUIVisibility フック

```typescript
// FloatingUI/useFloatingUIVisibility.ts
interface UseFloatingUIVisibilityOptions {
  /** スクロール率（0-100） */
  scrollPercentage: number;
  /** 非表示になるスクロール閾値（px） */
  hideThreshold?: number;
  /** スクロール停止後の再表示までの時間（ms） */
  showDelayMs?: number;
  /** 常時表示になるスクロール率 */
  alwaysShowThreshold?: number;
}

interface UseFloatingUIVisibilityReturn {
  /** PillNavの表示状態 */
  isPillNavVisible: boolean;
  /** スクロール位置を更新 */
  updateScrollDirection: (currentScrollY: number) => void;
}

export function useFloatingUIVisibility({
  scrollPercentage,
  hideThreshold = 50,
  showDelayMs = 2000,
  alwaysShowThreshold = 90,
}: UseFloatingUIVisibilityOptions): UseFloatingUIVisibilityReturn {
  const [isPillNavVisible, setIsPillNavVisible] = useState(true);
  const [lastScrollY, setLastScrollY] = useState(0);
  const timeoutRef = useRef<NodeJS.Timeout | null>(null);

  // 記事最下部では常時表示
  useEffect(() => {
    if (scrollPercentage >= alwaysShowThreshold) {
      setIsPillNavVisible(true);
    }
  }, [scrollPercentage, alwaysShowThreshold]);

  const updateScrollDirection = useCallback(
    (currentScrollY: number) => {
      // 最下部では何もしない
      if (scrollPercentage >= alwaysShowThreshold) return;

      const deltaY = currentScrollY - lastScrollY;
      setLastScrollY(currentScrollY);

      // タイマーをクリア
      if (timeoutRef.current) {
        clearTimeout(timeoutRef.current);
      }

      if (deltaY > hideThreshold) {
        // 下スクロール: 非表示
        setIsPillNavVisible(false);
      } else if (deltaY < 0) {
        // 上スクロール: 表示
        setIsPillNavVisible(true);
      }

      // スクロール停止後に再表示
      timeoutRef.current = setTimeout(() => {
        setIsPillNavVisible(true);
      }, showDelayMs);
    },
    [lastScrollY, scrollPercentage, alwaysShowThreshold, hideThreshold, showDelayMs]
  );

  // クリーンアップ
  useEffect(() => {
    return () => {
      if (timeoutRef.current) {
        clearTimeout(timeoutRef.current);
      }
    };
  }, []);

  return { isPillNavVisible, updateScrollDirection };
}
```

### FloatingUI コンポーネント

```tsx
// FloatingUI/FloatingUI.tsx
"use client";

import { cn } from "@/shared/lib/utils";
import { PillNav } from "@/shared/components/ui/PillNav";
import { ProgressBar } from "@/shared/components/ui/ProgressBar";
import { useFloatingUIVisibility } from "./useFloatingUIVisibility";
import type { FloatingUIProps } from "./index";

export function FloatingUI({
  progress,
  isFavorited,
  onFavorite,
  onNext,
  scrollPercentage = 0,
}: FloatingUIProps) {
  const { isPillNavVisible } = useFloatingUIVisibility({
    scrollPercentage,
  });

  return (
    <div className="fixed bottom-0 left-0 right-0 z-nav pointer-events-none">
      {/* ProgressBar - 常時表示 */}
      <div className="px-4 mb-2 pointer-events-auto">
        <ProgressBar value={progress} />
      </div>

      {/* PillNav - スクロールで表示/非表示 */}
      <div
        className={cn(
          "flex justify-center pb-8 transition-opacity duration-300 pointer-events-auto",
          isPillNavVisible ? "opacity-100" : "opacity-0 pointer-events-none"
        )}
      >
        <PillNav isFavorited={isFavorited} onFavorite={onFavorite} onNext={onNext} />
      </div>
    </div>
  );
}
```

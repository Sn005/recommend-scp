## ユーザーストーリー

**ペルソナ**: ユーザー
**目的**: お気に入りに保存した記事を一覧で確認し、タップして読み返す
**価値**: 保存した記事に素早くアクセスできる
**理由**: 気に入った記事をいつでも簡単に見つけたい

> ユーザーとして、お気に入りに保存した記事を一覧で確認し、タップして読み返したい。なぜなら気に入った記事をいつでも簡単に見つけたいから。

## 背景

### 責務

- `FavoriteList` - お気に入り記事のリスト表示

- 削除ボタンで `onRemove` コールバック実行

### 実装パターン

```typescript
// FavoriteCard/index.tsx
export const FavoriteCard = ({ article, onRemove, isRemoving }: FavoriteCardProps) => {
  const router = useRouter();

  const handleCardClick = () => {
    router.push(`/recommend?article=${article.articleId}`);
  };

  const handleRemoveClick = (e: React.MouseEvent) => {
    e.stopPropagation(); // カードクリックを阻止
    onRemove(article.articleId);
  };

  return (
    <div
      className={cn(
        "fav-card bg-white rounded-xl shadow-sm p-4 cursor-pointer",
        "transition-all duration-300",
        isRemoving && "opacity-0 scale-95"
      )}
      onClick={handleCardClick}
    >
      <div className="flex items-start gap-3">
        <div className="flex-1">
          <div className="flex items-center gap-2 mb-1">
            <ObjectClassBadge variant={article.objectClass}>
              {article.objectClass}
            </ObjectClassBadge>
            <span className="text-xs text-gray-400">+{article.rating.toLocaleString()}</span>
          </div>
          <h3 className="font-semibold text-gray-800">{article.title}</h3>
          <p className="text-sm text-gray-500 mt-1 line-clamp-1">{article.excerpt}</p>
        </div>
        <button
          onClick={handleRemoveClick}
          className="p-1 hover:bg-gray-100 rounded"
          aria-label="お気に入りから削除"
        >
          <Icon name="x" size={16} className="text-gray-400" />
        </button>
        <Icon name="chevron-right" size={20} className="text-gray-300 flex-shrink-0" />
      </div>
    </div>
  );
};
```

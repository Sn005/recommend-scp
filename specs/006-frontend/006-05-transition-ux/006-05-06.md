# Subtask 006-05-06: フィードバック判定改善

## 概要

「次へ」ボタン押下時の明示的Dislike記録を廃止し、スクロール深度と滞在時間に基づく暗黙的フィードバック（interest_level）を導入する。
ユーザーの明示的なネガティブ判断を求めず、行動データから興味度を推定する。

## ステータス

- **status**: completed

## 親Story

[006-05: 記事遷移UX改善](./006-05.md)

## ユーザーストーリー

**ペルソナ**: SCPファン
**目的**: 「次へ」を押しても否定的なフィードバックとして記録されない
**価値**: 気軽に記事をスキップでき、推薦の精度も向上する
**理由**: 「まだ読んでいないだけ」と「興味がない」は異なる意味を持つ

> SCPファンとして、「次へ」ボタンを押しても否定的フィードバックとして記録されたくない。なぜなら「後で読みたい」だけでDislikeになるのは推薦精度を下げるから。

## 背景

### 現行のフィードバック判定

| アクション         | フィードバック        | 問題                                    |
| ------------------ | --------------------- | --------------------------------------- |
| スクロール90%到達  | Like（暗黙的）        | 問題なし                                |
| 「次へ」ボタン押下 | **Dislike（明示的）** | 冒頭だけ見て次に進んだ場合もDislike扱い |
| お気に入りボタン   | Favorite（明示的）    | 問題なし                                |

### 既存仕様との関係

**006-02 AC-5の上書き**: 006-02-05で実装された「次へ」ボタン押下時のDislike記録（006-02 AC-5）を廃止し、暗黙的フィードバック（skip + interest_level）に置き換える。

### 新しいフィードバック判定

| アクション         | フィードバック     | 判定ロジック                                         |
| ------------------ | ------------------ | ---------------------------------------------------- |
| スクロール90%到達  | Like（暗黙的）     | 変更なし                                             |
| 「次へ」ボタン押下 | **暗黙的スキップ** | scroll depth + dwell time から interest_level を算出 |
| お気に入りボタン   | Favorite（明示的） | 変更なし                                             |

### interest_levelの算出

```
interest_level = f(scrollDepth, dwellTime)

低興味: scrollDepth < 10% かつ dwellTime < 5s → "skip"（興味なし）
中興味: scrollDepth 10-50% または dwellTime 5-30s → "neutral"（判断保留）
高興味: scrollDepth > 50% かつ dwellTime > 30s → "like"に近い（読んだが次へ進んだ）
```

## Acceptance Criteria（EARS記法）

### AC-1: Dislike記録の廃止

- [x] WHEN ユーザーが「次へ」ボタンをタップした際
      THEN type=dislikeのフィードバックが記録されない

### AC-2: 暗黙的フィードバックの記録

- [x] WHEN ユーザーが「次へ」ボタンをタップした際
      THEN スクロール深度（scrollDepth: 0-100）と滞在時間（dwellTime: 秒）が計測される
      AND interest_level（skip/neutral/like）が算出される
      AND POST /feedback APIにtype="skip"とメタデータ（scrollDepth, dwellTime）が送信される

### AC-3: 低興味判定（skip）

- [x] WHEN ユーザーが「次へ」ボタンをタップした際
      GIVEN scrollDepthが10%未満かつdwellTimeが5秒未満の場合
      THEN interest_level="skip"として記録される

### AC-4: 中興味判定（neutral）

- [x] WHEN ユーザーが「次へ」ボタンをタップした際
      GIVEN scrollDepthが10-50%またはdwellTimeが5-30秒の場合
      THEN interest_level="neutral"として記録される

### AC-5: 高興味判定（like相当）

- [x] WHEN ユーザーが「次へ」ボタンをタップした際
      GIVEN scrollDepthが50%超かつdwellTimeが30秒超の場合
      THEN interest_level="like"として記録される（暗黙的Like相当）

### AC-6: スクロール深度の計測

- [x] WHERE 記事閲覧中において
      THE SYSTEM SHALL iframe内のスクロール位置を継続的に追跡する
      AND 最大到達スクロール深度を保持する（スクロールバックしても減らない）

### AC-7: 滞在時間の計測

- [x] WHERE 記事閲覧中において
      THE SYSTEM SHALL 記事表示開始時刻からの経過時間を計測する
      AND 「次へ」タップ時の滞在時間を取得する

### AC-8: 既存Like/Favoriteとの優先度

- [x] WHERE フィードバック優先度において
      IF 既にLikeまたはFavoriteが記録された記事で「次へ」がタップされた場合
      THE SYSTEM SHALL 暗黙的フィードバックの送信をスキップする（優先度: favorite > like > skip/neutral）

### AC-9: API後方互換性

- [x] WHERE POST /feedback APIにおいて
      THE SYSTEM SHALL 既存の "like" | "dislike" | "favorite" 型に加えて "skip" 型を受け付ける
      AND メタデータ（scrollDepth, dwellTime, interestLevel）をオプショナルフィールドとして受け付ける

### useFeedback変更

```typescript
// Before
type FeedbackType = "like" | "dislike" | "favorite";
recordDislike: (articleId: string) => Promise<void>;

// After
type FeedbackType = "like" | "skip" | "favorite";

interface SkipMetadata {
  scrollDepth: number; // 0-100
  dwellTime: number; // 秒
  interestLevel: "skip" | "neutral" | "like";
}

recordSkip: (articleId: string, metadata: SkipMetadata) => Promise<void>;
```

### interest_level算出ロジック

```typescript
function calculateInterestLevel(
  scrollDepth: number,
  dwellTime: number
): "skip" | "neutral" | "like" {
  if (scrollDepth < 10 && dwellTime < 5) return "skip";
  if (scrollDepth > 50 && dwellTime > 30) return "like";
  return "neutral";
}
```

### page.tsx handleNext変更

```typescript
// Before
const handleNext = useCallback(() => {
  if (transitioningRef.current || !currentArticle) return;
  void recordDislike(currentArticle.id);
  goToNext();
}, [currentArticle, recordDislike, goToNext]);

// After
const handleNext = useCallback(() => {
  if (transitioningRef.current || !currentArticle) return;
  const metadata: SkipMetadata = {
    scrollDepth: currentScrollDepth, // useScrollPositionから取得
    dwellTime: (Date.now() - articleStartTime) / 1000,
    interestLevel: calculateInterestLevel(currentScrollDepth, dwellTime),
  };
  void recordSkip(currentArticle.id, metadata);
  goToNext();
}, [currentArticle, recordSkip, goToNext, currentScrollDepth, articleStartTime]);
```

### フィードバックAPI変更

```typescript
// POST /feedback リクエスト拡張
interface FeedbackRequest {
  articleId: string;
  type: "like" | "skip" | "favorite"; // "dislike" → "skip"
  metadata?: {
    scrollDepth?: number;
    dwellTime?: number;
    interestLevel?: "skip" | "neutral" | "like";
  };
}
```

## 備考

- "dislike"型はAPI側で後方互換性のために残すが、フロントからは送信しない
- interest_levelの閾値（10%/50%、5s/30s）は運用データを見て調整可能
- 推薦エンジン側でskip/neutral/likeの重み付けを調整する必要がある（別タスク）
- 滞在時間はページ表示開始〜「次へ」ボタン押下の差分で計算（バックグラウンドタブ考慮なし）

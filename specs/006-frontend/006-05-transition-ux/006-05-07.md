# Subtask 006-05-07: 遷移UX統合・結合テスト

## 概要

006-05-01〜06の全変更をpage.tsxに統合する。
「次へ」ボタン押下 → 遷移ヘッダーカード表示 → 次記事表示のフルフローを実装し、
全コンポーネントの結合テストを行う。

## ステータス

- **status**: completed

## 親Story

[006-05: 記事遷移UX改善](./006-05.md)

## ユーザーストーリー

**ペルソナ**: SCPファン
**目的**: 全ての遷移UX改善が統合された記事閲覧体験を得る
**価値**: 「次へ」を押すとオブジェクトクラスのグラデーションカードが一瞬表示され、待ち時間なく次の記事が読める
**理由**: 個別の改善が統合されて初めて完成した体験になる

> SCPファンとして、「次へ」ボタンを押すとSCPのオブジェクトクラスカードが一瞬表示され、シームレスに次の記事が読める完成された体験を得たい。

## 背景

### 統合対象

| Subtask   | 統合対象           | page.tsxへの影響                        |
| --------- | ------------------ | --------------------------------------- |
| 006-05-01 | API拡張            | Article型にobjectClass/ratingが含まれる |
| 006-05-02 | デザイントークン   | ObjectClassBadge拡張済み                |
| 006-05-03 | TransitionCard     | 遷移フローに組み込み                    |
| 006-05-04 | useIframePool      | デュアルWebView → 3スロットプール       |
| 006-05-05 | ProgressBar削除    | FloatingUIからprogress prop削除         |
| 006-05-06 | フィードバック改善 | handleNext: dislike → skip + metadata   |

### 統合後の遷移フロー

```
1. ユーザーが「次へ」ボタンをタップ
   ├─ recordSkip(currentArticle.id, metadata) 実行
   └─ 遷移状態開始

2. 現在の記事がフェードアウト（150ms）

3. TransitionCard がフェードイン
   ├─ 次記事のSCP番号・バッジ・rating表示
   └─ 次記事のobjectClassに応じたグラデーション背景

4. 適応型タイミング待機
   ├─ isNextReady(iframePool) → isContentReady(TransitionCard)
   ├─ min: 500ms
   └─ max: 1000ms

5. TransitionCard がフェードアウト（150ms）

6. 次の記事がフェードイン（150ms）
   ├─ iframePool.advance() 実行
   └─ 3スロットローテーション開始

7. 記事表示完了
   └─ 新しいPrefetchスロットのiframe読み込み開始
```

## Acceptance Criteria（EARS記法）

### AC-1: フルフロー遷移

- [x] WHEN ユーザーが「次へ」ボタンをタップした際
      THEN 以下の順序で遷移が実行される1. 現在の記事がフェードアウト2. TransitionCardがフェードイン（次記事のSCP番号+バッジ+rating+グラデーション）3. 適応型タイミング（500-1000ms）後にTransitionCardがフェードアウト4. 次の記事がフェードイン

### AC-2: iframeプール統合

- [x] WHEN page.tsxが表示された際
      THEN useIframePoolが3スロットiframeプールを管理する
      AND 遷移完了後にスロットローテーションが実行される
      AND 最大3つのiframeのみがDOMに存在する

### AC-3: TransitionCardとiframePoolの連携

- [x] WHEN TransitionCardが表示されている間
      THEN iframePool.isNextReadyの値がTransitionCardのisContentReadyに渡される
      AND isContentReady=true かつ 500ms以上経過でカードがフェードアウトする

### AC-4: フィードバック統合

- [x] WHEN ユーザーが「次へ」ボタンをタップした際
      THEN recordSkipがscrollDepthとdwellTimeメタデータ付きで呼ばれる
      AND recordDislikeは呼ばれない

### AC-5: ProgressBar非表示

- [x] WHEN 記事閲覧画面が表示された際
      THEN FloatingUIにprogress propが渡されていない
      AND ProgressBarが表示されていない

### AC-6: 連打防止

- [x] WHILE 遷移アニメーション中の間
      THE SYSTEM SHALL 「次へ」ボタンの連打を防止する
      AND TransitionCard表示中は追加の遷移を受け付けない

### AC-7: スクロール到達で自動遷移しない（仕様変更）

- [x] WHEN ユーザーが記事最下部にスクロールで到達した際
      THEN 自動的な記事遷移は発生しない
      AND 自動的なLike記録は発生しない
      AND ユーザーが「次へ」ボタンをタップするまで現在の記事が表示され続ける

> **仕様変更理由**: Story spec（006-05.md）では遷移トリガーは「次へ」ボタンタップのみと定義。
> スクロール深度はフィードバックメタデータとして利用（AC-4参照）し、遷移トリガーとしては使用しない。

### AC-8: お気に入りボタン正常動作

- [x] WHEN ユーザーがお気に入りボタンをタップした際
      THEN 従来通りのお気に入りトグル動作が実行される
      AND 遷移フローに影響しない

### AC-9: 推薦切れ・エラー時の挙動

- [x] WHEN 推薦記事がなくなった際
      THEN EmptyStateが表示される（既存挙動維持）
- [x] WHEN API呼び出しでエラーが発生した際
      THEN ErrorStateが表示される（既存挙動維持）

### AC-10: prefers-reduced-motion対応

- [x] WHEN ユーザーがprefers-reduced-motionを設定している際
      THEN フェードアニメーションがスキップされる
      AND 遷移は即座に完了する
      AND TransitionCardは表示されるが最小表示時間（500ms）は維持する

## 技術設計

### page.tsx 統合後の構成

```tsx
export default function RecommendPage() {
  // 記事データ
  const { articles, currentIndex, isLoading, error, isEmpty, goToNext, reset } =
    useInfiniteArticles();

  // iframeプール
  const { slots, isNextReady, advance, handleIframeLoad } = useIframePool({
    articles,
    currentIndex,
  });

  // フィードバック（skip対応）
  const { recordLike, recordSkip, recordFavorite, hasRecorded } = useFeedback();

  // お気に入り
  const currentArticle = articles[currentIndex];
  const { isFavorited, toggleFavorite } = useArticleFavorite(currentArticle?.id);

  // 閲覧履歴
  const { recordView } = useHistory();

  // 遷移状態管理
  const [isTransitioning, setIsTransitioning] = useState(false);
  const [showCard, setShowCard] = useState(false);
  const [nextArticleForCard, setNextArticleForCard] = useState<Article | null>(null);

  // スクロール深度・滞在時間
  const scrollDepthRef = useRef(0);
  const articleStartTimeRef = useRef(Date.now());

  // 「次へ」ハンドラ
  const handleNext = useCallback(() => {
    if (isTransitioning) return;
    const nextArticle = articles[currentIndex + 1];
    if (!nextArticle) return;

    // 暗黙的フィードバック
    if (currentArticle && !hasRecorded(currentArticle.id)) {
      const dwellTime = (Date.now() - articleStartTimeRef.current) / 1000;
      void recordSkip(currentArticle.id, {
        scrollDepth: scrollDepthRef.current,
        dwellTime,
        interestLevel: calculateInterestLevel(scrollDepthRef.current, dwellTime),
      });
    }

    // 遷移開始
    setIsTransitioning(true);
    setNextArticleForCard(nextArticle);
    setShowCard(true);
  }, [isTransitioning, currentArticle, articles, currentIndex, hasRecorded, recordSkip]);

  // TransitionCard dismissハンドラ
  const handleCardDismissed = useCallback(() => {
    setShowCard(false);
    advance();       // iframeプールローテーション
    goToNext();      // currentIndex更新

    // 新しい記事用にリセット
    scrollDepthRef.current = 0;
    articleStartTimeRef.current = Date.now();
    setIsTransitioning(false);
  }, [advance, goToNext]);

  // スクロール到達で自動遷移しない（仕様変更: AC-7）
  // スクロール深度はonScrollChange経由でメタデータとして記録し、
  // 「次へ」ボタンタップ時のrecordSkipに含める（AC-4参照）

  // ... Loading/Error/Empty states ...

  return (
    <div className="relative h-screen">
      {/* Current Article（onScrollEndなし: 自動遷移しない） */}
      <ArticleWebView
        key={slots[0].articleIndex}
        url={slots[0].url}
        onLoad={() => handleIframeLoad(slots[0].articleIndex)}
        onScrollChange={(pct) => { scrollDepthRef.current = Math.max(scrollDepthRef.current, pct); }}
        className={showCard ? "opacity-0" : "opacity-100"}
      />

      {/* Next (hidden, prerendered) */}
      {slots[1] && (
        <ArticleWebView ... className="hidden" />
      )}

      {/* Prefetch (hidden) */}
      {slots[2] && (
        <ArticleWebView ... className="hidden" />
      )}

      {/* Transition Card */}
      {nextArticleForCard && (
        <TransitionCard
          scpNumber={nextArticleForCard.id}
          objectClass={nextArticleForCard.objectClass}
          rating={nextArticleForCard.rating}
          isVisible={showCard}
          isContentReady={isNextReady}
          onDismissed={handleCardDismissed}
        />
      )}

      {/* Floating UI (ProgressBarなし) */}
      <FloatingUI
        isFavorited={isFavorited}
        onFavorite={() => {
          if (currentArticle) {
            void recordFavorite(currentArticle.id);
            toggleFavorite();
          }
        }}
        onNext={handleNext}
      />
    </div>
  );
}
```

### 状態遷移図

```
[Idle] ─── handleNext() ──→ [Transitioning]
                                  │
                          setShowCard(true)
                                  │
                                  ↓
                          [Card Visible]
                                  │
                          onDismissed()
                                  │
                                  ↓
                          [Card Hidden]
                                  │
                          advance() + goToNext()
                                  │
                                  ↓
                              [Idle]
```

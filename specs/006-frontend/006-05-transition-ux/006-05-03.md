# Subtask 006-05-03: 遷移ヘッダーカードコンポーネント

## 概要

記事間の遷移時に表示されるTransitionCardコンポーネントを新規実装する。
オブジェクトクラス別グラデーション背景にSCP番号、クラスバッジ、ratingを表示し、
フェードイン→フェードアウトの適応型タイミング（500ms〜1000ms）で遷移を演出する。

## ステータス

- **status**: pending

## 親Story

[006-05: 記事遷移UX改善](./006-05.md)

## ユーザーストーリー

**ペルソナ**: SCPファン
**目的**: 次の記事に切り替わる瞬間に、そのSCPの情報を一瞬見る
**価値**: 「次はKeterか！」というワクワク感が得られる
**理由**: 無機質な画面切り替えではなく、次の記事への期待を高めたい

> SCPファンとして、次の記事に切り替わる瞬間にSCP番号・オブジェクトクラス・ratingが一瞬表示されてほしい。なぜなら「次はKeterか！」というワクワク感を得たいから。

## 背景

### 遷移フロー

```
1. ユーザーが「次へ」ボタンをタップ
2. 現在の記事がフェードアウト（150ms）
3. TransitionCard がフェードイン（150ms）
4. 次の記事のiframe読み込みを待機（min 500ms / max 1000ms）
5. TransitionCard がフェードアウト（150ms）
6. 次の記事がフェードイン（150ms）
```

### 適応型タイミング

| 条件                                  | 動作                                             |
| ------------------------------------- | ------------------------------------------------ |
| iframe読み込み完了 かつ 500ms以上経過 | 即座にカード非表示                               |
| iframe読み込み完了 だが 500ms未満     | 500msまで待ってからカード非表示                  |
| 1000ms経過 だが iframe未完了          | 強制的にカード非表示（iframe読み込みは裏で継続） |

### カードレイアウト

```
┌─────────────────────────────────────┐
│                                     │
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │  ← グラデーション背景
│  ▓                               ▓  │    （例: Euclid = #92400E → #F59E0B）
│  ▓       SCP-173                 ▓  │  ← SCP番号（白、大文字、太字）
│  ▓       [Euclid]  ★ 4250       ▓  │  ← バッジ + rating（横並び）
│  ▓                               ▓  │
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │
│                                     │
└─────────────────────────────────────┘
```

## Acceptance Criteria（EARS記法）

### AC-1: カード表示内容

- [ ] WHEN TransitionCardが表示された際
      THEN SCP番号（例: "SCP-173"）が白色の大きなテキストで表示される
      AND オブジェクトクラスバッジ（ObjectClassBadge）が表示される
      AND rating（例: "★ 4250"）が白色テキストで表示される

### AC-2: オブジェクトクラス別グラデーション

- [ ] WHEN TransitionCardが表示された際
      GIVEN 記事のobjectClassが"EUCLID"の場合
      THEN 背景にdesign-tokens.cssの`--gradient-euclid`に対応するグラデーションが適用される
      AND 全7クラス + Unknown で各固有のグラデーションが適用される

### AC-3: フェードインアニメーション

- [ ] WHEN TransitionCardが表示される際
      THEN opacity: 0 → 1 のフェードインが150msで再生される

### AC-4: 適応型タイミング（最小表示時間）

- [ ] WHEN TransitionCardが表示された際
      GIVEN 次の記事のiframeが即座に読み込み完了した場合
      THEN 最低500ms間はカードを表示し続ける

### AC-5: 適応型タイミング（最大表示時間）

- [ ] WHEN TransitionCardが表示された際
      GIVEN 1000ms経過してもiframeが読み込み完了しない場合
      THEN 1000ms経過時点でカードをフェードアウトする

### AC-6: 適応型タイミング（通常ケース）

- [ ] WHEN TransitionCardが表示された際
      GIVEN 500ms以降にiframeが読み込み完了した場合
      THEN iframe完了時点で即座にカードをフェードアウトする

### AC-7: フェードアウトアニメーション

- [ ] WHEN TransitionCardが非表示になる際
      THEN opacity: 1 → 0 のフェードアウトが150msで再生される

### AC-8: objectClass未定義時のフォールバック

- [ ] WHEN TransitionCardが表示された際
      GIVEN 記事のobjectClassがnullの場合
      THEN Unknown用のグラデーション（`#4B5563 → #9CA3AF`）が適用される
      AND バッジに「Unknown」と表示される

### AC-9: rating未定義時のフォールバック

- [ ] WHEN TransitionCardが表示された際
      GIVEN 記事のratingがnullの場合
      THEN ratingの表示を省略する（SCP番号とバッジのみ）

### Props定義

```typescript
interface TransitionCardProps {
  /** SCP番号（例: "SCP-173"） */
  scpNumber: string;
  /** オブジェクトクラス（例: "EUCLID"）。nullの場合Unknown */
  objectClass: string | null;
  /** 記事の評価値。nullの場合非表示 */
  rating: number | null;
  /** 表示状態 */
  isVisible: boolean;
  /** iframe読み込み完了通知 */
  isContentReady: boolean;
  /** カード非表示完了コールバック */
  onDismissed: () => void;
}
```

### 適応型タイミングロジック

```typescript
const CARD_MIN_MS = 500;
const CARD_MAX_MS = 1000;
const FADE_DURATION_MS = 150;

// 状態管理
// 1. isVisible=true でタイマー開始
// 2. CARD_MIN_MS経過 → minTimeReached=true
// 3. isContentReady=true → contentReady=true
// 4. minTimeReached && contentReady → フェードアウト開始
// 5. CARD_MAX_MS経過 → 強制フェードアウト
// 6. フェードアウト完了 → onDismissed()
```

### グラデーションマッピング

```typescript
const GRADIENTS: Record<string, string> = {
  SAFE: "linear-gradient(135deg, #065F46, #10B981)",
  EUCLID: "linear-gradient(135deg, #92400E, #F59E0B)",
  KETER: "linear-gradient(135deg, #991B1B, #EF4444)",
  THAUMIEL: "linear-gradient(135deg, #3730A3, #6366F1)",
  NEUTRALIZED: "linear-gradient(135deg, #374151, #6B7280)",
  APOLLYON: "linear-gradient(135deg, #450A0A, #DC2626)",
  ARCHON: "linear-gradient(135deg, #4C1D95, #8B5CF6)",
};

const DEFAULT_GRADIENT = "linear-gradient(135deg, #4B5563, #9CA3AF)";

const getGradient = (objectClass: string | null): string =>
  objectClass ? (GRADIENTS[objectClass.toUpperCase()] ?? DEFAULT_GRADIENT) : DEFAULT_GRADIENT;
```

### レイアウト構造

```tsx
<div
  className="fixed inset-0 z-[60] flex items-center justify-center"
  style={{ background: getGradient(objectClass) }}
>
  <div className="text-center text-white">
    <p className="text-3xl font-bold mb-3">{scpNumber}</p>
    <div className="flex items-center justify-center gap-3">
      <ObjectClassBadge variant={normalizeClass(objectClass)} />
      {rating !== null && <span className="text-lg font-medium">★ {rating.toLocaleString()}</span>}
    </div>
  </div>
</div>
```

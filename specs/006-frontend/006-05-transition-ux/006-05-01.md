# Subtask 006-05-01: 推薦APIレスポンス拡張

## 概要

推薦API（POST /recommend）のレスポンスに`objectClass`と`rating`フィールドを追加する。
Supabase RPC関数の返却カラム追加、Repository層・型定義の更新を行う。

## ステータス

- **status**: completed

## 親Story

[006-05: 記事遷移UX改善](./006-05.md)

## ユーザーストーリー

**ペルソナ**: フロントエンドの遷移ヘッダーカード
**目的**: 推薦記事のオブジェクトクラスとratingを取得する
**価値**: 遷移カードにクラス別グラデーションとrating表示ができる
**理由**: APIが返さないデータはフロントで表示できない

> フロントエンドの遷移ヘッダーカードとして、推薦記事のオブジェクトクラスとratingを取得したい。なぜなら遷移カードにクラス別グラデーション背景とrating表示を実現するために必要だから。

## 背景

### 現状

| 項目                 | 現行                                | 問題                     |
| -------------------- | ----------------------------------- | ------------------------ |
| RPC関数の返却        | `(id, title, similarity, url)`      | objectClass/ratingがない |
| RecommendedArticle型 | id/title/similarityScore/source/url | 同上                     |
| scp_articles.tags    | TEXT[] にオブジェクトクラスが混在   | 構造化されていない       |
| scp_articles.rating  | INTEGER カラムが存在                | RPC関数で返却していない  |

### 対象RPC関数（3つ）

| RPC関数                              | 用途               | マイグレーション                                   |
| ------------------------------------ | ------------------ | -------------------------------------------------- |
| `search_articles_by_embedding`       | ベクトル類似度検索 | `20260131000003_update_search_rpc_with_ja_url.sql` |
| `search_articles_by_unexplored_tags` | 未探索タグ検索     | 同上                                               |
| `search_adjacent_articles`           | 隣接記事検索       | 同上                                               |

### objectClassの取得方法

`scp_articles.tags` カラム（TEXT[]）にオブジェクトクラスが格納されている。
`tag_dictionary` テーブルの `category = 'object_class'` と突合して抽出する。

```sql
-- tag_dictionaryのobject_class値: SAFE, EUCLID, KETER, THAUMIEL, NEUTRALIZED, APOLLYON, ARCHON
-- scp_articles.tagsの例: ['EUCLID', 'HORROR', 'COGNITION']
-- → tagsとtag_dictionary(object_class)の共通部分を取得
```

### Unknownクラスの取り扱い

- tag_dictionaryには7クラスのみ格納（SAFE, EUCLID, KETER, THAUMIEL, NEUTRALIZED, APOLLYON, ARCHON）
- **Unknown**: tag_dictionaryに存在しないため、`get_object_class()`がNULLを返す
- フロントエンド側で`null` → "Unknown"として表示（006-05-03で実装）

## 技術設計

### 新規マイグレーション

```sql
-- supabase/migrations/YYYYMMDD_add_object_class_rating_to_rpc.sql

-- objectClassを抽出するヘルパー関数
CREATE OR REPLACE FUNCTION get_object_class(article_tags TEXT[])
RETURNS TEXT AS $$
DECLARE
  oc TEXT;
BEGIN
  SELECT td.value INTO oc
  FROM tag_dictionary td
  WHERE td.category = 'object_class'
    AND td.value = ANY(article_tags)
  LIMIT 1;
  RETURN oc;
END;
$$ LANGUAGE plpgsql STABLE;
```

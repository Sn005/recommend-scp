# Subtask 006-05-02: デザイントークン・型定義拡張

## 概要

design-tokens.cssにオブジェクトクラス全8色（7クラス + Unknown）とグラデーション変数を追加する。
ObjectClassBadgeコンポーネントにApollyonとArchonを追加し、フロントエンド側のArticle型にobjectClassとratingフィールドを追加する。

## ステータス

- **status**: pending

## 親Story

[006-05: 記事遷移UX改善](./006-05.md)

## ユーザーストーリー

**ペルソナ**: 開発者
**目的**: 全オブジェクトクラスのカラーとグラデーションが一元管理されている
**価値**: 遷移カード・バッジ等のUI実装時にデザイントークンを参照するだけで統一的な色が使える
**理由**: 現状3色しか定義されておらず、コンポーネントごとにハードコードされている

> 開発者として、全オブジェクトクラスのカラーとグラデーションがデザイントークンで一元管理されていてほしい。なぜなら現状3色しか定義されておらず統一性がないから。

## Acceptance Criteria（EARS記法）

### AC-1: design-tokens.cssにオブジェクトクラス全色追加

- [ ] WHERE design-tokens.cssのステータス色セクションにおいて
      THE SYSTEM SHALL Safe/Euclid/Keter/Thaumiel/Neutralized/Apollyon/Archon/Unknownの8色が定義されている

### AC-2: グラデーション変数の追加

- [ ] WHERE design-tokens.cssにおいて
      THE SYSTEM SHALL 各オブジェクトクラスのグラデーション（暗色→明色）が定義されている
      AND 遷移ヘッダーカードの背景として使用可能な形式である

### AC-3: ObjectClassBadgeの拡張

- [ ] WHERE ObjectClassBadgeコンポーネントにおいて
      THE SYSTEM SHALL Apollyon/Archonのカラー定義が追加されている
      AND KnownObjectClass型にApollyonとArchonが含まれている

### AC-4: フロントエンドArticle型の拡張

- [ ] WHERE フロントエンドのArticle型定義において
      THE SYSTEM SHALL `objectClass: string | null` フィールドが含まれる
      AND `rating: number | null` フィールドが含まれる

### AC-5: ObjectClass型の統一

- [ ] WHERE オブジェクトクラスを扱う全コンポーネントにおいて
      THE SYSTEM SHALL 共通のObjectClass型を参照する
      AND 型定義が重複しない

### ObjectClassBadge変更

```typescript
// ObjectClassBadge.tsx
type KnownObjectClass =
  | "Safe"
  | "Euclid"
  | "Keter"
  | "Thaumiel"
  | "Neutralized"
  | "Apollyon"
  | "Archon";

const OBJECT_CLASS_COLORS: Record<KnownObjectClass, string> = {
  Safe: "#10B981",
  Euclid: "#F59E0B",
  Keter: "#EF4444",
  Thaumiel: "#6366F1", // 既存 #8B5CF6 → #6366F1 に統一
  Neutralized: "#6B7280",
  Apollyon: "#DC2626", // 新規
  Archon: "#8B5CF6", // 新規
};

const UNKNOWN_COLOR = "#9CA3AF";
```

**注意**: 既存のThaumielカラーが `#8B5CF6`（violet-500）だが、Phase 2で `#6366F1`（indigo-500）と定義した。Archonを `#8B5CF6` にするため、Thaumielを `#6366F1` に変更して差別化する。

## ユーザーストーリー

**ペルソナ**: SCPファン（エンドユーザー）
**目的**: 推薦の進捗状況を視覚的に確認する
**価値**: あとどれくらい記事があるか把握できる
**理由**: 進捗が見えると達成感があり、継続して使いたくなるから

> SCPファンとして、推薦の進捗状況を視覚的に確認して、あとどれくらい記事があるか把握したい。なぜなら進捗が見えると達成感があり、継続して使いたくなるから。

## Acceptance Criteria

### AC-1: 表示

- [ ] WHEN 推薦画面を表示した際
      THEN プログレスバーが表示される
      AND 現在の進捗が視覚的に分かる

### AC-2: 進捗表示

- [ ] WHEN 進捗値を渡した際
      GIVEN 0〜100の値の場合
      THEN バーがその割合で塗りつぶされる

### AC-3: アニメーション

- [ ] WHEN 進捗が更新された際
      THEN スムーズなアニメーションで変化する

### AC-4: カラー

- [ ] WHEN プログレスバーを表示した際
      THEN プライマリカラー（#3B82F6）で塗りつぶされる

### 実装例

```typescript
// ProgressBar.tsx
import { cn } from '@/shared/lib/utils';

interface ProgressBarProps {
  value: number;
  max?: number;
  className?: string;
}

export const ProgressBar = ({ value, max = 100, className }: ProgressBarProps) => {
  const percentage = Math.min(100, Math.max(0, (value / max) * 100));

  return (
    <div
      role="progressbar"
      aria-valuenow={value}
      aria-valuemin={0}
      aria-valuemax={max}
      className={cn('h-1 w-full bg-gray-200 rounded-full overflow-hidden', className)}
    >
      <div
        className="h-full bg-primary rounded-full transition-[width] duration-300 ease-out"
        style={{ width: `${percentage}%` }}
      />
    </div>
  );
};
```

## テストケース

- [ ] value=0 で空のバーが表示される
- [ ] value=50 で半分塗りつぶされる
- [ ] value=100 で完全に塗りつぶされる
- [ ] value が範囲外（負数や100超）でもクランプされる
- [ ] role="progressbar" が設定されている
- [ ] aria-valuenow, aria-valuemin, aria-valuemax が設定されている

# Story: 共通UIコンポーネント

## 親EPIC

[006: フロントエンドUI](../006-frontend.md)

## ユーザーストーリー

**ペルソナ**: SCPファン（エンドユーザー）
**目的**: 全画面で一貫したナビゲーションとUIを使用する
**価値**: 直感的な操作で迷わずにアプリを使える
**理由**: 画面ごとに異なる操作方法だと学習コストが高くなるから

> SCPファンとして、全画面で一貫したナビゲーションとUIを使用して、直感的にアプリを操作したい。なぜなら画面ごとに異なる操作方法だと学習コストが高くなるから。

## 背景

### デザイン原則（DESIGN_GUIDELINES.md より）

- **没入感最大化**: UI要素は最小限、コンテンツを最大化
- **2026年UIトレンド**: Glassmorphism、フローティングUI、ミニマルナビゲーション
- **一貫性**: 全画面で同じドロワーメニュー、戻るボタン廃止

### コンポーネント一覧

| コンポーネント           | 用途                       | 配置               |
| ------------------------ | -------------------------- | ------------------ |
| ドロワーメニュー         | 全画面共通のサイドメニュー | 左からスライドイン |
| メニューボタン（☰）     | ドロワーを開くトリガー     | 左上固定           |
| フローティングピルナビ   | 推薦画面のボトムナビ       | 下部中央           |
| オブジェクトクラスバッジ | Safe/Euclid/Keter表示      | 記事カード内       |
| プログレスバー           | 推薦進捗表示               | 推薦画面下部       |

## Acceptance Criteria

### AC-1: グローバルレイアウト

- [x] WHEN アプリにアクセスした際
      GIVEN メイン画面（推薦、お気に入り、履歴）の場合
      THEN 共通のMainLayoutが適用される
      AND ドロワーメニューとメニューボタンが使用可能になる

### AC-2: ドロワーメニュー

- [x] WHEN メニューボタンをタップした際
      GIVEN どの画面からでも
      THEN ドロワーメニューが左からスライドインする
      AND オーバーレイが表示される

- [x] WHEN ドロワー外（オーバーレイ）をタップした際
      GIVEN ドロワーが開いている状態で
      THEN ドロワーが閉じる

### AC-3: メニューボタン

- [x] WHEN 画面を表示した際
      GIVEN メイン画面の場合
      THEN 左上にメニューボタン（☰）が常時表示される
      AND Glassmorphism効果が適用される

### AC-4: フローティングピルナビ

- [x] WHEN 推薦画面を表示した際
      THEN 下部にフローティングピルナビが表示される
      AND お気に入りボタン（♡）と次へボタン（→）が配置される

### AC-5: オブジェクトクラスバッジ

- [x] WHEN オブジェクトクラスを表示する際
      GIVEN Safe/Euclid/Keter/Thaumiel/Neutralizedのいずれかの場合
      THEN 対応する色のバッジが表示される

### AC-6: プログレスバー

- [x] WHEN 推薦画面を表示した際
      THEN 推薦の進捗を示すプログレスバーが表示される

## 技術設計

### ディレクトリ構成（コロケーション原則）

```
apps/web/src/
├── app/
│   ├── layout.tsx              # RootLayout（フォント、メタデータのみ）
│   └── (main)/
│       └── layout.tsx          # MainLayout（ドロワー + メニューボタン）
│
└── shared/
    └── components/
        └── ui/
            ├── Drawer/         # ドロワー（Context・Hook含む）
            │   ├── index.tsx
            │   ├── Drawer.tsx
            │   ├── DrawerContext.tsx
            │   ├── DrawerProvider.tsx
            │   ├── useDrawer.ts
            │   └── DrawerMenu.tsx
            ├── MenuButton/
            ├── PillNav/
            ├── Badge/
            └── ProgressBar/
```

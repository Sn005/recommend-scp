# Subtask: メニューボタン

## 親Story

[006-00: 共通UIコンポーネント](./006-00.md)

## ユーザーストーリー

**ペルソナ**: SCPファン（エンドユーザー）
**目的**: 画面左上のボタンからドロワーメニューを開く
**価値**: いつでもナビゲーションにアクセスできる
**理由**: ボタンが常時表示されていれば迷わずメニューを開けるから

> SCPファンとして、画面左上のボタンからドロワーメニューを開いて、いつでもナビゲーションにアクセスしたい。なぜならボタンが常時表示されていれば迷わずメニューを開けるから。

## Acceptance Criteria

### AC-1: 常時表示

- [x] WHEN メイン画面（推薦、お気に入り、履歴）を表示した際
      THEN 左上にメニューボタン（☰）が固定表示される
      AND スクロールしても位置が変わらない

### AC-2: Glassmorphism効果

- [x] WHEN メニューボタンを表示した際
      THEN すりガラス効果（blur(12px)）が適用される
      AND 半透明の白背景（rgba(255,255,255,0.8)）が適用される

### AC-3: ドロワー連携

- [x] WHEN メニューボタンをタップした際
      THEN useDrawer フックの toggle() が呼び出される
      AND ドロワーが開く

### AC-4: タッチターゲット

- [x] WHEN メニューボタンを実装した際
      THEN タッチターゲットサイズが44x44px以上である（Apple HIG準拠）

### 実装例

```typescript
// MenuButton.tsx
import { useDrawer } from '@/shared/components/ui/Drawer';

export const MenuButton = () => {
  const { toggle } = useDrawer();

  return (
    <button
      onClick={toggle}
      aria-label="メニューを開く"
      className="fixed top-4 left-4 z-nav w-10 h-10 rounded-full
                 bg-white/80 backdrop-blur-md shadow-sm
                 flex items-center justify-center
                 transition-transform active:scale-95"
    >
      <span className="text-xl">☰</span>
    </button>
  );
};
```

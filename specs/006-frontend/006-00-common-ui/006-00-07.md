## ユーザーストーリー

**ペルソナ**: SCPファン（エンドユーザー）
**目的**: サイドメニューから各画面にナビゲーションする
**価値**: どの画面からでも素早く目的の画面に移動できる
**理由**: 戻るボタンやタブバーより没入感を損なわずにナビゲーションできるから

> SCPファンとして、サイドメニューから各画面にナビゲーションして、どの画面からでも素早く目的の画面に移動したい。なぜなら戻るボタンやタブバーより没入感を損なわずにナビゲーションできるから。

## Acceptance Criteria

### AC-1: ドロワー開閉

- [x] WHEN メニューボタンをタップした際
      THEN ドロワーが左からスライドインする（0.3s ease）
      AND オーバーレイ（rgba(0,0,0,0.3)）が表示される

- [x] WHEN オーバーレイをタップした際
      GIVEN ドロワーが開いている状態で
      THEN ドロワーが左へスライドアウトする
      AND オーバーレイが非表示になる

### AC-2: メニュー項目

- [x] WHEN ドロワーを開いた際
      THEN 以下のメニュー項目が表示される: - 📖 推薦を見る - ♡ お気に入り一覧 - 🕐 閲覧履歴
      AND 現在のページがハイライトされる

### AC-3: ナビゲーション

- [x] WHEN メニュー項目をタップした際
      THEN 対応するページに遷移する
      AND ドロワーが自動的に閉じる

### AC-4: コロケーション

- [x] WHEN Drawerコンポーネントを実装した際
      THEN Context・Provider・Hook・UIが同一ディレクトリに配置される
      AND `shared/components/ui/Drawer/` 内で完結する

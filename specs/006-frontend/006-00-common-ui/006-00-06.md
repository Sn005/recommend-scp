# Subtask: グローバルレイアウト

## 親Story

[006-00: 共通UIコンポーネント](./006-00.md)

## ユーザーストーリー

**ペルソナ**: フロントエンド開発者
**目的**: 全画面で共通のレイアウト構造を提供する
**価値**: コンポーネントの再利用性が向上し、一貫したUXを提供できる
**理由**: 画面ごとにレイアウトを実装すると重複コードが増え、保守性が低下するから

> フロントエンド開発者として、全画面で共通のレイアウト構造を提供して、コンポーネントの再利用性を向上させたい。なぜなら画面ごとにレイアウトを実装すると重複コードが増え、保守性が低下するから。

## Acceptance Criteria

### AC-1: Route Groups構成

- [x] WHEN `app/(main)/` ディレクトリを作成した際
      THEN メイン画面（推薦、お気に入り、履歴）が同一レイアウトを共有する
      AND オンボーディング画面は別レイアウトを使用する

### AC-2: MainLayout

- [x] WHEN `(main)/layout.tsx` を実装した際
      THEN DrawerProviderでchildrenをラップする
      AND メニューボタンとドロワーが全ページで使用可能になる

### AC-3: RootLayoutとの分離

- [x] WHEN `app/layout.tsx` を確認した際
      THEN フォント設定とメタデータのみを含む
      AND UI要素（ドロワー等）は含まない

## 技術設計

### ディレクトリ構成

```
apps/web/src/app/
├── layout.tsx              # RootLayout（フォント、メタデータ）
├── (main)/                 # Route Group
│   ├── layout.tsx          # MainLayout（ドロワー + メニューボタン）
│   ├── page.tsx            # リダイレクト（→ /recommend）
│   ├── recommend/
│   │   └── page.tsx
│   ├── favorites/
│   │   └── page.tsx
│   └── history/
│       └── page.tsx
└── onboarding/             # 別レイアウト
    ├── layout.tsx
    └── page.tsx
```

### MainLayout実装例

```typescript
// app/(main)/layout.tsx
import { DrawerProvider } from '@/shared/components/ui/Drawer';
import { MenuButton } from '@/shared/components/ui/MenuButton';
import { Drawer } from '@/shared/components/ui/Drawer';

export default function MainLayout({ children }: { children: React.ReactNode }) {
  return (
    <DrawerProvider>
      <div className="relative min-h-screen">
        <MenuButton />
        <Drawer />
        <main>{children}</main>
      </div>
    </DrawerProvider>
  );
}
```

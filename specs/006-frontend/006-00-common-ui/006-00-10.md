## 親Story

[006-00: 共通UIコンポーネント](./006-00.md)

## ユーザーストーリー

**ペルソナ**: SCPファン（エンドユーザー）
**目的**: SCP記事のオブジェクトクラスを視覚的に識別する
**価値**: 一目で記事の危険度や特性を把握できる
**理由**: オブジェクトクラスはSCP財団の重要な分類システムだから

> SCPファンとして、SCP記事のオブジェクトクラスを視覚的に識別して、一目で記事の危険度や特性を把握したい。なぜならオブジェクトクラスはSCP財団の重要な分類システムだから。

## Acceptance Criteria

### AC-1: バリエーション

- [x] WHEN オブジェクトクラスを表示する際
      GIVEN Safe の場合
      THEN 緑色（#10B981）のバッジが表示される

- [x] WHEN オブジェクトクラスを表示する際
      GIVEN Euclid の場合
      THEN 黄色（#F59E0B）のバッジが表示される

- [x] WHEN オブジェクトクラスを表示する際
      GIVEN Keter の場合
      THEN 赤色（#EF4444）のバッジが表示される

- [x] WHEN オブジェクトクラスを表示する際
      GIVEN Thaumiel または Neutralized の場合
      THEN 適切な色のバッジが表示される

- [x] WHEN オブジェクトクラスを表示する際
      GIVEN 未定義のクラスの場合
      THEN グレー色（#9CA3AF）のバッジが表示される

### AC-2: スタイル

- [x] WHEN バッジを表示した際
      THEN コンパクトなピル型で表示される
      AND 文字が読みやすいコントラストを持つ

### AC-3: 型安全

- [x] WHEN バッジコンポーネントを使用する際
      THEN variant prop で型安全にオブジェクトクラスを指定できる
      AND 未定義のクラス（string型）も受け入れられる

### 型定義

```typescript
type ObjectClass = "Safe" | "Euclid" | "Keter" | "Thaumiel" | "Neutralized";

interface BadgeProps {
  variant: ObjectClass;
  children?: React.ReactNode;
}
```

### カラー定義（DESIGN_GUIDELINES.md より）

| クラス      | 背景色           | 文字色 |
| ----------- | ---------------- | ------ |
| Safe        | #10B981 (green)  | white  |
| Euclid      | #F59E0B (yellow) | white  |
| Keter       | #EF4444 (red)    | white  |
| Thaumiel    | #8B5CF6 (purple) | white  |
| Neutralized | #6B7280 (gray)   | white  |

### スタイル仕様

```css
.badge {
  padding: 2px 8px;
  border-radius: 4px;
  font-size: 12px;
  font-weight: 500;
}
```

### 実装例

```typescript
// Badge.tsx
import { cn } from '@/shared/lib/utils';

const variantStyles: Record<ObjectClass, string> = {
  Safe: 'bg-safe text-white',
  Euclid: 'bg-euclid text-white',
  Keter: 'bg-keter text-white',
  Thaumiel: 'bg-purple-500 text-white',
  Neutralized: 'bg-gray-500 text-white',
};

export const Badge = ({ variant, children }: BadgeProps) => {
  return (
    <span className={cn(
      'px-2 py-0.5 rounded text-xs font-medium',
      variantStyles[variant]
    )}>
      {children ?? variant}
    </span>
  );
};
```

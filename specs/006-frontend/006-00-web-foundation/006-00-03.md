# Subtask 006-00-03: APIクライアント設定

## 概要

Hono RPCクライアントを設定し、バックエンドAPI（EPIC-005）との型安全な通信基盤を構築する。
環境変数設定とapi-typesパッケージの連携を行う。

## ステータス

- **status**: planned

## 親Story

[006-00: フロントエンド環境構築](./006-00.md)

## ユーザーストーリー

**ペルソナ**: フロントエンド開発者
**目的**: 型安全なAPIクライアントを設定する
**価値**: APIとの通信でコンパイル時に型エラーを検出できる
**理由**: 実行時エラーを減らし、開発効率を向上させたい

> フロントエンド開発者として、型安全なAPIクライアントを設定して、APIとの通信でコンパイル時に型エラーを検出したい。なぜなら実行時エラーを減らし、開発効率を向上させたいから。

### api-client.ts

```typescript
// apps/web/src/shared/lib/api-client.ts
import { hc } from "hono/client";
import type { AppType } from "@recommend-scp/api-types";

/**
 * APIベースURL
 * 環境変数から取得、未設定時はエラー
 */
const getBaseUrl = (): string => {
  const url = process.env.NEXT_PUBLIC_API_URL;
  if (!url) {
    throw new Error("NEXT_PUBLIC_API_URL is not defined");
  }
  return url;
};

/**
 * Hono RPCクライアント
 * 型安全なAPI呼び出しを提供
 */
export const api = hc<AppType>(getBaseUrl());

/**
 * APIクライアントの型エクスポート
 */
export type ApiClient = typeof api;
```

### エラーハンドリングユーティリティ

```typescript
// apps/web/src/shared/lib/api-error.ts

/**
 * RFC 7807 Problem Details形式
 */
export interface ProblemDetails {
  type: string;
  title: string;
  status: number;
  detail?: string;
  instance?: string;
}

/**
 * APIレスポンスをProblemDetailsとしてパース
 */
export async function parseApiError(response: Response): Promise<ProblemDetails> {
  try {
    const json = await response.json();
    return {
      type: json.type || "https://recommend-scp.dev/errors/unknown",
      title: json.title || "Unknown Error",
      status: response.status,
      detail: json.detail,
      instance: json.instance,
    };
  } catch {
    return {
      type: "https://recommend-scp.dev/errors/parse-error",
      title: "Response Parse Error",
      status: response.status,
      detail: "Failed to parse error response",
    };
  }
}

/**
 * APIエラーかどうかを判定
 */
export function isApiError(error: unknown): error is ProblemDetails {
  return (
    typeof error === "object" &&
    error !== null &&
    "type" in error &&
    "title" in error &&
    "status" in error
  );
}

/**
 * ユーザー向けエラーメッセージを取得
 */
export function getErrorMessage(error: ProblemDetails): string {
  // 既知のエラータイプに対するメッセージマッピング
  const messages: Record<string, string> = {
    "https://recommend-scp.dev/errors/not-found": "リソースが見つかりませんでした",
    "https://recommend-scp.dev/errors/validation-error": "入力内容に問題があります",
    "https://recommend-scp.dev/errors/internal-error": "サーバーエラーが発生しました",
  };

  return messages[error.type] || error.detail || error.title;
}
```

### 使用例

```typescript
// コンポーネントでの使用例
import { api } from "@/shared/lib/api-client";
import { parseApiError, getErrorMessage } from "@/shared/lib/api-error";

async function fetchPacks() {
  const res = await api.onboarding.packs.$get();

  if (!res.ok) {
    const error = await parseApiError(res);
    throw new Error(getErrorMessage(error));
  }

  return res.json();
}

// Hono RPCの型推論により、以下が型安全に:
// - リクエストボディの型
// - レスポンスの型
// - URLパラメータの型
```

# Subtask 006-00-01: Next.jsプロジェクト初期化

## 概要

apps/webディレクトリにNext.js 15 App Routerプロジェクトを作成し、
モノレポ（Turborepo）に統合する。

## ステータス

- **status**: completed

## 親Story

[006-00: フロントエンド環境構築](./006-00.md)

## ユーザーストーリー

**ペルソナ**: フロントエンド開発者
**目的**: Next.js App Routerプロジェクトを初期化する
**価値**: モダンなReactアプリケーション開発が可能になる
**理由**: EPIC-006のUI実装基盤が必要

> フロントエンド開発者として、Next.js App Routerプロジェクトを初期化して、モダンなReactアプリケーション開発ができるようにしたい。なぜならEPIC-006のUI実装基盤が必要だから。

## Acceptance Criteria（EARS記法）

### AC-1: プロジェクト作成

- [x] WHEN `apps/web` ディレクトリを確認した際
      THEN Next.js 15プロジェクトが存在する
      AND App Router構成になっている

### AC-2: 開発サーバー起動

- [x] WHEN `pnpm dev --filter web` を実行した際
      THEN 開発サーバーがポート3000で起動する
      AND http://localhost:3000 にアクセスできる

### AC-3: TypeScript設定

- [x] WHEN tsconfig.jsonを確認した際
      THEN strictモードが有効になっている
      AND パスエイリアス `@/*` が `./src/*` にマッピングされている

### AC-4: ディレクトリ構成

- [x] WHEN src/ディレクトリを確認した際
      THEN `app/`, `shared/` ディレクトリが存在する
      AND vidmarkアーキテクチャに準拠している

### AC-5: package.json設定

- [x] WHEN package.jsonを確認した際
      THEN name が `web` になっている
      AND 必要なscriptsが定義されている

### AC-6: Turborepo統合

- [x] WHEN `pnpm build` を実行した際
      THEN apps/webのビルドがパイプラインに含まれる

### AC-7: ESLint設定

- [x] WHEN `pnpm lint --filter web` を実行した際
      THEN ESLintが実行される
      AND プロジェクトのルールに準拠している

## 技術設計

### 初期化コマンド

```bash
cd apps
pnpm create next-app@latest web --typescript --tailwind --eslint --app --src-dir --import-alias "@/*" --use-pnpm
```

### package.json

```json
{
  "name": "web",
  "version": "0.0.1",
  "private": true,
  "scripts": {
    "dev": "next dev -p 3000",
    "build": "next build",
    "start": "next start",
    "lint": "next lint",
    "typecheck": "tsc --noEmit"
  },
  "dependencies": {
    "next": "^15.0.0",
    "react": "^19.0.0",

}
```

### tsconfig.json

```json
{
  "compilerOptions": {
    "target": "ES2017",
```

### next.config.ts

```typescript
import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  // Turbopack有効化（開発時）
  experimental: {
    // 必要に応じて設定
  },
  // トランスパイル対象パッケージ
  transpilePackages: ["@recommend-scp/api-types", "@recommend-scp/shared"],
};

export default nextConfig;
```

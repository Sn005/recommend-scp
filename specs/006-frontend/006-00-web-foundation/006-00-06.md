# Subtask 006-00-06: グローバルレイアウト

## 概要

全画面で共通使用するグローバルUIコンポーネント（ドロワーメニュー、メニューボタン）を実装し、
RootLayoutに統合する。

## ステータス

- **status**: planned

## 親Story

[006-00: フロントエンド環境構築](./006-00.md)

## ユーザーストーリー

**ペルソナ**: エンドユーザー
**目的**: どの画面からでも統一されたナビゲーションにアクセスする
**価値**: 画面間の移動が直感的で、アプリ全体で一貫した操作感を得られる
**理由**: 戻るボタンを廃止し、ドロワーメニューでナビゲーションを一元化したい

> エンドユーザーとして、どの画面からでもドロワーメニューにアクセスして、統一されたナビゲーションを利用したい。なぜなら画面間の移動を直感的にしたいから。

## Acceptance Criteria（EARS記法）

### AC-1: メニューボタン表示

- [ ] WHEN 任意の画面を表示した際
      THEN 左上にメニューボタン（☰）が表示される
      AND Glassmorphism効果が適用されている
      AND z-indexは `--z-menu-btn: 50` である

### AC-2: ドロワーメニュー開閉

- [ ] WHEN メニューボタンをタップした際
      THEN ドロワーメニューが左からスライドインする
      AND 背景にオーバーレイが表示される
      AND アニメーション時間は 0.3s である

- [ ] WHEN オーバーレイをタップした際
      THEN ドロワーメニューが閉じる

### AC-3: ドロワーメニュー内容

- [ ] WHEN ドロワーメニューを開いた際
      THEN 以下のメニュー項目が表示される: - 推薦を見る（アイコン: 本）- お気に入り一覧（アイコン: ハート）- 閲覧履歴（アイコン: 時計）- 設定（アイコン: 歯車）- 推薦をリセット（アイコン: リセット）

### AC-4: アクティブ状態

- [ ] WHEN 現在の画面に対応するメニュー項目がある場合
      THEN その項目がアクティブ状態で表示される（背景: `#EFF6FF`、文字: primary）

### AC-5: z-index管理

- [ ] WHEN ドロワーメニューを開いた際
      THEN ドロワーのz-indexは `--z-drawer: 101`
      AND オーバーレイのz-indexは `--z-drawer-overlay: 100`

### AC-6: RootLayout統合

- [ ] WHEN アプリを起動した際
      THEN RootLayoutにMenuButtonとDrawerが含まれている
      AND 全ページでこれらのコンポーネントが利用可能である

### Drawer.tsx

```tsx
"use client";

import { usePathname } from "next/navigation";
import Link from "next/link";

interface DrawerProps {
  isOpen: boolean;
  onClose: () => void;
}

const menuItems = [
  { href: "/", label: "推薦を見る", icon: "book" },
  { href: "/favorites", label: "お気に入り一覧", icon: "heart" },
  { href: "/history", label: "閲覧履歴", icon: "clock" },
  { href: "/settings", label: "設定", icon: "settings" },
  { href: "/reset", label: "推薦をリセット", icon: "refresh" },
];

export function Drawer({ isOpen, onClose }: DrawerProps) {
  const pathname = usePathname();

  return (
    <>
      {/* オーバーレイ */}
      <div
        className={`fixed inset-0 bg-black/30 z-drawer-overlay transition-opacity duration-300 ${
          isOpen ? "opacity-100 visible" : "opacity-0 invisible"
        }`}
        onClick={onClose}
      />

      {/* ドロワー本体 */}
      <div
        className={`fixed top-0 left-0 bottom-0 w-[280px] bg-white z-drawer shadow-2xl transition-transform duration-300 ${
          isOpen ? "translate-x-0" : "-translate-x-full"
        }`}
      >
        {/* ヘッダー */}
        <div className="pt-16 pb-4 px-5 border-b border-gray-100">
          <h2 className="text-lg font-bold text-gray-800">SCP Recommend</h2>
          <p className="text-sm text-gray-500 mt-1">あなた専用のSCP推薦</p>
        </div>

        {/* メニュー項目 */}
        <nav className="py-2">
          {menuItems.map((item) => (
            <Link
              key={item.href}
              href={item.href}
              onClick={onClose}
              className={`flex items-center gap-3 px-5 py-4 text-[15px] transition-colors ${
                pathname === item.href
                  ? "bg-blue-50 text-primary"
                  : "text-gray-700 hover:bg-gray-100"
              }`}
            >
              <DrawerIcon name={item.icon} active={pathname === item.href} />
              {item.label}
            </Link>
          ))}
        </nav>
      </div>
    </>
  );
}

function DrawerIcon({ name, active }: { name: string; active: boolean }) {
  const className = `w-[22px] h-[22px] ${active ? "text-primary" : "text-gray-500"}`;
  // アイコン実装は省略（SVGまたはlucide-react使用）
  return <span className={className}>{/* Icon */}</span>;
}
```

### useDrawer.ts（hooks）

```tsx
"use client";

import { useState, useCallback } from "react";

export function useDrawer() {
  const [isOpen, setIsOpen] = useState(false);

  const open = useCallback(() => setIsOpen(true), []);
  const close = useCallback(() => setIsOpen(false), []);
  const toggle = useCallback(() => setIsOpen((prev) => !prev), []);

  return { isOpen, open, close, toggle };
}
```

### RootLayout統合

```tsx
// src/app/layout.tsx
import { MenuButton, Drawer } from "@/components/global";
import { useDrawer } from "@/hooks/useDrawer";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="ja">
      <body>
        <GlobalNavigation />
        {children}
      </body>
    </html>
  );
}

// Client Component として分離
("use client");
function GlobalNavigation() {
  const { isOpen, open, close } = useDrawer();

  return (
    <>
      <MenuButton onClick={open} />
      <Drawer isOpen={isOpen} onClose={close} />
    </>
  );
}
```

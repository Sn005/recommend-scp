# Subtask 006-00-04: テスト環境構築

## 概要

Vitest + Testing Libraryによるユニットテスト・コンポーネントテスト環境を構築する。
jsdom環境でのReactコンポーネントテストを可能にする。

## ステータス

- **status**: planned

## 親Story

[006-00: フロントエンド環境構築](./006-00.md)

## ユーザーストーリー

**ペルソナ**: フロントエンド開発者
**目的**: コンポーネントとフックのユニットテストを実行できる
**価値**: TDDで品質の高いUIを開発できる
**理由**: リファクタリング時の回帰を防ぎたい

> フロントエンド開発者として、コンポーネントとフックのユニットテストを実行できるようにしたい。なぜならTDDで品質の高いUIを開発し、リファクタリング時の回帰を防ぎたいから。

## Acceptance Criteria（EARS記法）

### AC-1: Vitest実行

- [ ] WHEN `pnpm test --filter web` を実行した際
      THEN Vitestが起動しテストが実行される

### AC-2: Watchモード

- [ ] WHEN `pnpm test:watch --filter web` を実行した際
      THEN Vitestがwatchモードで起動する
      AND ファイル変更時に自動再実行される

### AC-3: Reactコンポーネントテスト

- [ ] WHEN Testing Libraryを使用したテストを書いた際
      THEN Reactコンポーネントがレンダリングされる
      AND DOMクエリでアサーションできる

### AC-4: カスタムフックテスト

- [ ] WHEN `renderHook` を使用したテストを書いた際
      THEN カスタムフックが正しくテストできる

### AC-5: jsdom環境

- [ ] WHEN テスト内でDOM APIを使用した際
      THEN jsdom環境で正しく動作する

### AC-6: パスエイリアス

- [ ] WHEN テストファイルで `@/` パスエイリアスを使用した際
      THEN 正しくモジュールが解決される

### AC-7: グローバル設定

- [ ] WHEN テストファイルを書いた際
      THEN `describe`, `it`, `expect` がimportなしで使用できる

  cleanup();

### テスト例：コンポーネント

```tsx
// src/shared/components/ui/Button/Button.test.tsx
import { render, screen } from "@testing-library/react";
import userEvent from "@testing-library/user-event";
import { Button } from "./index";

describe("Button", () => {
  it("テキストが表示される", () => {
    render(<Button>クリック</Button>);
    expect(screen.getByRole("button", { name: "クリック" })).toBeInTheDocument();
  });

  it("クリックでonClickが呼ばれる", async () => {
    const user = userEvent.setup();
    const onClick = vi.fn();

    render(<Button onClick={onClick}>クリック</Button>);
    await user.click(screen.getByRole("button"));

    expect(onClick).toHaveBeenCalledTimes(1);
  });

  it("disabled時はクリックできない", async () => {
    const user = userEvent.setup();
    const onClick = vi.fn();

    render(
      <Button onClick={onClick} disabled>
        クリック
      </Button>
    );
    await user.click(screen.getByRole("button"));

    expect(onClick).not.toHaveBeenCalled();
  });
});
```

### テスト例：カスタムフック

```tsx
// src/shared/hooks/__tests__/useVisitorId.test.ts
import { renderHook, waitFor } from "@testing-library/react";
import { useVisitorId } from "../useVisitorId";

describe("useVisitorId", () => {
  beforeEach(() => {
    vi.clearAllMocks();
    localStorage.clear();
  });

  it("localStorageにvisitorIdがない場合、新規生成される", async () => {
    vi.mocked(localStorage.getItem).mockReturnValue(null);

    const { result } = renderHook(() => useVisitorId());

    await waitFor(() => {
      expect(result.current.isLoading).toBe(false);
    });

    expect(result.current.visitorId).toBe("test-uuid-1234-5678-9abc-def012345678");
    expect(localStorage.setItem).toHaveBeenCalled();
  });

  it("localStorageにvisitorIdがある場合、それを返す", async () => {
    vi.mocked(localStorage.getItem).mockReturnValue("existing-visitor-id");

    const { result } = renderHook(() => useVisitorId());

    await waitFor(() => {
      expect(result.current.isLoading).toBe(false);
    });

    expect(result.current.visitorId).toBe("existing-visitor-id");
  });
});
```

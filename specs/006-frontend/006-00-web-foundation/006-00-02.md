# Subtask 006-00-02: Tailwind CSS設定

## 概要

Tailwind CSS 4をNext.jsプロジェクトに設定し、
プロジェクト固有のデザイントークン（カラー、フォント等）を定義する。

## ステータス

- **status**: completed

## 親Story

[006-00: フロントエンド環境構築](./006-00.md)

## ユーザーストーリー

**ペルソナ**: フロントエンド開発者
**目的**: Tailwind CSSでスタイリング基盤を構築する
**価値**: 一貫性のあるデザインを効率的に実装できる
**理由**: ユーティリティファーストで高速なUI開発がしたい

> フロントエンド開発者として、Tailwind CSSでスタイリング基盤を構築して、一貫性のあるデザインを効率的に実装したい。なぜならユーティリティファーストで高速なUI開発がしたいから。

## Acceptance Criteria（EARS記法）

### AC-1: Tailwindクラス適用

- [x] WHEN コンポーネントにTailwindクラスを適用した際
      THEN スタイルが正しく反映される

### AC-2: カスタムカラー

- [x] WHEN プロジェクト固有のカラー（例: `bg-scp-primary`）を使用した際
      THEN 定義されたカラーが適用される

### AC-3: レスポンシブデザイン

- [x] WHEN レスポンシブプレフィックス（`md:`, `lg:`）を使用した際
      THEN 画面サイズに応じたスタイルが適用される

### AC-4: ダークモード対応

- [x] WHEN `dark:` プレフィックスを使用した際
      THEN ダークモード用スタイルが適用される

### AC-5: グローバルCSS

- [x] WHEN globals.cssを確認した際
      THEN Tailwindディレクティブが正しく設定されている
      AND 基本的なリセットスタイルが適用されている

### AC-6: PostCSS設定

- [x] WHEN ビルドを実行した際
      THEN PostCSSがTailwindを正しく処理する

## 技術設計

### tailwind.config.ts

```typescript
import type { Config } from "tailwindcss";

const config: Config = {
  content: ["./src/app/**/*.{js,ts,jsx,tsx,mdx}", "./src/shared/**/*.{js,ts,jsx,tsx,mdx}"],
  darkMode: "class",
  theme: {
    extend: {
      colors: {
        // SCP財団テーマカラー
        scp: {
          primary: "#1a1a2e", // ダークネイビー
          secondary: "#16213e", // ディープブルー
          accent: "#e94560", // 警告レッド
          safe: "#4ecca3", // 安全グリーン
          euclid: "#f9ed69", // ユークリッドイエロー
          keter: "#f08a5d", // ケターオレンジ
        },
      },
      fontFamily: {
        sans: ["Inter", "Hiragino Sans", "Hiragino Kaku Gothic ProN", "Noto Sans JP", "sans-serif"],
        mono: ["JetBrains Mono", "Fira Code", "monospace"],
      },
      animation: {
        "fade-in": "fadeIn 0.3s ease-in-out",
        "slide-up": "slideUp 0.3s ease-out",
      },
      keyframes: {
        fadeIn: {
          "0%": { opacity: "0" },
          "100%": { opacity: "1" },
        },
        slideUp: {
          "0%": { transform: "translateY(10px)", opacity: "0" },
          "100%": { transform: "translateY(0)", opacity: "1" },
        },
      },
    },
  },
  plugins: [],
};

export default config;
```

### globals.css

```css
@tailwind base;
@tailwind components;
@tailwind utilities;

@layer base {
  /* フォントスムージング */
  html {
    -webkit-font-smoothing: antialiased;
    -moz-osx-font-smoothing: grayscale;
  }

  /* デフォルトの背景・テキスト色 */
  body {
    @apply bg-white text-gray-900;
    @apply dark:bg-gray-900 dark:text-gray-100;
  }

  /* フォーカスリングのカスタマイズ */
  *:focus-visible {
    @apply outline-none ring-2 ring-scp-accent ring-offset-2;
  }
}

@layer components {
  /* カード共通スタイル */
  .card {
    @apply rounded-lg border border-gray-200 bg-white p-4 shadow-sm;
    @apply dark:border-gray-700 dark:bg-gray-800;
  }

  /* ボタン共通スタイル */
  .btn {
    @apply inline-flex items-center justify-center rounded-lg px-4 py-2 font-medium;
    @apply transition-colors duration-200;
    @apply focus:outline-none focus:ring-2 focus:ring-offset-2;
    @apply disabled:cursor-not-allowed disabled:opacity-50;
  }

  .btn-primary {
    @apply btn bg-scp-accent text-white hover:bg-red-600;
    @apply focus:ring-scp-accent;
  }

  .btn-secondary {
    @apply btn border border-gray-300 bg-white text-gray-700 hover:bg-gray-50;
    @apply dark:border-gray-600 dark:bg-gray-800 dark:text-gray-200 dark:hover:bg-gray-700;
  }
}

@layer utilities {
  /* スクロールバー非表示（Webkit） */
  .scrollbar-hide::-webkit-scrollbar {
    display: none;
  }

  .scrollbar-hide {
    -ms-overflow-style: none;
    scrollbar-width: none;
  }

  /* セーフエリア対応 */
  .safe-area-inset-bottom {
    padding-bottom: env(safe-area-inset-bottom);
  }
}
```

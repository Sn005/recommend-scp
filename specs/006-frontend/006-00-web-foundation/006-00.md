# Story: フロントエンド環境構築

## 親EPIC

[006: フロントエンドUI](../006-frontend.md)

## ユーザーストーリー

**ペルソナ**: フロントエンド開発者
**目的**: Next.js App Routerベースの開発環境を構築する
**価値**: 型安全でモダンなフロントエンド開発が可能になる
**理由**: EPIC-006の各Storyを実装するための基盤が必要

> フロントエンド開発者として、Next.js App Routerベースの開発環境を構築して、型安全でモダンなフロントエンド開発ができるようにしたい。なぜならEPIC-006の各Storyを実装するための基盤が必要だから。

## 背景

### 技術選定

| 項目            | 選定                    | 理由                               |
| --------------- | ----------------------- | ---------------------------------- |
| フレームワーク  | Next.js 15 (App Router) | Server Components、静的最適化      |
| スタイリング    | Tailwind CSS 4          | ユーティリティファースト、高速開発 |
| 型定義          | TypeScript 5.x          | 型安全性                           |
| APIクライアント | Hono RPC                | バックエンドとの型共有             |
| ビルド          | Turborepo               | モノレポ統合、キャッシュ活用       |

### 参照アーキテクチャ

[vidmark architecture.md](https://github.com/Sn005/vidmark/blob/main/docs/architecture.md) に準拠:

- Route Separation + Hybrid approach
- Page-exclusive components (`_components/`, `_hooks/`)
- Global shared components (`shared/`)

## Acceptance Criteria

### AC-1: Next.jsプロジェクト初期化

- [x] WHEN `pnpm dev --filter web` を実行した際
      THEN Next.js開発サーバーが起動する
      AND http://localhost:3000 でアプリケーションにアクセスできる

### AC-2: Tailwind CSS動作

- [x] WHEN Tailwindクラスをコンポーネントに適用した際
      THEN スタイルが正しく反映される

### AC-3: TypeScript設定

- [x] WHEN `pnpm typecheck --filter web` を実行した際
      THEN 型チェックが実行される
      AND パスエイリアス（@/）が正しく解決される

### AC-4: api-types連携

- [x] WHEN `@recommend-scp/api-types` をインポートした際
      THEN AppType型が利用可能になる
      AND コンパイルエラーが発生しない

### AC-5: Hono RPCクライアント

- [x] WHEN api-client.tsでHono RPCクライアントを初期化した際
      THEN 型安全なAPI呼び出しが可能になる

### AC-6: Turborepo統合

- [x] WHEN `pnpm build` を実行した際
      THEN apps/webのビルドがTurborepoパイプラインに含まれる

### AC-7: 環境変数設定

- [x] WHEN 環境変数 `NEXT_PUBLIC_API_URL` を設定した際
      THEN APIクライアントから参照できる

### AC-8: ディレクトリ構成

- [x] WHEN apps/web/src を確認した際
      THEN vidmarkアーキテクチャに準拠した構成になっている

### AC-9: テスト環境

- [x] WHEN `pnpm test --filter web` を実行した際
      THEN Vitestが実行される
      AND Reactコンポーネントのテストが可能である

### AC-10: UIコンポーネント基盤

- [x] WHEN shadcn/uiコンポーネントを使用した際
      THEN アクセシブルなUIが提供される
      AND cn関数でTailwindクラスをマージできる

## 技術設計

### ディレクトリ構成

```
apps/web/
├── src/
│   ├── app/
│   │   ├── layout.tsx          # ルートレイアウト
│   │   ├── page.tsx            # トップページ（リダイレクト）
│   │   └── globals.css         # Tailwind directives
│   └── shared/
│       ├── components/
│       │   └── ui/             # 共通UIコンポーネント
│       ├── hooks/
│       │   └── index.ts
│       ├── lib/
│       │   └── api-client.ts   # Hono RPCクライアント
│       └── types/
│           └── index.ts
├── public/
├── next.config.ts
├── tailwind.config.ts
├── postcss.config.mjs
├── tsconfig.json
└── package.json
```

### 環境変数

```bash
# apps/web/.env.local（開発用）
NEXT_PUBLIC_API_URL=http://localhost:3001

# 本番環境（Vercel）
NEXT_PUBLIC_API_URL=https://api.recommend-scp.dev
```

```json
    "lint": "next lint",

  }
}
```

## ユーザーストーリー

**ペルソナ**: 開発者
**目的**: 再利用可能なSVGアイコンコンポーネントを使用する
**価値**: デザイン一貫性を保ちながら効率的に開発できる
**理由**: アイコンの一元管理でメンテナンス性を向上させたいから

> 開発者として、再利用可能なSVGアイコンコンポーネントを使用して、デザイン一貫性を保ちながら効率的に開発したい。なぜならアイコンの一元管理でメンテナンス性を向上させたいから。

## Acceptance Criteria

### AC-1: Iconコンポーネント基本機能

- [ ] WHEN 開発者がIconコンポーネントをインポートした際
      THEN `<Icon name="menu" />` のように名前指定でアイコンを表示できる
      AND TypeScriptで利用可能なアイコン名が補完される

### AC-2: サイズカスタマイズ

- [ ] WHEN 開発者がsizeプロパティを指定した際
      THEN アイコンのサイズが変更される
      AND デフォルトサイズは24pxである

### AC-3: カラーカスタマイズ

- [ ] WHEN 開発者がclassNameを指定した際
      THEN Tailwindのtext-\*クラスでアイコン色を変更できる
      AND デフォルトはcurrentColorを継承する

### AC-4: 必須アイコン

- [ ] THEN 以下のアイコンが利用可能である: - `menu`: ハンバーガーメニュー（3本線）- `heart`: ハートアウトライン - `heart-filled`: ハート塗りつぶし - `chevron-right`: 右矢印 - `clock`: 時計 - `bookmark`: お気に入り一覧用

### AC-5: アクセシビリティ

- [ ] WHEN アイコンが装飾目的の場合
      THEN `aria-hidden="true"` が設定される
      AND スクリーンリーダーで読み上げられない

## テストケース

```typescript
describe("Iconコンポーネント", () => {
  it("name指定でアイコンを表示できる", () => {
    render(<Icon name="menu" />);
    expect(screen.getByRole("img", { hidden: true })).toBeInTheDocument();
  });

  it("sizeプロパティでサイズを変更できる", () => {
    render(<Icon name="menu" size={32} />);
    const svg = screen.getByRole("img", { hidden: true });
    expect(svg).toHaveAttribute("width", "32");
    expect(svg).toHaveAttribute("height", "32");
  });

  it("classNameでスタイルを適用できる", () => {
    render(<Icon name="menu" className="text-red-500" />);
    const svg = screen.getByRole("img", { hidden: true });
    expect(svg).toHaveClass("text-red-500");
  });

  it("デフォルトでaria-hidden=trueが設定される", () => {
    render(<Icon name="menu" />);
    const svg = screen.getByRole("img", { hidden: true });
    expect(svg).toHaveAttribute("aria-hidden", "true");
  });

  it("全必須アイコンが定義されている", () => {
    const requiredIcons = ["menu", "heart", "heart-filled", "chevron-right", "clock", "bookmark"];
    requiredIcons.forEach(name => {
      expect(() => render(<Icon name={name as IconName} />)).not.toThrow();
    });
  });
});
```

## 現状の乖離

| #   | 項目                 | モック仕様 (`onboarding-v2.html`)        | 現在の実装                         |
| --- | -------------------- | ---------------------------------------- | ---------------------------------- |
| 1   | **フロー**           | タブUIで1画面内切り替え                  | 選択画面→各画面へ遷移（2画面構成） |

## Acceptance Criteria

### AC-1: タブUI実装

- [ ] WHEN ユーザーがオンボーディング画面を開いた際
      THEN 「スターターパック」「SCP番号を入力」の2つのタブが表示される
      AND タブ切り替えで1画面内でコンテンツが切り替わる
      AND 選択画面（OnboardingSelect）は廃止される

### AC-2: 複数パック選択対応

- [ ] WHEN ユーザーがパックカードをタップした際
      THEN パックの選択状態がトグルされる
      AND 複数のパックを同時に選択できる
      AND 選択されたパック数が0の場合「推薦を開始」ボタンは非活性

### AC-3: パックカードのデザイン準拠

- [ ] WHEN ユーザーがパックカードを見た際
      THEN モック（`onboarding-v2.html`）と同一のデザインである
      AND 選択時にチェックマークが右上に表示される（既存実装OK）
      AND border-colorがprimary色になる（既存実装OK）

### AC-4: パックカードのアイコン

- [ ] WHEN ユーザーがパックカードを見た際
      THEN アイコンは絵文字のままでOK（モック準拠）
      AND モックと同じアイコン（🏛️👻🚀💝🔍🇯🇵）を使用する

### AC-5: SCP番号入力タブ

- [ ] WHEN ユーザーが「SCP番号を入力」タブを選択した際
      THEN 番号入力フォームが表示される
      AND 入力フィールドのスタイルがモックと一致する
      AND プレースホルダーが「例: 173」「例: 5000」等になる

### AC-6: フローティング開始ボタン

- [ ] WHEN ユーザーがオンボーディング画面を見た際
      THEN 画面下部に固定の「推薦を開始」ボタンが表示される
      AND ボタンはGlassmorphism効果を持つ
      AND パック選択またはSCP番号入力がない場合は非活性

### タブUIコンポーネント

```tsx
// app/onboarding/page.tsx
"use client";
import { useState } from "react";

type TabType = "pack" | "manual";

export default function OnboardingPage() {
  const [activeTab, setActiveTab] = useState<TabType>("pack");

  return (
    <div className="flex min-h-screen flex-col bg-gray-50">
      {/* ヘッダー */}
      <header className="border-b border-gray-100 bg-white">
        <div className="px-6 pb-6 pt-12">
          <h1 className="text-2xl font-bold text-gray-800">SCP Recommend</h1>
          <p className="mt-2 text-gray-500">あなたの好みに合わせたSCP記事を推薦します</p>
        </div>
        {/* タブ */}
        <div className="flex border-b border-gray-100">
          <TabButton active={activeTab === "pack"} onClick={() => setActiveTab("pack")}>
            スターターパック
          </TabButton>
          <TabButton active={activeTab === "manual"} onClick={() => setActiveTab("manual")}>
            SCP番号を入力
          </TabButton>
        </div>
      </header>

      {/* コンテンツ */}
      <main className="flex-1 px-4 py-6 pb-28">
        {activeTab === "pack" ? <PackSelector /> : <ScpNumberInput />}
      </main>

      {/* 開始ボタン */}
      <FloatingStartButton disabled={!canStart} onClick={handleStart} />
    </div>
  );
}
```

### 複数選択対応

```tsx
// Before: 単一選択
const [selectedPack, setSelectedPack] = useState<Pack | null>(null);

// After: 複数選択
const [selectedPacks, setSelectedPacks] = useState<Set<string>>(new Set());

const togglePack = (packId: string) => {
  setSelectedPacks((prev) => {
    const next = new Set(prev);
    if (next.has(packId)) {
      next.delete(packId);
    } else {
      next.add(packId);
    }
    return next;
  });
};
```

## テストケース

```typescript
describe("オンボーディング タブUI", () => {
  it("2つのタブが表示される", () => {
    render(<OnboardingPage />);
    expect(screen.getByText("スターターパック")).toBeInTheDocument();
    expect(screen.getByText("SCP番号を入力")).toBeInTheDocument();
  });

  it("タブ切り替えでコンテンツが変わる", async () => {
    render(<OnboardingPage />);
    await userEvent.click(screen.getByText("SCP番号を入力"));
    expect(screen.getByPlaceholderText("例: 173")).toBeInTheDocument();
  });
});

describe("パック複数選択", () => {
  it("複数のパックを選択できる", async () => {
    render(<PackSelector />);
    await userEvent.click(screen.getByText("ホラー・恐怖"));
    await userEvent.click(screen.getByText("ミステリー・考察"));
    expect(screen.getAllByTestId("pack-check")).toHaveLength(2);
  });

  it("選択したパックを解除できる", async () => {
    render(<PackSelector />);
    await userEvent.click(screen.getByText("ホラー・恐怖"));
    await userEvent.click(screen.getByText("ホラー・恐怖"));
    expect(screen.queryByTestId("pack-check")).not.toBeInTheDocument();
  });
});
```

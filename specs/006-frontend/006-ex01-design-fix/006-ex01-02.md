# Subtask: 既存UIへのSVGアイコン適用

## 親Story

[006-ex01: デザイン整合性修正](./006-ex01.md)

## ユーザーストーリー

**ペルソナ**: ユーザー
**目的**: モックアップと同一のアイコンデザインを見る
**価値**: 洗練された視覚体験を得られる
**理由**: テキスト絵文字よりSVGアイコンの方が美しく一貫性があるから

> ユーザーとして、モックアップと同一のアイコンデザインを見て、洗練された視覚体験を得たい。なぜならテキスト絵文字よりSVGアイコンの方が美しく一貫性があるから。

## 前提条件

- [006-ex01-01](./006-ex01-01.md) が完了していること（Iconコンポーネント利用可能）

## Acceptance Criteria

### AC-1: MenuButtonのSVGアイコン化

- [x] WHEN ユーザーがメニューボタンを見た際
      THEN SVGハンバーガーアイコン（`<Icon name="menu" />`）が表示される
      AND テキスト「☰」は使用されていない
      AND `mockups/header-6-minimal-2btn.html` と同一のビジュアルである

### AC-2: PillNavのSVGアイコン化

- [x] WHEN ユーザーがフローティングナビを見た際
      THEN お気に入りボタンにSVGハートアイコンが表示される
      AND 次へボタンにSVG矢印アイコンが表示される
      AND テキスト「♡」「♥」「→」は使用されていない

### AC-3: PillNavのお気に入り状態表示

- [x] WHEN 記事がお気に入り済みの場合
      THEN ハートアイコンが塗りつぶし（fill）表示される
      AND 色が `#EF4444`（red-500）である
      AND アニメーション（heartPop）が維持される

### AC-4: DrawerMenuのSVGアイコン化

- [x] WHEN ユーザーがドロワーメニューを開いた際
      THEN 「推薦を見る」にブックマークアイコンが表示される
      AND 「お気に入り一覧」にハートアイコンが表示される
      AND 「閲覧履歴」に時計アイコンが表示される
      AND 絵文字（📖, ♡, 🕐）は使用されていない

### AC-5: 既存テストの維持

- [x] WHEN 既存のテストを実行した際
      THEN 全てのテストがパスする
      AND 新しいアイコン表示に対応したテストが追加されている

## 設計

### 変更対象ファイル

| ファイル                                         | 変更内容                            |
| ------------------------------------------------ | ----------------------------------- |
| `shared/components/ui/MenuButton/MenuButton.tsx` | テキスト☰ → `<Icon name="menu" />` |
| `shared/components/ui/PillNav/PillNav.tsx`       | テキスト♡/♥/→ → `<Icon />`          |
| `shared/components/ui/Drawer/DrawerMenu.tsx`     | 絵文字 → `<Icon />`                 |

### MenuButton変更例

```tsx
// Before
<span className="text-xl">☰</span>;

// After
import { Icon } from "../Icon";
<Icon name="menu" size={20} className="text-gray-600" />;
```

### PillNav変更例

```tsx
// Before
<span className="text-[26px]">{isFavorited ? "♥" : "♡"}</span>
<span className="text-[26px]">→</span>

// After
import { Icon } from "../Icon";
<Icon
  name={isFavorited ? "heart-filled" : "heart"}
  size={26}
  className={isFavorited ? "text-favorite fill-favorite" : "text-gray-500"}
/>
<Icon name="chevron-right" size={26} className="text-primary" />
```

### DrawerMenu変更例

```tsx
// Before
const menuItems = [
  { href: "/recommend", icon: "📖", label: "推薦を見る" },
  { href: "/favorites", icon: "♡", label: "お気に入り一覧" },
  { href: "/history", icon: "🕐", label: "閲覧履歴" },
];

// After
import { Icon, IconName } from "../Icon";
const menuItems: { href: string; icon: IconName; label: string }[] = [
  { href: "/recommend", icon: "bookmark", label: "推薦を見る" },
  { href: "/favorites", icon: "heart", label: "お気に入り一覧" },
  { href: "/history", icon: "clock", label: "閲覧履歴" },
];

// 表示部分
<Icon name={item.icon} size={22} className="text-gray-500" />;
```

## テストケース

```typescript
describe("MenuButton SVGアイコン", () => {
  it("SVGハンバーガーアイコンが表示される", () => {
    render(<MenuButton />);
    const svg = screen.getByRole("img", { hidden: true });
    expect(svg).toBeInTheDocument();
  });
});

describe("PillNav SVGアイコン", () => {
  it("お気に入りボタンにSVGハートアイコンが表示される", () => {
    render(<PillNav isFavorited={false} />);
    // heart outlineアイコンの存在確認
  });

  it("お気に入り済みの場合、塗りつぶしハートが表示される", () => {
    render(<PillNav isFavorited={true} />);
    // heart-filledアイコンの存在確認
  });

  it("次へボタンにSVG矢印アイコンが表示される", () => {
    render(<PillNav />);
    // chevron-rightアイコンの存在確認
  });
});

describe("DrawerMenu SVGアイコン", () => {
  it("各メニュー項目にSVGアイコンが表示される", () => {
    render(<DrawerMenu />);
    const svgIcons = screen.getAllByRole("img", { hidden: true });
    expect(svgIcons.length).toBeGreaterThanOrEqual(3);
  });
});
```

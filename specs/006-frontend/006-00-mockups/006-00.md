# Story 006-00: UIモック作成

## 概要

フロントエンド実装前に静的HTMLモックを作成し、UIの方向性をフィードバックサイクルで確定させる。

## 目的

- 実装前にUI/UXを確認・調整
- デザインカンプの代替（Photoshop不要）
- 高速なフィードバックループ

## 成果物

```
mockups/
├── index.html       # 画面一覧
├── onboarding.html  # オンボーディング
├── reader.html      # 推薦画面
└── favorites.html   # お気に入り
```

## 進め方

1. モック作成 → GitHub Pagesデプロイ
2. スマホ/PCで確認
3. フィードバック
4. 修正
5. 繰り返し → フィックス

## 技術

- プレーンHTML + Tailwind CDN
- React/TypeScript不使用（使い捨て前提）
- GitHub Pagesで公開

## 備考

- TDD対象外（デザインカンプのため）
- フィックス後、mockups/は削除可能
- 本実装は006-01〜006-03で行う

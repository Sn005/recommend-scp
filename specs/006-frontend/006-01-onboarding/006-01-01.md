# Subtask 006-01-01: オンボーディング画面実装

## 概要

オンボーディングページ（/onboarding）のメイン画面を実装する。
選択肢表示、ルーティング制御、初回訪問判定を担当。

## ステータス

- **status**: completed

## 親Story

[006-01: オンボーディング](./006-01.md)

## ユーザーストーリー

**ペルソナ**: 新規ユーザー
**目的**: アプリ初回起動時にオンボーディング画面を見る
**価値**: どのように始めればよいかが明確にわかる
**理由**: スムーズにSCP推薦体験を開始したい

> 新規ユーザーとして、アプリ初回起動時にオンボーディング画面を見て、どのように始めればよいかが明確にわかりたい。なぜならスムーズにSCP推薦体験を開始したいから。

## Acceptance Criteria（EARS記法）

### AC-1: オンボーディング画面表示

- [x] WHEN ユーザーが /onboarding にアクセスした際
      THEN オンボーディング画面が表示される
      AND 「スターターパックから選ぶ」ボタンが表示される
      AND 「好きなSCPを教える」ボタンが表示される

### AC-2: 初回訪問リダイレクト

- [x] WHEN ユーザーがトップページ（/）にアクセスした際
      GIVEN visitorIdが未登録またはオンボーディング未完了の場合
      THEN /onboarding にリダイレクトされる

### AC-3: オンボーディング完了済みリダイレクト

- [x] WHEN ユーザーが /onboarding にアクセスした際
      GIVEN オンボーディングが既に完了している場合
      THEN /reader にリダイレクトされる

### AC-4: スターターパック選択遷移

- [x] WHEN ユーザーが「スターターパックから選ぶ」をクリックした際
      THEN パック選択コンポーネント（PackSelector）が表示される

### AC-5: SCP番号入力遷移

- [x] WHEN ユーザーが「好きなSCPを教える」をクリックした際
      THEN SCP番号入力コンポーネント（ScpNumberInput）が表示される

### AC-6: ローディング状態

- [x] WHEN visitorIdの初期化中の際
      THEN ローディングインジケーターが表示される

### AC-7: エラー状態

- [x] WHEN visitorId初期化でエラーが発生した際
      THEN エラーメッセージが表示される
      AND リトライボタンが表示される

### page.tsx 実装方針

```tsx
// app/onboarding/page.tsx
"use client";

import { useEffect } from "react";
import { useRouter } from "next/navigation";
import { useVisitorId } from "@/shared/hooks/useVisitorId";
import { useOnboarding } from "./_hooks/useOnboarding";
import { OnboardingSelect } from "./_components/OnboardingSelect";
import { PackSelector } from "./_components/PackSelector";
import { ScpNumberInput } from "./_components/ScpNumberInput";

export default function OnboardingPage() {
  const router = useRouter();
  const { visitorId, isLoading: isVisitorLoading, isOnboarded, error } = useVisitorId();
  const { step, setStep, completeWithPack, completeWithCustom } = useOnboarding();

  // オンボーディング完了済みならリダイレクト
  useEffect(() => {
    if (!isVisitorLoading && isOnboarded) {
      router.replace("/reader");
    }
  }, [isVisitorLoading, isOnboarded, router]);

  if (isVisitorLoading) {
    return <LoadingIndicator />;
  }

  if (error) {
    return <ErrorMessage error={error} onRetry={() => window.location.reload()} />;
  }

  switch (step) {
    case "select":
      return (
        <OnboardingSelect
          onSelectPack={() => setStep("pack")}
          onSelectCustom={() => setStep("custom")}
        />
      );
    case "pack":
      return (
        <PackSelector
          visitorId={visitorId!}
          onComplete={() => router.push("/reader")}
          onBack={() => setStep("select")}
        />
      );
    case "custom":
      return (
        <ScpNumberInput
          visitorId={visitorId!}
          onComplete={() => router.push("/reader")}
          onBack={() => setStep("select")}
        />
      );
  }
}
```

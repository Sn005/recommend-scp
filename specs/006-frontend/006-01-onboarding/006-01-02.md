# Subtask 006-01-02: パック選択コンポーネント

## 概要

スターターパック一覧を表示し、ユーザーが選択できるPackSelectorコンポーネントを実装する。
API連携、選択処理、ローディング状態を管理。

## ステータス

- **status**: completed

## 親Story

[006-01: オンボーディング](./006-01.md)

## ユーザーストーリー

**ペルソナ**: 新規ユーザー（SCP初心者）
**目的**: 事前定義されたスターターパックから好みのものを選ぶ
**価値**: 自分で探す手間なく、推薦をスタートできる
**理由**: SCPをあまり知らないので、カテゴリから選びたい

> 新規ユーザーとして、事前定義されたスターターパックから好みのものを選んで、自分で探す手間なく推薦をスタートしたい。なぜならSCPをあまり知らないので、カテゴリから選びたいから。

## Acceptance Criteria（EARS記法）

### AC-1: パック一覧表示

- [x] WHEN PackSelectorが表示された際
      THEN GET /onboarding/packs APIが呼び出される
      AND 5種類のスターターパックが表示される
      AND 各パックに名前・説明・アイコンが表示される

### AC-2: パック選択

- [x] WHEN ユーザーがパックをクリックした際
      THEN 選択されたパックがハイライト表示される
      AND 「始める」ボタンが有効になる

### AC-3: パック確定

- [x] WHEN ユーザーが「始める」ボタンをクリックした際
      GIVEN パックが選択されている場合
      THEN POST /onboarding/select APIが呼び出される
      AND ローディング状態が表示される
      AND 成功時は記事閲覧画面に遷移する

### AC-4: ローディング状態（一覧取得）

- [x] WHEN パック一覧を取得中の際
      THEN スケルトンローダーが表示される

### AC-5: ローディング状態（選択確定）

- [x] WHEN パック選択を確定中の際
      THEN 「始める」ボタンがローディング状態になる
      AND 他のUIは操作不可になる

### AC-6: エラーハンドリング（一覧取得）

- [x] WHEN GET /onboarding/packs APIがエラーを返した際
      THEN エラーメッセージが表示される
      AND リトライボタンが表示される

### AC-7: エラーハンドリング（選択確定）

- [x] WHEN POST /onboarding/select APIがエラーを返した際
      THEN エラートーストが表示される
      AND 選択状態は維持される

### AC-8: 戻るボタン

- [x] WHEN ユーザーが「戻る」をクリックした際
      THEN 選択肢画面に戻る

### 実装方針

```tsx
// app/onboarding/_components/PackSelector/index.tsx
"use client";

import { usePackSelector } from "./usePackSelector";

interface PackSelectorProps {
  visitorId: string;
  onComplete: () => void;
  onBack: () => void;
}

export function PackSelector({ visitorId, onComplete, onBack }: PackSelectorProps) {
  const {
    packs,
    isLoadingPacks,
    packsError,
    selectedPack,
    selectPack,
    confirmSelection,
    isConfirming,
    confirmError,
    retryLoadPacks,
  } = usePackSelector(visitorId);

  const handleConfirm = async () => {
    try {
      await confirmSelection();
      onComplete();
    } catch {
      // エラーはhook内で処理
    }
  };

  if (isLoadingPacks) {
    return <PackSelectorSkeleton />;
  }

  if (packsError) {
    return (
      <ErrorState
        message="パック一覧の取得に失敗しました"
        onRetry={retryLoadPacks}
        onBack={onBack}
      />
    );
  }

  return (
    <div className="flex flex-col min-h-screen p-4">
      <header className="mb-6">
        <button onClick={onBack} className="text-gray-500">
          ← 戻る
        </button>
        <h1 className="text-xl font-bold mt-2">スターターパックを選ぶ</h1>
      </header>

      <div className="flex-1 grid gap-4">
        {packs.map((pack) => (
          <PackCard
            key={pack.type}
            pack={pack}
            isSelected={selectedPack?.type === pack.type}
            onSelect={() => selectPack(pack)}
            disabled={isConfirming}
          />
        ))}
      </div>

      {confirmError && (
        <div className="text-red-500 text-sm mt-4">
          選択に失敗しました。もう一度お試しください。
        </div>
      )}

      <footer className="mt-6">
        <button
          onClick={handleConfirm}
          disabled={!selectedPack || isConfirming}
          className="w-full py-3 bg-blue-600 text-white rounded-lg disabled:opacity-50"
        >
          {isConfirming ? "設定中..." : "始める"}
        </button>
      </footer>
    </div>
  );
}
```

### PackCard コンポーネント

```tsx
interface PackCardProps {
  pack: StarterPackInfo;
  isSelected: boolean;
  onSelect: () => void;
  disabled: boolean;
}

function PackCard({ pack, isSelected, onSelect, disabled }: PackCardProps) {
  // パックタイプ別のアイコン
  const icons: Record<string, string> = {
    horror: "👻",
    surreal: "🌀",
    scientific: "🔬",
    heartwarming: "💖",
    mystery: "🔍",
  };

  return (
    <button
      onClick={onSelect}
      disabled={disabled}
      className={`p-4 border-2 rounded-lg text-left transition-colors ${
        isSelected ? "border-blue-500 bg-blue-50" : "border-gray-200 hover:border-gray-300"
      } ${disabled ? "opacity-50 cursor-not-allowed" : ""}`}
    >
      <div className="flex items-start gap-3">
        <span className="text-2xl">{icons[pack.type]}</span>
        <div>
          <h3 className="font-bold">{pack.displayName}</h3>
          <p className="text-sm text-gray-600 mt-1">{pack.description}</p>
          <div className="flex gap-2 mt-2">
            {pack.primaryTags.slice(0, 3).map((tag) => (
              <span key={tag} className="text-xs px-2 py-1 bg-gray-100 rounded">
                {tag}
              </span>
            ))}
          </div>
        </div>
      </div>
    </button>
  );
}
```

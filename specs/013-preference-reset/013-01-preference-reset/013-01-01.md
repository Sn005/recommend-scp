# Subtask 013-01-01: PreferenceStorage resetPreference 実装

## 概要

`PreferenceStorage` インターフェースに `resetPreference` メソッドを追加し、`SupabasePreferenceStorage` で実装する。

**status**: completed

## ユーザーストーリー

**As a** 推薦システムの開発者
**I want** 嗜好リセット操作を `PreferenceStorage` インターフェースで抽象化したい
**So that** ストレージ実装に依存せずリセット機能を利用できる

## Acceptance Criteria（EARS記法）

### AC-1: インターフェース定義

- [x] WHEN `PreferenceStorage` インターフェースを参照した際
      GIVEN インターフェース定義が更新されている場合
      THEN `resetPreference(visitorId: string): Promise<void>` メソッドが定義されている

### AC-2: SupabasePreferenceStorage 実装

- [x] WHEN `resetPreference(visitorId)` が呼び出された際
      GIVEN 有効なvisitorIdが存在する場合
      THEN `visitors` テーブルの以下カラムが初期化される: - `preference_vector` → NULL - `tag_weights` → `{}` - `object_class_preference` → `{}` - `starter_pack` → NULL - `onboarding_completed_at` → NULL
      AND `feedback` テーブルの該当visitor_id行が全件削除される
      AND `recommendation_log` テーブルの該当visitor_id行が全件削除される

### AC-3: データ保持

- [x] WHEN `resetPreference(visitorId)` が実行された際
      THEN `favorites` テーブルのデータは変更されない
      AND `view_history` テーブルのデータは変更されない
      AND `visitors.visitor_id` は変更されない

- [x] WHERE `resetPreference` メソッド
      IF visitorIdが既に初期状態（オンボーディング未完了）の場合

## 技術設計

### インターフェース追加（packages/shared/src/storage/types.ts）

```typescript
export interface PreferenceStorage {
  // ... 既存メソッド

  /**
   * 嗜好データをリセット
   * - visitors: preference_vector, tag_weights, object_class_preference,
   *   starter_pack, onboarding_completed_at を初期化
   * - feedback: 全行削除
   * - recommendation_log: 全行削除
   * - favorites, view_history: 保持
   *
   * @param visitorId 訪問者ID
   */
  resetPreference(visitorId: string): Promise<void>;
}
```

### Supabase実装（apps/api-server/src/lib/storage/supabase-preference-storage.ts）

```typescript
resetPreference = async (visitorId: string): Promise<void> => {
  // 1. visitorsテーブルの嗜好カラムを初期化
  const { error: updateError } = await this.supabase
    .from("visitors")
    .update({
      preference_vector: null,
      tag_weights: {},
      object_class_preference: {},
      starter_pack: null,
      onboarding_completed_at: null,
      updated_at: new Date().toISOString(),
    })
    .eq("visitor_id", visitorId);

  if (updateError) throw new DatabaseError(updateError);

  // 2. feedback削除（既存メソッド活用）
  await this.clearFeedback(visitorId);

  // 3. recommendation_log削除（既存メソッド活用）
  await this.clearRecommendationLog(visitorId);
};
```

### 既存メソッドの活用

`clearFeedback()` と `clearRecommendationLog()` は `SupabasePreferenceStorage` クラスの既存メソッド。
`PreferenceStorage` インターフェースには含まれないが、具象クラス内部で `this.clearFeedback()` として呼び出せる。
インターフェースに追加するのは `resetPreference()` のみ。

| メソッド                   | 処理内容                     | 新規/既存 | インターフェース |
| -------------------------- | ---------------------------- | --------- | ---------------- |
| `clearFeedback()`          | feedback全行DELETE           | 既存      | なし（内部利用） |
| `clearRecommendationLog()` | recommendation_log全行DELETE | 既存      | なし（内部利用） |
| `resetPreference()`        | 上記 + visitorsカラム初期化  | 新規      | あり（追加）     |

## 技術設計

### エンドポイント仕様

```
POST /visitors/reset
Content-Type: application/json

Request:
{
  "visitorId": "uuid-string"
}

Response (200):
{
  "success": true,
  "visitorId": "uuid-string"
}

Response (404):
{
  "type": "about:blank",
  "title": "Not Found",
  "status": 404,
  "detail": "Visitor not found"
}
```

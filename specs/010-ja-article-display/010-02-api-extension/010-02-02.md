# Subtask 010-02-02: 翻訳有無更新API

## 親Story

[010-02: 推薦API日本語対応](./010-02.md)

## ユーザーストーリー

**ペルソナ**: フロントエンド開発者
**目的**: WebViewで404を検知したときにDBを更新できるようにする
**価値**: 翻訳がない記事を次回から推薦候補から除外できる
**理由**: ユーザー体験を向上させ、404エラーを減らしたい

> フロントエンド開発者として、WebViewで404を検知したときにDBを更新し、翻訳がない記事を次回から除外したい。なぜならユーザー体験を向上させ、404エラーを減らしたいから。

## Acceptance Criteria

### AC-1: エンドポイント作成

- [ ] WHEN PATCH /api/articles/:articleId/translation を呼び出した際
      GIVEN 有効なリクエストボディの場合
      THEN 200 OK を返す

### AC-2: has_translation 更新

- [ ] WHEN 有効なリクエストで呼び出した際
      THEN `article_translations` の `has_translation` が更新される
      AND `checked_at` が現在時刻に更新される

### AC-3: バリデーション

- [ ] WHEN 無効な articleId で呼び出した際
      THEN 404 Not Found を返す

- [ ] WHEN 無効な lang で呼び出した際
      THEN 400 Bad Request を返す

### AC-4: 存在しないレコード

- [ ] WHEN 存在しない article_id + lang の組み合わせで呼び出した際
      THEN 404 Not Found を返す

### ハンドラ実装

```typescript
// apps/api/src/routes/articles/translation.ts
import { Hono } from "hono";
import { zValidator } from "@hono/zod-validator";
import { z } from "zod";

const updateTranslationSchema = z.object({
  lang: z.string().min(2).max(5),
  hasTranslation: z.boolean(),
});

export const translationRoutes = new Hono().patch(
  "/",
  zValidator("json", updateTranslationSchema),
  async (c) => {
    const articleId = c.req.param("articleId");
    const { lang, hasTranslation } = c.req.valid("json");

    const { data, error } = await supabase
      .from("article_translations")
      .update({
        has_translation: hasTranslation,
        checked_at: new Date().toISOString(),
      })
      .eq("article_id", articleId)
      .eq("lang", lang)
      .select()
      .single();

    if (error || !data) {
      return c.json(
        {
          type: "about:blank",
          title: "Not Found",
          status: 404,
          detail: "Translation record not found",
        },
        404
      );
    }

    return c.json({
      success: true,
      data: {
        articleId: data.article_id,
        lang: data.lang,
        hasTranslation: data.has_translation,
        checkedAt: data.checked_at,
      },
    });
  }
);
```

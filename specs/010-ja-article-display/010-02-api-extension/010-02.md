# Story 010-02: 推薦API日本語対応

## 親EPIC

[010: 日本語記事表示・閲覧履歴改善](../010-ja-article-display.md)

## ユーザーストーリー

**ペルソナ**: フロントエンド開発者
**目的**: 推薦APIから日本語版URLを取得できるようにする
**価値**: WebViewで日本語記事を表示できる
**理由**: フロントエンドで日本語版URLを使用して記事を表示したい

> フロントエンド開発者として、推薦APIから日本語版URLを取得し、WebViewで日本語記事を表示したい。なぜなら日本語ユーザーに最適な体験を提供したいから。

## Acceptance Criteria

### AC-1: RecommendedArticle に url 追加

- [ ] WHEN 推薦APIが記事を返す際
      THEN レスポンスに `url` フィールドが含まれる
      AND `article_translations` から日本語URLを取得する

### AC-2: 翻訳なし記事の除外

- [ ] WHEN 推薦APIが記事を選択する際
      GIVEN `has_translation = FALSE` の記事がある場合
      THEN その記事を推薦候補から除外する

### AC-3: 未確認記事の許可

- [ ] WHEN 推薦APIが記事を選択する際
      GIVEN `has_translation = NULL` の記事がある場合
      THEN その記事は推薦候補に含める

### AC-4: 翻訳有無更新API

- [ ] WHEN PATCH /articles/:articleId/translation を呼び出した際
      GIVEN 有効なリクエストボディの場合
      THEN `article_translations` の `has_translation` が更新される
      AND `checked_at` が現在時刻に更新される

## 技術設計

### API変更

```typescript
// packages/shared/src/recommendation/engine.ts
export interface RecommendedArticle {
  id: string;
  title: string;
  similarityScore: number;
  source: "preference" | "serendipity";
  url: string; // 追加
}
```

### SQLクエリ変更

```sql
SELECT
  a.article_id,
  a.title,
  t.url
FROM scp_articles a
LEFT JOIN article_translations t
  ON a.article_id = t.article_id
  AND t.lang = 'ja'
WHERE (t.has_translation IS NULL OR t.has_translation = TRUE)
```

### 新規APIエンドポイント

```
PATCH /api/articles/:articleId/translation

Request:
{
  "lang": "ja",
  "hasTranslation": false
}

Response:
{
  "success": true
}
```

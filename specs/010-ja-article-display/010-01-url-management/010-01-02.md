# Subtask 010-01-02: 初期データ投入マイグレーション

## 親Story

[010-01: 日本語記事URL管理](./010-01.md)

## ユーザーストーリー

**ペルソナ**: 開発者
**目的**: 既存の英語版記事データから日本語版URLを一括生成する
**価値**: 日本語クローラーなしで日本語URLを取得できる
**理由**: 実装コストを抑えつつ、すぐに日本語対応を開始したい

> 開発者として、既存の英語版記事データから日本語版URLを一括生成し、日本語クローラーなしで対応したい。なぜなら実装コストを抑えつつ、すぐに日本語対応を開始したいから。

## Acceptance Criteria

### AC-1: 日本語URL生成

- [ ] WHEN マイグレーションを実行した際
      GIVEN 既存の `scp_articles` に英語版記事がある場合
      THEN 各記事に対応する日本語版URLが `article_translations` に挿入される

### AC-2: URL生成ロジック

- [ ] WHEN 日本語URLが生成される際
      GIVEN article_id が "SCP-173" の場合
      THEN URL は "http://scp-jp.wikidot.com/scp-173" となる
      AND lang は "ja" となる

### AC-3: 冪等性

- [ ] WHEN マイグレーションを再実行した際
      GIVEN 既にデータが存在する場合
      THEN 重複挿入エラーにならない（ON CONFLICT DO NOTHING）

### AC-4: 件数確認

- [ ] WHEN マイグレーション完了後
      THEN `scp_articles` の英語版記事数と同数のレコードが挿入される

## 技術設計

### マイグレーションファイル

```sql
-- supabase/migrations/YYYYMMDDHHMMSS_seed_article_translations_ja.sql

-- 日本語版URL一括投入
INSERT INTO article_translations (article_id, lang, url)
SELECT
  article_id,
  'ja',
  'http://scp-jp.wikidot.com/' || LOWER(article_id)
FROM scp_articles
WHERE lang = 'en'
ON CONFLICT (article_id, lang) DO NOTHING;

-- 投入件数確認用コメント
-- 期待値: scp_articles WHERE lang = 'en' と同数
```

### URL生成例

| article_id | lang | url                               |
| ---------- | ---- | --------------------------------- |
| SCP-173    | ja   | http://scp-jp.wikidot.com/scp-173 |
| SCP-682    | ja   | http://scp-jp.wikidot.com/scp-682 |
| SCP-999    | ja   | http://scp-jp.wikidot.com/scp-999 |

### 確認クエリ

```sql
-- 投入件数確認
SELECT COUNT(*) FROM article_translations WHERE lang = 'ja';

-- サンプルデータ確認
SELECT * FROM article_translations WHERE lang = 'ja' LIMIT 10;

-- 英語版記事との件数比較
SELECT
  (SELECT COUNT(*) FROM scp_articles WHERE lang = 'en') as en_count,
  (SELECT COUNT(*) FROM article_translations WHERE lang = 'ja') as ja_count;
```

## テストケース

- [ ] マイグレーション実行後、日本語URLが生成される
- [ ] article_id が小文字化されてURLに含まれる
- [ ] 再実行しても重複エラーにならない
- [ ] 英語版記事数と日本語URL数が一致する

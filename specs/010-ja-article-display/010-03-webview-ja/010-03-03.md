# Subtask 010-03-03: 本文・タイトル抽出

## 親Story

[010-03: WebView日本語記事表示](./010-03.md)

## ユーザーストーリー

**ペルソナ**: SCPファン
**目的**: 閲覧した記事の内容を後で思い出せるようにする
**価値**: 履歴に本文冒頭が表示され、何の記事だったか分かる
**理由**: タイトルだけでは記事内容を思い出しにくい

> SCPファンとして、閲覧した記事の内容を後で思い出せるように、本文冒頭を保存したい。なぜならタイトルだけでは記事内容を思い出しにくいから。

## 技術設計

### 抽出アプローチ

クロスオリジン制限により、iframe内のDOMに直接アクセスできない。
代替アプローチとして、サーバーサイドでコンテンツを取得する。

```typescript
// apps/api/src/routes/articles/content.ts

export const contentRoutes = new Hono().get("/:articleId/content", async (c) => {
  const articleId = c.req.param("articleId");
  const url = `http://scp-jp.wikidot.com/${articleId.toLowerCase()}`;

  try {
    const response = await fetch(url);
    const html = await response.text();

    // HTML解析
    const { JSDOM } = await import("jsdom");
    const dom = new JSDOM(html);
    const doc = dom.window.document;

    const title = doc.querySelector("#page-title")?.textContent?.trim() ?? "";
    const content = doc.querySelector("#page-content")?.textContent?.trim() ?? "";
    const excerpt = content.substring(0, 50);

    return c.json({ title, excerpt });
  } catch (error) {
    return c.json({ title: "", excerpt: "" });
  }
});
```

### クライアント側フック

```typescript
// apps/web/app/(main)/recommend/_components/ArticleWebView/useArticleContent.ts

interface UseArticleContentOptions {
  articleId: string;
  onContentLoaded: (content: { title: string; excerpt: string }) => void;
}

export const useArticleContent = ({ articleId, onContentLoaded }: UseArticleContentOptions) => {
  const [isLoading, setIsLoading] = useState(false);

  const fetchContent = useCallback(async () => {
    setIsLoading(true);
    try {
      const response = await fetch(`/api/articles/${articleId}/content`);
      const { title, excerpt } = await response.json();

      if (title && excerpt) {
        onContentLoaded({ title, excerpt });
      }
    } catch (error) {
      // サイレント失敗
      console.error("Content extraction failed:", error);
    } finally {
      setIsLoading(false);
    }
  }, [articleId, onContentLoaded]);

  return { fetchContent, isLoading };
};
```

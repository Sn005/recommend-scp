# Subtask 010-03-02: 404検知・サジェスト画面

## 親Story

[010-03: WebView日本語記事表示](./010-03.md)

## ユーザーストーリー

**ペルソナ**: SCPファン（日本語ユーザー）
**目的**: 翻訳がない記事にアクセスしたときに適切に対処する
**価値**: 404エラーでがっかりせず、別の記事を楽しめる
**理由**: 翻訳がない記事でも、スムーズに別の記事に移りたい

> SCPファンとして、翻訳がない記事にアクセスしたときに別の記事を提案してほしい。なぜなら404エラーでがっかりせず、スムーズに読み続けたいから。

## Acceptance Criteria

### AC-1: 404検知

- [ ] WHEN WebViewで記事を読み込んだ際
      GIVEN ページが存在しない（404）場合
      THEN 404を検知できる

### AC-2: DB更新

- [ ] WHEN 404が検知された際
      THEN PATCH /articles/:id/translation を呼び出す
      AND `has_translation = FALSE` に更新される

### AC-3: サジェスト画面表示

- [ ] WHEN 翻訳がない記事にアクセスした際
      THEN WebViewを非表示にする
      AND サジェスト画面を表示する

### AC-4: サジェスト画面UI

- [ ] WHEN サジェスト画面が表示された際
      THEN 「この記事の日本語訳はまだ公開されていません」と表示する
      AND 「別の記事をおすすめ」ボタンを表示する

### AC-5: 別記事遷移

- [ ] WHEN 「別の記事をおすすめ」ボタンをタップした際
      THEN 次の推薦記事に遷移する
      AND サジェスト画面が閉じる

## 技術設計

### 404検知フック

```typescript
// apps/web/app/(main)/recommend/_components/ArticleWebView/use404Detection.ts

interface Use404DetectionOptions {
  url: string;
  onNotFound: () => void;
}

export const use404Detection = ({ url, onNotFound }: Use404DetectionOptions) => {
  const [isChecking, setIsChecking] = useState(true);
  const [isNotFound, setIsNotFound] = useState(false);

  useEffect(() => {
    const checkUrl = async () => {
      setIsChecking(true);
      try {
        // プロキシAPIを使用して404チェック
        const response = await fetch(`/api/check-url?url=${encodeURIComponent(url)}`);
        const { exists } = await response.json();

        if (!exists) {
          setIsNotFound(true);
          onNotFound();
        }
      } catch (error) {
        // ネットワークエラーは404として扱わない
        console.error("URL check failed:", error);
      } finally {
        setIsChecking(false);
      }
    };

    checkUrl();
  }, [url, onNotFound]);

  return { isChecking, isNotFound };
};
```

### URLチェックAPI（プロキシ）

```typescript
// apps/api/src/routes/check-url.ts
// クロスオリジン制限を回避するためのサーバーサイドチェック

export const checkUrlRoutes = new Hono().get("/", async (c) => {
  const url = c.req.query("url");

  if (!url) {
    return c.json({ error: "url is required" }, 400);
  }

  try {
    const response = await fetch(url, { method: "HEAD" });
    return c.json({ exists: response.ok });
  } catch {
    return c.json({ exists: false });
  }
});
```

### 統合

```typescript
// apps/web/app/(main)/recommend/_components/ArticleWebView/index.tsx

export const ArticleWebView = ({
  article,
  onReadComplete,
  onSkip,
}: ArticleWebViewProps) => {
  const [showNotFound, setShowNotFound] = useState(false);

  const handleNotFound = async () => {
    // DB更新
    await fetch(`/api/articles/${article.id}/translation`, {
      method: 'PATCH',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ lang: 'ja', hasTranslation: false }),
    });

    setShowNotFound(true);
  };

  const { isChecking } = use404Detection({
    url: article.url,
    onNotFound: handleNotFound,
  });

  if (showNotFound) {
    return <TranslationNotFound onSuggest={onSkip} />;
  }

  if (isChecking) {
    return <LoadingSpinner />;
  }

  return (
    <iframe
      src={article.url}
      className="w-full h-full border-0"
      title={article.title}
    />
  );
};
```

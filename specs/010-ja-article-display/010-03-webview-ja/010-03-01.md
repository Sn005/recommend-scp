# Subtask 010-03-01: WebView日本語URL対応

## 親Story

[010-03: WebView日本語記事表示](./010-03.md)

## ユーザーストーリー

**ペルソナ**: SCPファン（日本語ユーザー）
**目的**: WebViewで日本語版記事を表示する
**価値**: 日本語で記事を読める
**理由**: 英語版URLではなく、日本語版URLで記事を表示したい

> SCPファンとして、WebViewで日本語版記事を表示し、日本語で記事を読みたい。なぜなら英語版URLではなく、日本語版URLで記事を表示したいから。

## Acceptance Criteria

### AC-1: URL使用

- [ ] WHEN ArticleWebView コンポーネントを使用する際
      THEN 推薦APIから取得した `url` プロパティを使用する
      AND iframe の src に日本語版URLが設定される

### AC-2: URL形式

- [ ] WHEN 記事を表示する際
      THEN URLは `http://scp-jp.wikidot.com/` で始まる

### AC-3: 既存機能維持

- [ ] WHEN 日本語URL対応を追加した際
      THEN 既存のスクロール連携機能は維持される
      AND 既存のフィードバック機能は維持される

## 技術設計

### コンポーネント変更

```typescript
// apps/web/app/(main)/recommend/_components/ArticleWebView/index.tsx

interface ArticleWebViewProps {
  article: RecommendedArticle;  // url フィールドを含む
  onReadComplete: () => void;
  onError: (type: 'not_found' | 'network') => void;
}

export const ArticleWebView = ({
  article,
  onReadComplete,
  onError,
}: ArticleWebViewProps) => {
  const iframeRef = useRef<HTMLIFrameElement>(null);

  return (
    <iframe
      ref={iframeRef}
      src={article.url}  // 日本語版URLを使用
      className="w-full h-full border-0"
      title={article.title}
    />
  );
};
```

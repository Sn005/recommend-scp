## ユーザーストーリー

**ペルソナ**: SCPファン（日本語ユーザー）
**目的**: 日本語で記事を読む
**価値**: 言語の壁なくSCPコンテンツを楽しめる
**理由**: 英語が苦手でも、日本語翻訳で記事を楽しみたい

> SCPファンとして、日本語で記事を読み、言語の壁なくSCPコンテンツを楽しみたい。なぜなら英語が苦手でも、日本語翻訳で記事を楽しみたいから。

### AC-1: 日本語URL使用

- [x] WHEN 記事をWebViewで表示する際

- [x] WHEN 404が検知された際

### 404検知アプローチ

```typescript
// クロスオリジンの場合、iframeのコンテンツにアクセスできない
// HEAD リクエストで事前確認するアプローチ

const check404 = async (url: string): Promise<boolean> => {
  try {
    const response = await fetch(url, { method: "HEAD", mode: "no-cors" });
    // no-corsモードではステータスコードを取得できない
    // 代替: サーバーサイドで確認するAPIを用意
    return response.ok;
  } catch {
    return false;
  }
};
```

### 本文抽出（同一オリジンの場合）

```typescript
const extractContent = (doc: Document) => {
  // SCP-JPのページ構造に基づく抽出
  const title = doc.querySelector("#page-title")?.textContent?.trim();
  const content = doc.querySelector("#page-content")?.textContent?.trim();
  const excerpt = content?.substring(0, 50);

  return { title, excerpt };
};
```

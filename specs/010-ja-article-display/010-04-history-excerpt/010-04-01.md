# Subtask 010-04-01: excerpt フィールド追加

## 親Story

[010-04: 閲覧履歴本文表示](./010-04.md)

## ユーザーストーリー

**ペルソナ**: SCPファン
**目的**: 閲覧履歴に本文冒頭を表示する
**価値**: 「何の記事だったか」思い出しやすくなる
**理由**: タイトルだけでは記事を特定しにくいことがある

> SCPファンとして、閲覧履歴に本文冒頭を表示し、「何の記事だったか」思い出しやすくしたい。なぜならタイトルだけでは記事を特定しにくいことがあるから。

## Acceptance Criteria

### AC-1: 型定義変更

- [ ] WHEN HistoryEntry 型を使用する際
      THEN `excerpt` フィールドが存在する
      AND 型は `string` である

### AC-2: ストレージ保存

- [ ] WHEN 履歴を追加する際
      THEN `excerpt` が localStorage に保存される

### AC-3: 後方互換性

- [ ] WHEN 既存の履歴データを読み込む際
      GIVEN `excerpt` フィールドがない場合
      THEN 空文字列をデフォルト値とする
      AND エラーにならない

### AC-4: UI表示

- [ ] WHEN 履歴カードを表示する際
      THEN タイトル下に `excerpt` が表示される
      AND グレーのテキストカラーで表示される
      AND 1行に収まるよう省略される

### AC-5: 空の excerpt

- [ ] WHEN `excerpt` が空の場合
      THEN excerpt 行は表示しない

```typescript
// apps/web/app/(main)/history/_lib/historyStorage.ts

export const addHistory = (entry: Omit<HistoryEntry, "viewedAt">): HistoryEntry => {
  const newEntry: HistoryEntry = {
    ...entry,
    excerpt: entry.excerpt ?? "", // デフォルト値
    viewedAt: new Date().toISOString(),
  };

  // ...
};

// 後方互換性のためのマイグレーション
export const getHistory = (): HistoryEntry[] => {
  if (typeof window === "undefined") return [];
  const stored = localStorage.getItem(STORAGE_KEY);
  if (!stored) return [];

  const parsed = JSON.parse(stored) as unknown[];
  return parsed.map((item: Record<string, unknown>) => ({
    scpNumber: item.scpNumber as string,
    title: item.title as string,
    excerpt: (item.excerpt as string) ?? "", // 後方互換性
    objectClass: item.objectClass as ObjectClass,
    viewedAt: item.viewedAt as string,
  }));
};
```

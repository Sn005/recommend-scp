## ユーザーストーリー

**ペルソナ**: SCPファン
**目的**: 閲覧履歴から「何の記事だったか」思い出せるようにする
**価値**: タイトルだけでなく本文冒頭も見れて、記事を特定しやすい
**理由**: 後で読み返したい記事をすぐに見つけたい

> SCPファンとして、閲覧履歴から「何の記事だったか」思い出せるように、本文冒頭も表示したい。なぜなら後で読み返したい記事をすぐに見つけたいから。

```typescript
export interface HistoryEntry {
  scpNumber: string;
  title: string;
  excerpt: string; // 追加: 本文冒頭50文字
  objectClass: ObjectClass;
  viewedAt: string;
}
```

### UI更新

```typescript

export const HistoryCard = ({ entry }: { entry: HistoryEntry }) => {
  return (
```

# Subtask 004-03-02: 初期プロファイル構築

## 概要

スターターパック選択または記事選択から初期の嗜好プロファイル（`PreferenceProfile`）を構築する機能を実装する。

## ステータス

- **status**: completed

## ユーザーストーリー

**As a** 新規ユーザー
**I want** 選択したスターターパックから自動で好みを設定してほしい
**So that** すぐにパーソナライズされた推薦を受けられる

## Acceptance Criteria（EARS記法）

- [x] WHEN ユーザーがスターターパックを選択した際
      THEN システムはパックのprimaryTagsからtagWeightsを生成する
      AND seedArticlesのEmbeddingからpreferenceEmbeddingを計算する

- [x] WHEN ユーザーが「自分で選ぶ」で記事を選択した際
      GIVEN 3件以上の記事が選択された場合
      THEN 選択記事のタグからtagWeightsを生成する
      AND 選択記事のEmbedding平均からpreferenceEmbeddingを計算する

- [x] WHEN 初期プロファイルが構築された際
      THEN onboardingCompletedAtにタイムスタンプが設定される
      AND starterPackフィールドに選択されたパックタイプが設定される

- [x] WHEN オンボーディングが完了した際
      THEN ストレージにプロファイルが保存される
      AND 推薦エンジンが使用可能な状態になる

### Embedding平均計算

```typescript
private async calculateAverageEmbedding(articleIds: string[]): Promise<number[]> {
  const embeddings = await Promise.all(
    articleIds.map(id => this.getArticleEmbedding(id))
  );

  const dimension = embeddings[0].length;
  const average = new Array(dimension).fill(0);

  for (const embedding of embeddings) {
    for (let i = 0; i < dimension; i++) {
      average[i] += embedding[i] / embeddings.length;
    }
  }

  return average;
}
```

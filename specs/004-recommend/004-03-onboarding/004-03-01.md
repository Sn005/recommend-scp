# Subtask 004-03-01: スターターパック定義

## 概要

5種類のスターターパック（ホラー、シュール、科学・SF、ほのぼの、謎解き）を定義し、各パックに対応するタグと代表記事を設定する。

## ステータス

- **status**: pending

## ユーザーストーリー

**As a** 新規ユーザー
**I want** 自分の好みを簡単に選択したい
**So that** 複雑な設定なしで推薦を開始できる

## Acceptance Criteria（EARS記法）

- [ ] WHERE スターターパック
      THE SYSTEM SHALL 以下の5種類を提供する: - horror（ホラー好き）- surreal（シュール好き）- scientific（科学・SF好き）- heartwarming（ほのぼの好き）- mystery（謎解き好き）

- [ ] WHERE 各スターターパック
      THE SYSTEM SHALL 以下を含む: - displayName: 表示名（日本語）- description: 説明文 - primaryTags: 主要タグリスト - seedArticles: 代表記事IDリスト

- [ ] WHEN スターターパック一覧を取得する際
      THEN 全5種類 + custom オプションが返される

## 技術設計

### 型定義

```typescript
// packages/shared/src/onboarding/types.ts

export type StarterPackType =
  | "horror"
  | "surreal"
  | "scientific"
  | "heartwarming"
  | "mystery"
  | "custom";

export interface StarterPackDefinition {
  type: StarterPackType;
  displayName: string;
  description: string;
  primaryTags: string[];
  seedArticles: string[];
}
```

### スターターパック定義

```typescript
// packages/shared/src/onboarding/starter-packs.ts

export const STARTER_PACKS: Record<Exclude<StarterPackType, "custom">, StarterPackDefinition> = {
  horror: {
    type: "horror",
    displayName: "ホラー好き",
    description: "背筋が凍るような恐怖体験を求めるあなたへ",

    seedArticles: ["scp-087", "scp-106", "scp-096"],
  },
  surreal: {
    type: "surreal",
    displayName: "シュール好き",
    description: "不思議で奇妙な世界観を楽しみたいあなたへ",
    primaryTags: ["surreal", "humorous", "joke", "absurd"],
    seedArticles: ["scp-426", "scp-999", "scp-2337"],
  },
  scientific: {
    type: "scientific",
    displayName: "科学・SF好き",
    description: "科学的な考察やSF要素を楽しみたいあなたへ",

  },
  heartwarming: {
    type: "heartwarming",
    displayName: "ほのぼの好き",
    description: "心温まる優しい異常存在を探しているあなたへ",
    primaryTags: ["heartwarming", "safe", "friendly"],
    seedArticles: ["scp-999", "scp-131", "scp-529"],
  },
  mystery: {
    type: "mystery",
    displayName: "謎解き好き",
    description: "複雑な謎や考察を楽しみたいあなたへ",
    primaryTags: ["mystery", "puzzle", "meta"],
    seedArticles: ["scp-001", "scp-055", "scp-2521"],
  },
};

export function getStarterPackList(): StarterPackDefinition[] {
  return Object.values(STARTER_PACKS);
}

export function getStarterPack(type: StarterPackType): StarterPackDefinition | null {
  if (type === "custom") return null;
  return STARTER_PACKS[type] ?? null;
}
```

## テストケース

- [ ] getStarterPackListが5種類のパックを返す
- [ ] 各パックにdisplayName, description, primaryTags, seedArticlesが含まれる
- [ ] getStarterPack("custom")がnullを返す
- [ ] 存在しないパックタイプでnullが返る

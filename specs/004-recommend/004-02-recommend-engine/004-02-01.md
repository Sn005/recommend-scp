# Subtask 004-02-01: 推薦エンジンコア

## 概要

推薦ロジックのコアとなる`RecommendationEngine`クラスを実装する。ハイブリッド検索（Embedding + タグ）を使用して推薦候補を取得し、既読・Dislike済み記事を除外する。

## ステータス

- **status**: pending

## ユーザーストーリー

**As a** 推薦システム
**I want** ユーザーの嗜好に基づいて記事を推薦できる
**So that** パーソナライズされた体験を提供できる

## Acceptance Criteria（EARS記法）

- [ ] WHEN 推薦をリクエストした際
      GIVEN ユーザープロファイルが存在する場合
      THEN 既存のhybridSearch関数を使用して類似記事を取得する
      AND embedding_weight: 0.6, tag_weight: 0.4 で検索する

- [ ] WHEN 推薦候補を返す際
      THEN 既読記事（viewHistory）を除外する
      AND Dislike済み記事を除外する

- [ ] WHEN 推薦をリクエストした際
      GIVEN ユーザープロファイルが存在しない場合
      THEN オンボーディング未完了エラーをスローする

- [ ] WHERE RecommendationEngine
      THE SYSTEM SHALL 以下のメソッドを提供する:
      - getNextRecommendation(visitorId): 次の推薦を取得
      - recordView(visitorId, articleId): 閲覧を記録
      - recordFeedback(visitorId, articleId, type): フィードバックを記録

## 技術設計

### クラス設計

```typescript
// packages/shared/src/recommendation/engine.ts

export interface RecommendedArticle {
  id: string;
  title: string;
  similarityScore: number;
  source: "preference" | "serendipity";
}

export class RecommendationEngine {
  constructor(
    private storage: PreferenceStorage,
    private profiler: PreferenceProfiler
  ) {}

  async getNextRecommendation(
    visitorId: string,
    limit: number = 10
  ): Promise<RecommendedArticle[]> {
    const profile = await this.storage.getProfile(visitorId);
    if (!profile) {
      throw new Error("Onboarding not completed");
    }

    const excludedIds = await this.getExcludedIds(visitorId);

    // ハイブリッド検索（既存実装を活用）
    const results = await hybridSearch({
      queryEmbedding: profile.preferenceEmbedding,
      embeddingWeight: 0.6,
      tagWeight: 0.4,
      excludeIds: excludedIds,
      limit,
    });

    return results.map((r) => ({
      id: r.id,
      title: r.title,
      similarityScore: r.similarity_score,
      source: "preference" as const,
    }));
  }

  private async getExcludedIds(visitorId: string): Promise<string[]> {
    const viewHistory = await this.storage.getViewHistory(visitorId);
    const disliked = await this.storage.getDislikedArticleIds(visitorId);

    const viewedIds = viewHistory.map((h) => h.articleId);
    return [...new Set([...viewedIds, ...disliked])];
  }
}
```

## テストケース

- [ ] プロファイルが存在する場合、推薦記事リストが返る
- [ ] プロファイルが存在しない場合、エラーがスローされる
- [ ] 既読記事が除外される
- [ ] Dislike済み記事が除外される
- [ ] hybridSearchが正しいパラメータで呼ばれる

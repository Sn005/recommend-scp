# Subtask 004-02-03: 連続類似検出

## 概要

ユーザーが連続で類似記事を5件閲覧した場合、次の推薦を強制的に「冒険枠」にする機能を実装する。

## ステータス

- **status**: pending

## ユーザーストーリー

**As a** SCPファン
**I want** 同じようなジャンルばかり読み続けないようにしたい
**So that** フィルターバブルに陥らず多様な記事を楽しめる

## Acceptance Criteria（EARS記法）

- [ ] WHEN ユーザーが推薦記事を閲覧した際
      THEN 推薦ログ（RecommendationLog）にsourceを記録する

- [ ] WHEN 推薦を行う際
      GIVEN 直近5件の推薦が全て "preference" の場合
      THEN 次の推薦は強制的に "serendipity" から選出する

- [ ] WHEN 連続類似検出がトリガーされた際
      THEN ログに「冒険枠強制」が記録される

- [ ] WHERE 連続類似検出
      IF 直近5件に "serendipity" が1件以上含まれる場合
      THE SYSTEM SHALL 通常の80/20判定を行う

## 技術設計

### 連続類似検出ロジック

```typescript
// packages/shared/src/recommendation/engine.ts

private async shouldForceSerendipity(visitorId: string): Promise<boolean> {
  const recentLogs = await this.storage.getRecommendationLog(visitorId, 5);

  if (recentLogs.length < 5) {
    return false;
  }

  // 直近5件が全て "preference" かチェック
  const allPreference = recentLogs.every(
    (log) => log.source === "preference"
  );

  return allPreference;
}
```

### エンジンへの統合


### 推薦ログ記録

```typescript
async recordRecommendation(
  visitorId: string,
  articleId: string,
  source: "preference" | "serendipity"
): Promise<void> {
  await this.storage.addRecommendationLog({
    id: `${visitorId}_${articleId}_${Date.now()}`,
    visitorId,
    articleId,
    recommendedAt: new Date().toISOString(),
    source,
    clicked: false,
  });
}
```

## テストケース

- [ ] 直近5件が全て "preference" の場合、trueが返る
- [ ] 直近5件に "serendipity" が含まれる場合、falseが返る
- [ ] 履歴が5件未満の場合、falseが返る
- [ ] 冒険枠強制時にセレンディピティ記事が返る
- [ ] 推薦ログが正しく記録される

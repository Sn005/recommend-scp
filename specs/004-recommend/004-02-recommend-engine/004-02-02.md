# Subtask 004-02-02: セレンディピティ実装

## 概要

80/20の比率で「好み推薦」と「セレンディピティ枠」を切り替える機能を実装する。

## ステータス

- **status**: pending

## ユーザーストーリー

**As a** SCPファン
**I want** たまに意外な記事を推薦してほしい
**So that** 新しいジャンルを発見できる

## Acceptance Criteria（EARS記法）

- [ ] WHEN 推薦を行う際
      THEN 80%の確率で好みに類似した記事を推薦する（Exploitation）
      AND 20%の確率でセレンディピティ枠から推薦する（Exploration）

- [ ] WHEN セレンディピティ枠から推薦する際
      THEN 好みベクトルから「少し離れた」記事を選出する
      AND 類似度 0.3〜0.7 の範囲から選ぶ

- [ ] WHEN 推薦結果を返す際
      THEN source フィールドで "preference" か "serendipity" かを識別できる

## 技術設計

### セレンディピティ選出ロジック

```typescript
// packages/shared/src/recommendation/serendipity.ts

export interface SerendipityConfig {
  explorationRate: number; // デフォルト: 0.2（20%）
  minSimilarity: number; // デフォルト: 0.3
  maxSimilarity: number; // デフォルト: 0.7
}

export async function getSerendipityArticles(
  profile: PreferenceProfile,
  excludeIds: string[],
  config: SerendipityConfig = defaultConfig,
  limit: number = 10
): Promise<RecommendedArticle[]> {
  // 好みベクトルから一定距離の記事を検索
  const results = await hybridSearch({
    queryEmbedding: profile.preferenceEmbedding,
    embeddingWeight: 0.6,
    tagWeight: 0.4,
    excludeIds,
    similarityMin: config.minSimilarity,
    similarityMax: config.maxSimilarity,
    limit,
  });

  return results.map((r) => ({
    id: r.id,
    title: r.title,
    similarityScore: r.similarity_score,
    source: "serendipity" as const,
  }));
}
```

### エンジンへの統合

```typescript
// RecommendationEngine.getNextRecommendation 内

const isSerendipity = Math.random() < this.config.explorationRate;

if (isSerendipity) {
  return getSerendipityArticles(profile, excludedIds, this.config);
} else {
  return this.getPreferenceBasedArticles(profile, excludedIds);
}
```

## テストケース

- [ ] explorationRate=0.2 の場合、約20%の確率でセレンディピティが選ばれる
- [ ] セレンディピティ記事は類似度0.3〜0.7の範囲から選ばれる
- [ ] 返却されるarticleのsourceが正しく設定される
- [ ] 除外IDリストが正しく適用される

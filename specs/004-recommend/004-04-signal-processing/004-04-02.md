# Subtask 004-04-02: 閲覧履歴・読了シグナル処理

## 概要

ユーザーの閲覧履歴を記録し、読了（Likeなし）を弱い正のシグナルとして処理する機能を実装する。

## ステータス

- **status**: pending

## ユーザーストーリー

**As a** 推薦システム
**I want** ユーザーの閲覧行動を追跡したい
**So that** 暗黙的なフィードバックも推薦に活用できる

## Acceptance Criteria（EARS記法）

- [ ] WHEN ユーザーが記事を開いた際
      THEN ViewHistoryレコードがストレージに保存される
      AND viewedAtにタイムスタンプが記録される

- [ ] WHEN ユーザーが記事を最後まで読んだ（Likeなし）際
      THEN その記事のタグに対する重みが +0.3 増加する
      AND プロファイルが再計算される

- [ ] WHEN 閲覧履歴を取得する際
      THEN visitorIdでフィルタリングできる
      AND 日付順でソートされる

- [ ] WHERE 閲覧履歴
      IF 滞在時間が記録可能な場合
      THE SYSTEM SHALL durationフィールドに秒数を保存する

## 技術設計

### 閲覧記録

```typescript
// packages/shared/src/recommendation/signal-processor.ts

export class SignalProcessor {
  // ... 既存メソッド

  async recordView(
    visitorId: string,
    articleId: string,
    duration?: number
  ): Promise<void> {
    await this.storage.addViewHistory({
      id: `${visitorId}_${articleId}_${Date.now()}`,
      visitorId,
      articleId,
      viewedAt: new Date().toISOString(),
      duration,
    });
  }

  async recordReadComplete(
    visitorId: string,
    articleId: string
  ): Promise<void> {
    // 読了はLikeがない場合のみ弱い正シグナルとして処理
    const existingFeedback = await this.storage.getFeedbackByArticle(
      visitorId,
      articleId
    );

    if (!existingFeedback) {
      // プロファイル再計算（読了として処理）
      const updatedProfile = await this.profiler.recalculateProfile(visitorId);
      await this.storage.saveProfile(updatedProfile);
    }
  }
}
```

### 読了シグナル処理

// PreferenceProfiler.recalculateProfile 内

// 読了（Likeなし）の記事を特定
const viewedArticles = viewHistory.map((h) => h.articleId);
const likedArticleIds = new Set(
  feedback.filter((f) => f.type === "like").map((f) => f.articleId)
);
const dislikedArticleIds = new Set(
  feedback.filter((f) => f.type === "dislike").map((f) => f.articleId)
);

const readWithoutFeedback = viewedArticles.filter(
  (id) => !likedArticleIds.has(id) && !dislikedArticleIds.has(id)
);

// 読了（Likeなし）は +0.3
for (const articleId of readWithoutFeedback) {
  const articleTags = await this.getArticleTags(articleId);
  for (const tag of articleTags) {

  }
}

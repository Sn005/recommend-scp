# Subtask 004-04-01: Like/Dislikeフィードバック処理

## 概要

ユーザーのLike/Dislikeフィードバックを記録し、嗜好プロファイルを更新する機能を実装する。

## ステータス

- **status**: pending

## ユーザーストーリー

**As a** SCPファン
**I want** 記事をLike/Dislikeで評価したい
**So that** 自分の好みに合った推薦を受けられる

## Acceptance Criteria（EARS記法）

- [ ] WHEN ユーザーが記事をLikeした際
      THEN Feedbackレコードがストレージに保存される
      AND その記事のタグに対する重みが +1.0 増加する
      AND プロファイルが再計算・保存される

- [ ] WHEN ユーザーが記事をDislikeした際
      THEN Feedbackレコードがストレージに保存される
      AND その記事がgetDislikedArticleIdsの結果に含まれる
      AND タグ重みは変化しない

- [ ] WHEN 同じ記事に対して再度フィードバックした際
      THEN 既存のフィードバックが上書きされる

- [ ] WHEN フィードバックを記録する際
      THEN 記事のタグ情報をSupabaseから取得する
      AND tagWeightsに反映する

## 技術設計

### シグナルプロセッサ

```typescript
// packages/shared/src/recommendation/signal-processor.ts

export class SignalProcessor {
  constructor(
    private storage: PreferenceStorage,
    private profiler: PreferenceProfiler
  ) {}

  async recordLike(visitorId: string, articleId: string): Promise<void> {
    // フィードバック保存
    await this.storage.addFeedback({
      id: `${visitorId}_${articleId}`,
      visitorId,
      articleId,
      type: "like",
      createdAt: new Date().toISOString(),
    });

    // プロファイル再計算
    const updatedProfile = await this.profiler.recalculateProfile(visitorId);
    await this.storage.saveProfile(updatedProfile);
  }

  async recordDislike(visitorId: string, articleId: string): Promise<void> {
    // フィードバック保存（タグ重みには影響しない）
    await this.storage.addFeedback({
      id: `${visitorId}_${articleId}`,
      visitorId,
      articleId,
      type: "dislike",
      createdAt: new Date().toISOString(),
    });
  }

  async getFeedbackType(visitorId: string, articleId: string): Promise<"like" | "dislike" | null> {
    const feedback = await this.storage.getFeedbackByArticle(visitorId, articleId);
    return feedback?.type ?? null;
  }
}
```

### タグ重み更新ロジック

```typescript
// PreferenceProfiler.recalculateProfile 内

const likedArticles = feedback.filter((f) => f.type === "like");

for (const like of likedArticles) {
  const articleTags = await this.getArticleTags(like.articleId);
  for (const tag of articleTags) {
    tagWeights[tag] = (tagWeights[tag] ?? 0) + 1.0;
  }
}
```

## テストケース

- [ ] Likeでフィードバックが保存される
- [ ] Likeで対象記事のタグ重みが+1.0増加する
- [ ] Likeでプロファイルが再計算される
- [ ] Dislikeでフィードバックが保存される
- [ ] Dislikeでタグ重みは変化しない
- [ ] Dislike済み記事がgetDislikedArticleIdsに含まれる
- [ ] 同じ記事への再フィードバックで上書きされる

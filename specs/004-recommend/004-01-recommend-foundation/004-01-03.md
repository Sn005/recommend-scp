# Subtask 004-01-03: 嗜好プロファイル計算

## 概要

ユーザーの閲覧履歴・フィードバックから嗜好プロファイル（`PreferenceProfile`）を計算する`PreferenceProfiler`クラスを実装する。

## ステータス

- **status**: pending

## ユーザーストーリー

**As a** 推薦エンジン
**I want** ユーザーの行動履歴から嗜好プロファイルを計算できる
**So that** パーソナライズされた推薦を提供できる

## Acceptance Criteria（EARS記法）

- [ ] WHEN ユーザーが記事をLikeした際
      THEN その記事のタグに対する重みが増加する
      AND tagWeightsが更新される

- [ ] WHEN ユーザーが記事を最後まで読んだ（Likeなし）際
      THEN その記事のタグに対する重みが微増する（Likeより弱い）

- [ ] WHEN ユーザーが記事をDislikeした際
      THEN その記事のタグに対する重みは変化しない
      AND 記事単体が除外リストに追加される

- [ ] WHEN 嗜好プロファイルを計算する際
      GIVEN フィードバック履歴が存在する場合
      THEN tagWeightsは0〜1の範囲に正規化される
      AND 最も高い重みのタグが1.0となる

- [ ] WHEN オンボーディングが完了した際
      GIVEN スターターパックが選択された場合
      THEN 初期tagWeightsがスターターパックに基づいて設定される

## 技術設計

### クラス設計

```typescript
// packages/shared/src/recommendation/profiler.ts

export class PreferenceProfiler {
  constructor(private storage: PreferenceStorage) {}

  /** プロファイルを再計算 */
  async recalculateProfile(visitorId: string): Promise<PreferenceProfile> {
    const feedback = await this.storage.getFeedback(visitorId);
    const viewHistory = await this.storage.getViewHistory(visitorId);

    // タグ重みを計算
    const tagWeights = this.calculateTagWeights(feedback, viewHistory);

    // 正規化
    const normalizedWeights = this.normalizeWeights(tagWeights);

    return {
      visitorId,
      tagWeights: normalizedWeights,
      // ...
    };
  }

  /** Likeからタグ重みを計算 */
  private calculateTagWeights(
    feedback: Feedback[],
    viewHistory: ViewHistory[]
  ): Record<string, number> {
    // Like: +1.0
    // 読了（Likeなし）: +0.3
    // Dislike: 0（タグ重みには影響しない）
  }

  /** 重みを0〜1に正規化 */
  private normalizeWeights(weights: Record<string, number>): Record<string, number> {
    const max = Math.max(...Object.values(weights));
    if (max === 0) return weights;
    return Object.fromEntries(
      Object.entries(weights).map(([k, v]) => [k, v / max])
    );
  }
}
```

### 重み計算ロジック

| アクション | 重み増分 | 備考 |
|------------|----------|------|
| Like | +1.0 | 強い正のシグナル |
| 読了（Likeなし） | +0.3 | 弱い正のシグナル |
| Dislike | 0 | タグ重みには影響しない |

## テストケース

- [ ] Likeした記事のタグ重みが増加する
- [ ] 読了（Likeなし）した記事のタグ重みが微増する
- [ ] Dislikeした記事のタグ重みは変化しない
- [ ] tagWeightsが0〜1の範囲に正規化される
- [ ] フィードバックがない場合は空のtagWeightsが返る
- [ ] スターターパックから初期プロファイルが生成される

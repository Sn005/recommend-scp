# Story 004-01: 推薦基盤

## 概要

推薦ロジックの基盤となるストレージ抽象化レイヤー、IndexedDB実装、嗜好プロファイル計算機能を実装する。

## ステータス

- **status**: pending

## ユーザーストーリー

**As a** SCPファン
**I want** 自分の閲覧履歴や好みがローカルに保存される
**So that** ユーザー登録なしでパーソナライズされた推薦を受けられる

## Acceptance Criteria（Story レベル）

### AC-1: ストレージ抽象化

- [ ] WHEN アプリケーションがストレージにアクセスする際
      THEN 抽象化レイヤー（PreferenceStorage）経由でアクセスする
      AND 将来的なストレージ実装の差し替えが可能である

### AC-2: IndexedDB実装

- [ ] WHEN ユーザーがPWAを使用する際
      GIVEN IndexedDBが利用可能な環境の場合
      THEN ユーザーの嗜好データがIndexedDBに永続化される
      AND ブラウザを閉じてもデータが保持される

### AC-3: 嗜好プロファイル計算

- [ ] WHEN ユーザーの閲覧履歴・フィードバックが蓄積された際
      THEN システムは嗜好プロファイル（tagWeights等）を計算する
      AND プロファイルは推薦エンジンから参照可能である

## 技術設計

### インターフェース定義

```typescript
// packages/shared/src/storage/types.ts

interface PreferenceStorage {
  // 嗜好プロファイル
  getProfile(visitorId: string): Promise<PreferenceProfile | null>;
  saveProfile(profile: PreferenceProfile): Promise<void>;

  // 閲覧履歴
  getViewHistory(visitorId: string, limit?: number): Promise<ViewHistory[]>;
  addViewHistory(history: ViewHistory): Promise<void>;

  // フィードバック
  getFeedback(visitorId: string): Promise<Feedback[]>;
  addFeedback(feedback: Feedback): Promise<void>;

  // 推薦ログ
  getRecommendationLog(visitorId: string, limit?: number): Promise<RecommendationLog[]>;
  addRecommendationLog(log: RecommendationLog): Promise<void>;
}
```

### データモデル

```typescript
interface PreferenceProfile {
  visitorId: string;
  tagWeights: Record<string, number>;
  objectClassPreference: Record<string, number>;
  starterPack?: StarterPackType;
  onboardingCompletedAt?: string;
  preferenceEmbedding?: number[];
  updatedAt: string;
}

interface ViewHistory {
  visitorId: string;
  articleId: string;
  viewedAt: string;
  duration?: number;
}

interface Feedback {
  visitorId: string;
  articleId: string;
  type: "like" | "dislike";
  createdAt: string;
}

interface RecommendationLog {
  visitorId: string;
  articleId: string;
  recommendedAt: string;
  source: "preference" | "serendipity";
  clicked: boolean;
}
```

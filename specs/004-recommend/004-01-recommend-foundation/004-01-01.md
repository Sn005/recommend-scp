# Subtask 004-01-01: ストレージ抽象化レイヤー

## 概要

推薦ロジックで使用するストレージの抽象化レイヤー（`PreferenceStorage`インターフェース）を定義する。

## ステータス

- **status**: pending

## ユーザーストーリー

**As a** 開発者
**I want** ストレージ実装を抽象化したインターフェースを使用する
**So that** 将来的にIndexedDB以外のストレージに差し替え可能にする

## Acceptance Criteria（EARS記法）

- [ ] WHEN ストレージ操作を行う際
      THEN 全ての操作はPreferenceStorageインターフェース経由で行われる
      AND 具体的なストレージ実装に依存しない

- [ ] WHERE PreferenceStorageインターフェース
      THE SYSTEM SHALL 以下のメソッドを提供する:
      - getProfile / saveProfile（嗜好プロファイル）
      - getViewHistory / addViewHistory（閲覧履歴）
      - getFeedback / addFeedback（フィードバック）
      - getRecommendationLog / addRecommendationLog（推薦ログ）

- [ ] WHEN 型定義を参照する際
      THEN `packages/shared/src/storage/types.ts` からインポート可能である

### インターフェース定義

```typescript
// packages/shared/src/storage/types.ts

/** ストレージ抽象化インターフェース */
export interface PreferenceStorage {
  // 嗜好プロファイル
  getProfile(visitorId: string): Promise<PreferenceProfile | null>;
  saveProfile(profile: PreferenceProfile): Promise<void>;

  // 閲覧履歴
  getViewHistory(visitorId: string, limit?: number): Promise<ViewHistory[]>;
  addViewHistory(history: ViewHistory): Promise<void>;

  // フィードバック
  getFeedback(visitorId: string): Promise<Feedback[]>;
  getFeedbackByArticle(visitorId: string, articleId: string): Promise<Feedback | null>;
  addFeedback(feedback: Feedback): Promise<void>;

  // 推薦ログ
  getRecommendationLog(visitorId: string, limit?: number): Promise<RecommendationLog[]>;
  addRecommendationLog(log: RecommendationLog): Promise<void>;

  // Dislike済み記事
  getDislikedArticleIds(visitorId: string): Promise<string[]>;
}

/** スターターパック種別 */
export type StarterPackType =
  | "horror"
  | "surreal"
  | "scientific"
  | "heartwarming"
  | "mystery"
  | "custom";

/** 嗜好プロファイル */
export interface PreferenceProfile {
  visitorId: string;
  tagWeights: Record<string, number>;
  objectClassPreference: Record<string, number>;
  starterPack?: StarterPackType;
  onboardingCompletedAt?: string;
  preferenceEmbedding?: number[];
  createdAt: string;
  updatedAt: string;
}

/** 閲覧履歴 */
export interface ViewHistory {
  id: string; // `${visitorId}_${articleId}_${timestamp}`
  visitorId: string;
  articleId: string;
  viewedAt: string;
  duration?: number;
}

/** フィードバック */
export interface Feedback {
  id: string; // `${visitorId}_${articleId}`
  visitorId: string;
  articleId: string;
  type: "like" | "dislike";
  createdAt: string;
}

/** 推薦ログ */
export interface RecommendationLog {
  id: string;
  visitorId: string;
  articleId: string;
  recommendedAt: string;
  source: "preference" | "serendipity";
  clicked: boolean;
}
```

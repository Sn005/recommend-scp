# Subtask 004-01-02: IndexedDB実装

## 概要

`PreferenceStorage`インターフェースのIndexedDB実装（`IndexedDBStorage`クラス）を作成する。

## ステータス

- **status**: pending

## ユーザーストーリー

**As a** PWAユーザー
**I want** 嗜好データがブラウザに保存される
**So that** アプリを閉じても好みの設定が保持される

## Acceptance Criteria（EARS記法）

- [ ] WHEN アプリケーションが初回起動した際
      GIVEN IndexedDBが利用可能な場合
      THEN システムは `scp-recommend` データベースを作成する
      AND 必要なオブジェクトストアを初期化する

- [ ] WHEN 嗜好プロファイルを保存する際
      THEN IndexedDBの `preferences` ストアに保存される
      AND 次回起動時に復元可能である

- [ ] WHEN 閲覧履歴を追加する際
      THEN IndexedDBの `viewHistory` ストアに追加される
      AND visitorId, articleId, viewedAt でインデックス検索可能である

- [ ] WHEN フィードバックを追加する際
      GIVEN 同じ記事への既存フィードバックがある場合
      THEN 既存のフィードバックを上書きする

- [ ] WHILE IndexedDBが利用不可能な環境
      THE SYSTEM SHALL エラーをスローする
      AND 適切なエラーメッセージを提供する

## 技術設計

### IndexedDBスキーマ

```typescript
const DB_NAME = "scp-recommend";
const DB_VERSION = 1;

const stores = {
  preferences: {
    keyPath: "visitorId",
  },
  viewHistory: {
    keyPath: "id",
    indexes: [
      { name: "byVisitor", keyPath: "visitorId" },
      { name: "byArticle", keyPath: "articleId" },
      { name: "byDate", keyPath: "viewedAt" },
    ],
  },
  feedback: {
    keyPath: "id",
    indexes: [
      { name: "byVisitor", keyPath: "visitorId" },
      { name: "byType", keyPath: "type" },
    ],
  },
  recommendationLog: {
    keyPath: "id",
    indexes: [
      { name: "byVisitor", keyPath: "visitorId" },
      { name: "byDate", keyPath: "recommendedAt" },
    ],
  },
};
```

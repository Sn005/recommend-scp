# EPIC 007: インフラ・デプロイ

## 概要

本番環境の構築、CI/CDパイプライン、シークレット管理など、インフラストラクチャ全般を整備する。

## ユーザーストーリー

```
AS A 開発者・運用者
I WANT 自動化されたデプロイパイプラインと安全なインフラ基盤
SO THAT 手動作業を減らし、安定したサービス運用を実現できる
```

## スコープ

### 含むもの

- CI/CDパイプライン構築（GitHub Actions）
- データベースマイグレーション自動化
- シークレット管理（GitHub Secrets）
- 環境分離（開発/ステージング/本番）

### 含まないもの

- Kubernetes/コンテナオーケストレーション（Supabaseマネージドを使用）
- 独自インフラ構築（Supabase/Vercelを活用）

## Acceptance Criteria（EPICレベル）

- [x] mainブランチへのマージで自動デプロイが実行される
- [x] データベースマイグレーションが自動適用される
- [x] シークレットが安全に管理されている
- [ ] デプロイ失敗時に通知される（将来のStoryで対応）
- [ ] CIで本番ビルドが検証され、ビルド退行が自動検知される
- [ ] api-serverがスタンドアロンで起動可能なビルド成果物を生成する

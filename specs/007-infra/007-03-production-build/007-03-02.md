# Subtask 007-03-02: api-serverバンドルビルド整備

## 概要

`apps/api-server` のビルドを `tsc` から `tsup`（esbuildベース）に移行し、`node dist/index.js` でスタンドアロン起動可能な本番ビルドを生成する。

## ユーザーストーリー

```
AS A 開発者・運用者
I WANT api-server が `node dist/index.js` で単体起動可能
SO THAT Vercel以外のデプロイ先（Docker, VPS, AWS Lambda等）にも柔軟に対応できる
```

## 背景・課題

現行の `tsc` ビルドには以下の問題がある:

1. **ESM拡張子なし** — `import { createApp } from "./app"` のように拡張子なしで出力されるが、`"type": "module"` 環境のNode.js ESMローダーは明示的な `.js` 拡張子を要求する
2. **shared パッケージの `.ts` 直接参照** — `@recommend-scp/shared` の `exports` が `.ts` ファイルを指しており、`node` ランタイムで解釈できない
3. **依存解決の不完全性** — `tsc` はトランスパイルのみでバンドルしないため、ワークスペース内パッケージの解決がランタイム依存

## Acceptance Criteria（EARS記法）

### AC-1: tsup導入とビルド設定

- [ ] WHEN `pnpm --filter api-server build` を実行した際
      THEN tsup が api-server のソースをバンドルし `dist/index.js` を出力する
      AND ワークスペース内パッケージ（`@recommend-scp/shared`）のコードがバンドルにインライン化される
      AND 外部 node_modules 依存（hono, pino等）は `external` 指定で除外される

### AC-2: スタンドアロン起動

- [ ] WHEN `node dist/index.js` を実行した際
      GIVEN 必要な環境変数（SUPABASE_URL等）が設定されている場合
      THEN api-server が正常に起動する
      AND ヘルスチェックエンドポイント (`/health`) が応答する

### AC-3: 型定義の出力

- [ ] WHEN ビルドが完了した際
      THEN `dist/` に `.d.ts` 型定義ファイルが出力される
      AND `packages/api-types` が型参照可能な状態を維持する

### AC-4: 開発体験の維持

- [ ] WHEN 開発モードで実行する際
      THEN `tsx watch` による開発サーバーが引き続き正常に動作する
      AND HMR（ホットリロード）の速度に劣化がないこと

### AC-5: 既存テストの維持

- [ ] WHEN ビルド設定を変更した後
      THEN 既存のvitest テストが全てパスする
      AND type-check が正常に通る

## 技術設計

### 変更対象ファイル

| ファイル                         | 変更内容                             |
| -------------------------------- | ------------------------------------ |
| `apps/api-server/package.json`   | build スクリプトを tsup に変更       |
| `apps/api-server/tsconfig.json`  | `noEmit: true` に変更（tsup が担当） |
| `apps/api-server/tsup.config.ts` | 新規: tsup設定ファイル               |

### tsup 設定案

```typescript
import { defineConfig } from "tsup";

export default defineConfig({
  entry: ["src/index.ts"],
  format: ["esm"],
  target: "node20",
  outDir: "dist",
  clean: true,
  dts: true,
  sourcemap: true,
  // ワークスペースパッケージはバンドルにインライン化
  noExternal: ["@recommend-scp/shared"],
  // node_modules の依存はバンドルに含めない
  external: [
    "hono",
    "@hono/node-server",
    "@hono/zod-validator",
    "@supabase/supabase-js",
    "openai",
    "pino",
    "jsdom",
    "zod",
  ],
});
```

### package.json 変更案

```json
{
  "scripts": {
    "dev": "tsx watch src/index.ts",
    "build": "tsup",
    "start": "node dist/index.js"
  }
}
```

### ビルド前後の比較

| 項目       | tsc（現状）          | tsup（変更後）           |
| ---------- | -------------------- | ------------------------ |
| 出力形式   | 個別JSファイル       | バンドル済み単一ファイル |
| ESM拡張子  | なし（エラー）       | 不要（単一ファイル）     |
| shared参照 | `.ts` 直接（エラー） | インライン化（解決済み） |
| 型定義     | `declaration: true`  | `dts: true`              |
| 速度       | 中速                 | 高速（esbuild）          |

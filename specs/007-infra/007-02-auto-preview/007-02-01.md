# Subtask 007-02-01: Vercel連携設定

## 概要

VercelとGitHubリポジトリを連携し、PRプッシュ時に自動プレビューデプロイが実行される環境を構築する。

## ユーザーストーリー

```
AS A 開発者
I WANT GitHubにPRをプッシュするとVercelプレビューが自動生成される
SO THAT 手動デプロイなしでUI確認できる
```

## Acceptance Criteria

### AC1: Vercelプロジェクト設定

- [ ] WHEN Vercel Dashboardでプロジェクトを作成した際
      THEN GitHubリポジトリ `recommend-scp` と連携されている
- [ ] WHEN プロジェクト設定を確認した際
      THEN Framework Preset が `Next.js` に設定されている
- [ ] WHEN プロジェクト設定を確認した際
      THEN Root Directory が `apps/web` に設定されている

### AC2: ビルド設定

- [ ] WHEN `vercel.json` を確認した際
      THEN モノレポ用のビルド設定が定義されている
- [ ] WHEN Vercelビルドが実行された際
      THEN `pnpm install` でルートから依存関係がインストールされる
- [ ] WHEN Vercelビルドが実行された際
      THEN `apps/web` の `next build` が成功する

### AC3: 環境変数設定

- [ ] WHEN Vercel Dashboard の Environment Variables を確認した際
      THEN `NEXT_PUBLIC_API_URL=/api` が設定されている
- [ ] WHEN Vercel Dashboard の Environment Variables を確認した際
      THEN `SUPABASE_URL` が設定されている
- [ ] WHEN Vercel Dashboard の Environment Variables を確認した際
      THEN `SUPABASE_ANON_KEY` が設定されている
- [ ] WHEN Vercel Dashboard の Environment Variables を確認した際
      THEN `OPENAI_API_KEY` が設定されている

### AC4: 自動デプロイ動作

- [ ] WHEN PRをGitHubにプッシュした際
      THEN Vercelプレビューデプロイが自動開始される
- [ ] WHEN デプロイが完了した際
      THEN PRにプレビューURLがコメントされる
- [ ] WHEN mainブランチにマージした際
      THEN 本番デプロイが自動実行される

## 技術仕様

### vercel.json

```json
{
  "$schema": "https://openapi.vercel.sh/vercel.json",
  "framework": "nextjs",
  "installCommand": "pnpm install",
  "buildCommand": "pnpm --filter web build",
  "outputDirectory": "apps/web/.next"
}
```

### Vercel Dashboard設定手順

1. https://vercel.com/new でプロジェクト作成
2. GitHubリポジトリ `recommend-scp` を選択
3. Framework Preset: `Next.js`
4. Root Directory: `apps/web`
5. Build Command: `pnpm --filter web build`
6. Install Command: `pnpm install`
7. Output Directory: `.next`

### 必要な環境変数

| 変数名                      | Scope   | 値                        |
| --------------------------- | ------- | ------------------------- |
| `NEXT_PUBLIC_API_URL`       | All     | `/api`                    |
| `SUPABASE_URL`              | All     | `https://xxx.supabase.co` |
| `SUPABASE_ANON_KEY`         | All     | `eyJ...`                  |
| `SUPABASE_SERVICE_ROLE_KEY` | All     | `eyJ...`                  |
| `OPENAI_API_KEY`            | All     | `sk-...`                  |
| `PREVIEW_AUTH_USER`         | Preview | `preview`                 |
| `PREVIEW_AUTH_PASS`         | Preview | `<random>`                |

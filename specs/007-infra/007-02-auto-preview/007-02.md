# Story 007-02: 自動プレビューデプロイ

## 概要

PRプッシュ時にVercelプレビュー環境が自動生成され、スマートフォンからUI確認できる仕組みを構築する。

## ユーザーストーリー

```
AS A 開発者（スマートフォンでClaude Codeを操作）
I WANT PRをプッシュするたびにプレビューURLが生成される
SO THAT 実装結果をスマートフォンから即座に確認できる
```

## 背景

- 開発者はスマートフォン経由でClaude Codeを操作している
- 静的HTMLのGitHub Pages確認体験が良かった
- フロントエンド開発中にAPIも含めた動作確認が必要

## 設計決定

### ハイブリッド方式の採用

```
┌─────────────────────────────────────────────────┐
│ ローカル開発（今まで通り）                        │
│  web:3000 ──────▶ api-server:3001               │
│      NEXT_PUBLIC_API_URL=http://localhost:3001  │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│ Vercel プレビュー/本番                           │
│  Next.js API Routes に Hono を統合               │
│      NEXT_PUBLIC_API_URL=/api                   │
└─────────────────────────────────────────────────┘
```

**理由:**

- ローカル開発の体験を変えない
- Vercelの自動プレビュー機能を活用
- 単一URLでフロント＋API完結

### プレビュー環境のベーシック認証

- プレビュー環境は特定の人間のみアクセス可能にする
- Next.js Middleware でベーシック認証を実装
- `VERCEL_ENV === "preview"` の場合のみ有効

### 段階的アプローチ

- 本番もVercel統合（`/api`）から開始
- トラフィック増加時にAPI分離を検討（環境変数変更のみで対応可能）

## スコープ

### 含むもの

- Vercel連携設定（vercel.json）
- Next.js API Routes への Hono 統合
- プレビュー環境用ベーシック認証
- 環境変数設定ガイド

### 含まないもの

- 本番独自ドメイン設定
- API分離構成（将来対応）
- Supabase Preview Branches（既存DBを使用）

## Acceptance Criteria（Storyレベル）

- [ ] WHEN PRをプッシュした際 THEN Vercelプレビューデプロイが自動実行される
- [ ] WHEN プレビューURLにアクセスした際 THEN ベーシック認証が要求される
- [ ] WHEN 認証成功後にフロントエンドにアクセスした際 THEN APIも正常に動作する
- [ ] WHEN ローカルで `pnpm dev` を実行した際 THEN 従来通りweb:3000とapi-server:3001が別々に起動する
- [ ] WHEN 本番環境にアクセスした際 THEN 認証なしでアクセスできる

## 技術スタック

| 項目         | 技術                            |
| ------------ | ------------------------------- |
| ホスティング | Vercel                          |
| API統合      | @hono/vercel                    |
| 認証         | Next.js Middleware + Basic Auth |
| ランタイム   | Vercel Edge Runtime             |

## 環境変数

| 変数名                | ローカル                | プレビュー | 本番         |
| --------------------- | ----------------------- | ---------- | ------------ |
| `NEXT_PUBLIC_API_URL` | `http://localhost:3001` | `/api`     | `/api`       |
| `PREVIEW_AUTH_USER`   | -                       | 設定必須   | -            |
| `PREVIEW_AUTH_PASS`   | -                       | 設定必須   | -            |
| `VERCEL_ENV`          | -                       | `preview`  | `production` |
